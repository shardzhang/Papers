## FQA

#### Q：L-BFGS

Limited-memory Broyden–Fletcher–Goldfarb–Shanno（有限内存 BFGS）

- BFGS：一种拟牛顿（quasi-Newton）优化算法，以四位发明者命名——Broyden、Fletcher、Goldfarb、Shanno。核心思想是用近似的**逆 Hessian 矩阵**指导参数更新，**避免直接计算二阶导数**。
- L（Limited-memory）：BFGS 需要存储近似的逆 Hessian（$O(n^2)$ 内存），L-BFGS 只保留最近几步的梯度差信息来隐式近似它，内存降到 $O(n)$，适合参数规模巨大的场景（如 GloVe 论文中 NER 模型的 CRF 训练）。



#### Q：对数线性模型

对数线性模型（log-linear model） 是一类把"预测概率的对数"建模为"特征线性组合"的概率模型。数学形式很统一：

$$p(y \mid x) = \frac{\exp\left(w \cdot \phi(x, y)\right)}{\sum_{y'} \exp\left(w \cdot \phi(x, y')\right)}$$

- 分子：特征的线性组合 $w \cdot \phi(x,y)$ 取指数
- 分母：对所有候选 $y'$ 求和归一化（softmax）
- 两边取对数：$\log p(y|x) \propto w \cdot \phi(x,y)$ —— **对数 = 线性**，这就是名字的由来

你其实早见过它

| 名称              | 本质上就是                               |
| ----------------- | ---------------------------------------- |
| 逻辑回归          | 二分类对数线性模型                       |
| softmax 回归      | 多分类对数线性模型                       |
| 最大熵模型        | 同一个东西的另一个名字                   |
| 条件随机场（CRF） | 序列版对数线性模型（特征加在状态转移上） |

与词向量模型的联系（GloVe 语境）

GloVe 论文自称"**global log-bilinear regression model**"，这里的 *bi*-linear（双线性）多了一层：对数是**两个向量的内积** $w_i^{\mathrm{T}} \tilde{w}_k$（双线性形式），而不是**特征向量的单线性组合**：

$$w_i^{\mathrm{T}} \tilde{w}_k + b_i + \tilde{b}_k = \log X_{ik}$$

同理：
- **skip-gram / CBOW / word2vec**：本质上都是对数线性模型（softmax 输出层）
- **FastText**：log-bilinear + 子词
- **L-BFGS 训练的 CRF**（GloVe 论文 NER 实验）：对数线性



"大规模"指什么

两个层面：

1. **参数量巨大**：词汇表 40 万词 × 300 维嵌入矩阵、共现对特征空间可达 $10^{11}$ 量级 → 需要 L-BFGS/AdaGrad 这类能处理海量参数的优化器
2. **归一化分母爆炸**：softmax 要对整个词汇表求和，$O(|V|)$ 每步 → 所以才有负采样、NCE、层次 softmax 这些加速技巧（你之前问过的那几篇论文都在解决这件事）



一句话总结

对数线性模型 = "预测概率的对数"是"特征线性组合"的模型（逻辑回归是它的特例）。词向量领域几乎所有经典模型（word2vec、GloVe、FastText）都在这个框架内——因为"内积 + softmax"天然就是对数线性结构。"大规模"则指词汇表巨大的场景下，参数规模和归一化计算带来的工程挑战。





#### Q：其中 $e_i$ 是第 $i$ 个标准基向量？

$e_i$ 是**第 $i$ 个标准基向量（standard basis vector）**：一个 $n$ 维向量，**第 $i$ 个分量为 1，其余分量全为 0**。

以 $\mathbb{R}^3$ 为例：
- $e_1 = (1,0,0)$
- $e_2 = (0,1,0)$
- $e_3 = (0,0,1)$

那么 $x + \alpha e_i$ 就等于在原始向量 $x$ 上**只给第 $i$ 个坐标加了个 $\alpha$**，其他坐标原封不动：

$$
x + \alpha e_i = (x_1,\ \dots,\ x_i + \alpha,\ \dots,\ x_n)
$$

所以这个式子

$$
\partial_i^+ f(x) = \lim_{\alpha \downarrow 0} \frac{f(x + \alpha e_i) - f(x)}{\alpha}
$$

就是在说：**只改变第 $i$ 个变量**，看 $f$ 的变化率——也就是 $f$ 关于 $x_i$ 的偏导数。$\alpha \downarrow 0$ 表示从**右侧**逼近零。



为什么这篇论文要区分左右偏导数

普通的偏导 $\frac{\partial f}{\partial x_i}$ 要求左右两侧的斜率一致。但目标函数里有 L1 正则项 $C\|x\|_1 = C\sum_i |x_i|$，而 $|x_i|$ 在 $x_i = 0$ 处有个"尖角"：

- 从右边逼近：$|x_i|$ 的斜率是 $+1$ → 右导数
- 从左边逼近：$|x_i|$ 的斜率是 $-1$ → 左导数

两者不等，所以 $f$ 在 $x_i=0$ 处**不可微**。论文因此定义 $\partial_i^+$（右偏导）和 $\partial_i^-$（左偏导），并组合出"伪梯度" $\diamond f(x)$（公式 4）来替代普通梯度——这正是 OWL-QN 能处理 L1 的关键。



论文主线（快速上手）

1. **问题**：L1 正则在 0 处不可微，标准 L-BFGS（用梯度）没法用。
2. **核心观察**：在任意象限内（每个坐标符号固定），$C\|x\|_1 = C\,\xi^\top x$ 变成线性函数 → $f$ 在象限内可微，二次近似只由损失项 $\ell$ 决定。
3. **OWL-QN 三步**：伪梯度选象限（§3.1）→ L-BFGS 方向（§2）→ 约束线搜索把探索点投影回原象限（§3.2）。
4. **验证**：百万特征句法重排序任务上比 K&T 快一个数量级，甚至快于 L-BFGS 在 L2 上的收敛；附录证明了收敛到全局最优。

#### Q：详细解释公式

$$
\pi_i(x; y) = \begin{cases} x_i & \text{if } \sigma(x_i) = \sigma(y_i), \\ 0 & \text{otherwise} \end{cases}
$$

这是把向量 $x$ **“投影”到由 $y$ 的方向（符号模式）决定的象限**上的操作。逐行拆解：



符号函数 $\sigma$
$$
\sigma(s) = \begin{cases} -1 & s < 0 \\ 0 & s = 0 \\ +1 & s > 0 \end{cases}
$$

它只关心"正、负、零"，不关心数值大小。



逐坐标理解 $\pi_i$

对第 $i$ 个分量：

- **`if σ(x_i) = σ(y_i)`**：$x_i$ 和 $y_i$ 同号（同正 / 同负 / 同为 0）→ **保留 $x_i$ 原值**
- **`otherwise`**：$x_i$ 和 $y_i$ 符号不一致 → **置为 0**



直观例子

设 $n=2$，$y = (3,\ -2)$（符号模式是"第一维为正、第二维为负"）：

- $\pi((\,5,\ -1)\,;\ y) = (5,\ -1)$ —— 符号一致，不动，仍然留在该象限内
- $\pi((-3,\ -1)\,;\ y) = (0,\ -1)$ —— $x_1=-3<0$ 与 $y_1>0$ 反号 → 第一维被"踩回" 0
- $\pi((\,5,\ +7)\,;\ y) = (5,\ \ 0)$ —— 第二维 $7>0$ 与 $y_2<0$ 反号 → 第二维置 0

注意到如果 $y_i = 0$，则 $\sigma(y_i)=0$：这一列 $x_i$ 必须也是 0 才能保留，否则会被强置为 0。这对应了论文中 $\Omega_\xi$ 是"象限 ∩ 若干坐标轴平面"的说法（第 110 行附近）。



在 OWL-QN 里的两处用途

1. **搜索方向（公式 3）**：$p_k = \pi(H_k v_k;\ v_k)$
   让 L-BFGS 算出的方向与最速下降方向 $v_k$ **符号一致**，保证不会跑出有利象限、也不偏离下降方向太远（脚注 2 说这是收敛所需的）。

2. **约束线搜索（§3.2）**：$x_{k+1} = \pi(x_k + \alpha p_k;\ \xi_k)$
   试探步 $x_k + \alpha p_k$ 一旦有某个坐标**穿越零、变了符号**，就被立刻"掰回" 0。这样每个探索点始终留在 $Q_\xi$ 有效的象限里。

一句话记忆：**$\pi$ 就是"只保留符号没变的分量，准许跨过零的分量强制归零"**——它是 OWL-QN 处理 L1 不可微点的核心工具。



#### Q：$y$ 是什么？

这个 $y$ 不是训练标签，也**不是某个具体的量**——它是定义辅助函数 $\pi$ 时用的**形式参数（占位符）**，就像函数签名里的参数名。



为什么这里出现 $y$

论文在 §1.1 用 $\pi$ 定义"把 $x$ 投影到由某个向量决定的象限上"这个**通用工具函数**。为了让"由谁决定象限"这个输入有个名字，就随便取了 $y$ 作参数名，含义是：

> $\pi(x;\, y)$ = 按 $y$ 的符号模式，把 $x$ 保留同号分量、归零反号分量。

所以这一句的 $y$ 相当于"模板参数"，本身没有物理意义，只是说明 **$\pi$ 有两个输入：被投影的对象 $x$ + 决定象限的对象 $y$**。



它在算法里被"实例化"成具体向量

定义好之后，后面每次用到 $\pi$ 时，$y$ 会被替换成真正的量：

| 位置                                            | 传入的实际向量                    | 作用               |
| ----------------------------------------------- | --------------------------------- | ------------------ |
| 公式 (3)：$p_k = \pi(H_k v_k;\ v_k)$            | $y = v_k$                         | 方向与 $v_k$ 同号  |
| §3.2：$x_{k+1} = \pi(x_k + \alpha p_k;\ \xi_k)$ | $y = \xi_k$（当前象限的符号向量） | 试探步投影回原象限 |



举例消歧

假设 $\pi$ 被调用为 $\pi(x;\ \xi)$，其中 $\xi = (1, -1)$：

- $x = (2, 3)$ → $(2, 0)$（第 2 维反号被归零）
- 若传 $\pi(x;\ v_k)$ 且 $v_k = (-1, 1)$ → $x=(2,3)$ 变成 $(0, 3)$

同一函数、不同 $y$，结果完全不同——这就是"由 $y$ 参数化"的意思。

一句话：**$y$ 只是函数定义里的占位参数，具体值由调用处决定**，千万别和 §4 里训练样本的标签 $y_j \in Y$ 混淆。



#### Q：**$\pi$ 就是"只保留符号没变的分量，准许跨过零的分量强制归零"**

那句话写得绕了，我用更直白的说法拆开讲。



先看规则本身

$\pi_i(x; y)$ 只做一件事：**比较 $x_i$ 和 $y_i$ 的符号（$+/-/0$）。**

- 符号相同 → 原样保留 $x_i$
- 符号不同 → 改成 $0$

例：设 $y = (3,\ -2)$（符号模式：$+,-$）

| $x$ 的分量 | $x_i$ 符号 | $y_i$ 符号 | 相同？ | 结果      |
| ---------- | ---------- | ---------- | ------ | --------- |
| $x_1=5$    | $+$        | $+$        | ✅      | 保留 $5$  |
| $x_2=-1$   | $-$        | $-$        | ✅      | 保留 $-1$ |
| $x_1=-3$   | $-$        | $+$        | ❌      | 变 $0$    |
| $x_2=7$    | $+$        | $-$        | ❌      | 变 $0$    |



什么叫"跨过零"

拿 $x_1=-3$ 和 $y_1=3$ 来说：目标象限要求 $x_1$ 是正的，可 $x_1$ 现在是 $-3$。想让它"变正"，就得从 $-3$ 一路穿过 $0$ 走到正半边——**这个分量必须跨过零**。而 $\pi$ 不允许翻转符号，所以把它**钉在 $0$**（正好停在符号交界处）。

所以更准确的一句话是：

> **$\pi$ 只保留"本来就在目标象限内"的分量；把"符号反了、得跨过零点才能归位"的分量直接钉在 0 上。**



几何直觉

把每个坐标轴想象成一条线，一条线上有正半轴、负半轴、零点：

- $x_i$ 已经站在正确的半轴上 → 不动
- $x_i$ 站在错误的半轴上 → 拉回原点（0）
- $y_i=0$ → 那一轴只允许 0，$x_i\neq 0$ 一律归零



在算法里的实际作用（§3.2）

线搜索时试探走一步 $x_k + \alpha p_k$，这一步可能让某个坐标从正变负（或负变正）——**一旦穿过了零就离开了当前象限**，公式 $Q_\xi$ 就不再有效了。于是用 $\pi(\cdot;\ \xi_k)$ 把越界的坐标"拽回 0"，保证试探点始终留在有效象限内。

也就是说：**$\pi$ 负责在"符号边界"处兜住搜索，是该算法处理 L1 不可微点的物理开关。**



这句话确实太抽象了。我换成**一个具体的数字例子**把它演出来。

## 场景设定

二维问题，当前点在 $x_k = (0.3,\ 0.8)$，两坐标都为正，所以当前象限的符号向量 $\xi = (1,1)$。在这个象限内，$f(x) = \ell(x) + C(x_1 + x_2)$，公式 $Q_\xi$ 就是基于这个形式构造的二次近似。

假设 L-BFGS 算出的搜索方向 $p_k = (-1,\ 0.2)$（第一维想往负方向走）。

## 线搜索试探的过程（$\alpha$ 从大到小试）

- **试 $\alpha = 0.1$**：$x_k + 0.1 p_k = (0.2,\ 0.82)$ —— 两坐标仍是正，没出问题 ✅
- **试 $\alpha = 1$**：$x_k + 1 \cdot p_k = (0.3-1,\ 0.8+0.2) = (-0.7,\ 1.0)$ —— ⚠️ **第一维从正的 0.3 变成了负的 -0.7，穿过了零！**

## 穿零为什么是问题

一旦 $x_1$ 变成负的，这个点就属于 $(-,+)$ 象限了，那里的真实目标函数是：

$$
f(x) = \ell(x) + C(-x_1 + x_2)
$$

而我们构造的 $Q_\xi$ 假设的是 $C(x_1 + x_2)$。**$Q_\xi$ 只是"负号象限内"的模型，拿到负号区域里它的预测就是错的**——不该用 $Q_\xi$ 来评价/决定这一步。

## $\pi$ 做了什么

$\pi(\text{试探点};\ \xi)$ 比较每个坐标符号与 $\xi=(1,1)$：

$$
\pi\big((-0.7,\ 1.0);\ (1,1)\big) = (0,\ 1.0)
$$

第一维 $x_1=-0.7$ 与 $\xi_1=+1$ 反号 → **钉回 0**。得到的 $(0, 1.0)$ 中 $x_1 = 0$ 仍位于 $\Omega_\xi$（象限的**边界**也属于这个象限，因为边界上符号约定为 0）。所以 $Q_\xi$ 在这个点依然有效。

之后再拿钉回后的点去检查下降准则（$f(x_{k+1}) \le f(x_k) - \gamma v^\top(x_{k+1}-x_k)$）：
- 不满足 → 把 $\alpha$ 缩小重试（回溯）。$\alpha$ 小到一定程度时没有坐标穿零，$\pi$ 什么都不用改，退化回标准 Armijo 规则（这正是命题 1 的直觉）。

## 把它翻译成第一性原理

> **方向 $p_k$ 想跨过零让某个变量改号，但 $\pi$ 不让它偷偷改——先把它拦在 0 上，检查这一步到底值不值。** 只有等到下一次迭代（换 $\xi_k$、重新选象限）这个变量被正式"批准"改号，它才会真正翻到另一边。

所以"物理开关"的比喻是：**$\pi$ 相当于在零点设了一个闸门，任何要越界的移动必须先停靠在零，由当前象限的局势决定是否放行。** 这就是它一手承接 L1 不可微（零点尖角），一手保证 $Q_\xi$ 始终有效的原因。

## 先用大白话讲这篇论文在干嘛

**背景问题**：训练模型时我们想让大部分权重**正好等于 0**（得到稀疏解，特征有上百万个时特别有用）。L1 正则项就是干这个的。但它有个"性格缺陷"——它在 0 点有一个**尖角**，不光滑。而主流快速优化器 L-BFGS 的工作前提是"函数要光滑"（要能求导），所以 L-BFGS 一碰到这个尖角就失灵。

**一句话难题**：想要稀疏解（不要平滑的 L2）→ 就要用 L1 → L1 在 0 点有尖角 → 最快的优化工具用不了。

**OWL-QN 的破局思路**（三层）：

1. **象限内是平的**：L1 就是"所有 |权重| 加起来"。如果你只看"每个权重符号都固定的区域"（比如都约定为正，或都约定为负），那 $\sum|x_i|$ 就退化成普通的线性相加，**尖角消失了**，函数瞬间光滑。
2. **在尖角处踩刹车**：优化时权重可能会穿越 0（符号变化）。算法规定：**想穿越 0？先给我停在 0 上**，检查这一跳到底划不划算，划算才放行。这就是那个看不懂的 $\pi$ 函数干的活。
3. **在 0 处怎么指路**：当某个权重已经卡在 0 时，用"左导数和右导数"来判断——如果左右两边都指向 0（梯度想把 0 往两边推都说得通），就说明这个权重待在 0 就已经最优了，保持 0 不变（稀疏性！）。

**结论**：只改了 L-BFGS 约 30 行代码，就能在百万参数规模上又快又稀疏地训好 L1 模型，还证明了必然收敛到全局最优。

## 类比

L1 就像在每个权重上设了一个 **"V 形收费站"**（角在 0）。普通优化器车开太快，在拐角处打滑。OWL-QN 的做法是：**到拐角先停车，观察清楚这个变量到底该往左还是往右，或者干脆留在 0（结果是稀疏）**，然后再决定过不过去。

#### Q：第二章详细解释

好，我带你把这章拆开，每一个公式都翻译成人话。

这章的任务

一句话：**要最小化函数 $f(x)$（在 $n$ 维空间），我们不能一步算出最优解，只能一步步"走"到谷底**。L-BFGS 就是一种特别会"走"的算法。这一整章就是在讲："牛顿法怎么走 → 太贵 → 拟牛顿法怎么走 → L-BFGS 怎么省内存"。

三个角色，三种走路方式

| 方法                | 它朝哪走                               | 缺点                                                 |
| ------------------- | -------------------------------------- | ---------------------------------------------------- |
| **梯度下降**        | 只看当前脚下最陡的方向 $-g_k$          | 慢，像盲人在坑里乱撞，来回震荡                       |
| **牛顿法**          | 看一眼整条路的"弯曲度"，直接跳向谷底   | 要算海森矩阵，$n^2$ 大小的矩阵，百万参数时根本算不起 |
| **拟牛顿 / L-BFGS** | 跟牛顿一样跳到谷底，但弯曲度**靠"猜"** | 猜得比真算快得多                                     |



公式 (2)：怎么"看弯曲度"然后跳到谷底
$$
Q(x) = f(x_k) + (x-x_k)^\top g_k + \frac{1}{2}(x-x_k)^\top B_k (x-x_k)
$$

这是在 $x_k$ 附近用一个**抛物线**（二次函数）去模拟真实的 $f$。三个术语对应三样东西：

- $f(x_k)$：当前位置的高度
- $g_k$：当前位置的**坡度**（梯度）
- $B_k$：当前位置的**弯曲度**（海森矩阵）

只要坡度、弯曲度都对得上，这个抛物线在 $x_k$ 附近就和 $f$ 长得几乎一样。

一拍脑袋就很自然的做法：**别在斜坡上慢慢挪了，直接跳到这个抛物线的底部去**。抛物线最低点的横坐标就是：

$$
x^* = x_k - H_k g_k, \qquad H_k = B_k^{-1}
$$

直觉解释这个式子：
- 坡度 $g_k$ 越陡 → 想走远一点（往下冲）
- 弯曲度 $B_k$ 越大（谷越窄越尖）→ 不敢走远，怕冲过头（所以除以弯曲度，即乘 $H_k$）

**这就是牛顿步。** 一次就能到抛物线底部；如果 $f$ 真是抛物线，一步精确到谷底。



拟牛顿：弯曲度靠"记忆"而不是"计算"

真算 $B_k$ 太贵（$n\times n$ 矩阵，要算二阶导）。拟牛顿的想法：**用我们走过的路程来反推弯曲度**。

想象你走山路，最近两步：

- 上一步你走了多远：$s_k = x_k - x_{k-1}$
- 斜率变陡了多少：$y_k = g_k - g_{k-1}$

"走了 $s$ 这么多，坡度变了 $y$ 这么多"——这两者一比就透露出**这一带的弯曲程度**（物理上这就是"位移/坡度变化"≈ 局部曲率）。数学上写成约束 $B\, s \approx y$（只对走过的方向有效——"secant condition"）。

把最近几步的 $(s_i, y_i)$ 都攒起来，就能拼出一个够用的"弯曲度估计" $B_k$，再求逆得 $H_k$。**全程只用一阶信息（梯度），不碰二阶导。**



L-BFGS：连"弯曲度矩阵"都不存

BFGS 会把 $H_k$ 这样一个完整矩阵存下来——$n$ 个参数就有 $n^2$ 个元素，百万参数时 ≈ $10^{12}$ 项，内存爆炸。

**L = Limited memory（有限内存）**，L-BFGS 的做法是：

1. 只保留**最近 $m$ 对** $(s_i, y_i)$（通常 $m$ 取 3~20），旧的丢掉；
2. 需要方向时，用这几对**临时算** $-H_k g_k$（有个著名的"两循环递归"技巧，不必记细节）；
3. 内存和每步耗时都是 $O(n)$——**与参数个数线性**，百万参数也扛得住。

所以 L-BFGS 成了大规模优化的事实标准，这正是原文说"Malouf 和 Minka 证明它对 L2 正则化对数线性模型最优"的原因。



完整一步长什么样

1. 用最近 $m$ 对记忆，算出方向 $d_k = -H_k g_k$（往哪走）
2. **线搜索**：沿这个方向试探走 $α$ 步（$α$ 从大到小试），直到 $f$ 确实下降了（这是"走多远的章"。这章先不展开）



与 OWL-QN 的衔接

OWL-QN = L-BFGS + "L1 尖角处理"。处理手段（§3）就是用到这章的两个组件：

- 二次模型 $Q$（公式 2）——但 L1 下只在**当前象限**里有效
- $H_k$（弯曲度估计）——但只用**损失函数** $\ell$ 的梯度来算，不掺 L1（因为 L1 在象限内是平的、不影响弯曲度）

到这里整章就通了。**最核心只需记住一句：L-BFGS 用最近几步的"位移+坡度变化"临时拼出一个弯曲度，朝抛物线谷底走一步。** 其余细节（怎么递归、怎么选 $m$）对理解论文不是必需的。

#### Q：第三章详细解释

这一章是全篇的核心。我换成人话 + 一个具体数字例子，分四步讲。

章节目标（一句话）

把 L1 这个在 0 点有"尖角"、不可微的目标函数，**伪装成一个光滑函数来跑 L-BFGS**——只需要在选好的"象限"里做事，并且在要跨过尖角的地方"踩刹车"。



第 1 步：核心伪装术（象限）

L1 长这样：$C\|x\|_1 = C\sum|x_i|$。它之所以难看，就是有绝对值 $|x_i|$——在 $x_i=0$ 处有尖角。

**关键观察**：如果我约定"每个 $x_i$ 的符号都不变"（比如全是非负，或全是非正），那么 $|x_i|$ 就只是 $x_i$ 或 $-x_i$，**没有尖角了，L1 直接变成线性函数**：

$$
f(x) = \ell(x) + C\xi^\top x \quad\text{（在象限 } \Omega_\xi \text{ 内）}
$$

其中 $\xi_i = \pm 1$ 表示第 $i$ 个坐标约定为正还是负；$\xi_i = 0$ 表示这一维被钉死在 0 上。

也就是说：**只要不跨过零，整个函数就是光滑的**，$\ell$ 的 L-BFGS 那套照常能用。难度全在"零的边界怎么处理"。



第 2 步：伪梯度 *⋄f*——尖角处的"交警"

普通梯度只能给光滑函数指路。在 $x_i=0$ 这个尖角处，给普通梯度它也不知道该往哪走。于是论文发明了**伪梯度** $⋄f$，规则只有三种情况：

对第 $i$ 维，记损失项在 0 处的斜率为 $\lambda$（就是 $\frac{\partial \ell}{\partial x_i}$），L1 在 0 处左边斜率 $-C$、右边斜率 $+C$。于是：

- 向右走的斜率：$\partial^{+} = \lambda + C$
- 向左走的斜率：$-\partial^{-} = -(\lambda - C)$

| 情况           | 数学条件         | 伪梯度取值         | 人话                         |
| -------------- | ---------------- | ------------------ | ---------------------------- |
| 左边是下坡     | $\partial^- > 0$ | $⋄_i = \partial^-$ | 想往**左**（负方向）走       |
| 右边是下坡     | $\partial^+ < 0$ | $⋄_i = \partial^+$ | 想往**右**（正方向）走       |
| **两边都上坡** | 其他             | $⋄_i = 0$          | **0 本身就是谷底，待在 0！** |

举个数字例子，设 $C=1$，损失在 0 处斜率 $\lambda = 0.5$：
- $\partial^- = \lambda - C = -0.5$，$\partial^+ = \lambda + C = 1.5$
- 往左走，高度的变化率是 $-(-0.5)=+0.5$（升高）；往右走变化率 $+1.5$（升高）
- **两边都是上坡 → 0 就是谷底 → $⋄_i = 0$，权重保持 0**

**这就是 L1 稀疏性的真身**：凡是"待在 0 更划算"的特征，伪梯度直接给你指到 0，权重从此不动。普通梯度没有这个概念，所以它给不出稀疏解。

（最后一条性质：$x$ 处 $⋄f(x)=0$ ⟺ $x$ 是局部最优。论文第 139 行说的就是这个。）



第 3 步：选象限——有个"免费午餐"

现在伪梯度 $-\diamond f(x_k)$ 指向"下坡那边"。论文选象限的规则（公式 4 后面那个 $\xi^k$）就是：

- $x_i^k \ne 0$ → 沿用它当前的符号；
- $x_i^k = 0$ → 采用 $-\diamond_i f(x_k)$ 的符号（等于告诉它"想往哪边去就选哪边"）。

**妙处**：这样选出来的 $v_k := -\diamond f(x_k)$ **恰好就是**"该象限内 $f_\xi$ 梯度的投影"（脚注 1：投影只是把钉死维度清零）。于是**根本不用真的去构造 $\xi_k$**，直接拿 $-\diamond f(x_k)$ 当梯度用就行，搜索方向：

$$
p_k = \pi(H_k v_k;\ v_k)
$$

一句人话：**"用 L-BFGS 的弯曲度估计 $H_k$ 乘上伪梯度，再把这个方向的符号跟伪梯度对齐。"**



第 4 步：约束线搜索——跨零前踩刹车

方向算好了，走多远由"线搜索"决定。试探点 $x_k + \alpha p_k$ 可能让某个坐标**跨过 0、符号反转**。一旦反转就离开当前象限，$Q_\xi$ 失效了。所以（§3.2）：

$$
x_{k+1} = \pi(x_k + \alpha p_k;\ \xi_k)
$$

**把符号反转的坐标钉回 0**（上一轮你已经弄懂了这个 $\pi$）。然后用钉回后的点检查下降条件：

$$
f(x_{k+1}) \le f(x_k) - \gamma\, v^\top(x_{k+1}-x_k)
$$

不满足就缩小 $\alpha$ 重试（回溯）。$\alpha$ 小到没人跨零时，条件退化成普通 Armijo 规则，必能停下（命题 1）。



## 算法 1：就改 4 处

把标准 L-BFGS 往手里一放，OWL-QN 只动了这些：

| 步   | 标准 L-BFGS                   | OWL-QN                                              |
| ---- | ----------------------------- | --------------------------------------------------- |
| 1    | 梯度 $g_k$                    | **伪梯度** $-\diamond f(x_k)$                       |
| 2    | 方向 $p_k = H_k g_k$ 随便     | 方向**与 $v_k$ 符号对齐**：$p_k=\pi(H_k v_k;\,v_k)$ |
| 3    | 线搜索随便走                  | 试探点**投影回象限**                                |
| 4    | $y_k = g_{k+1}-g_k$（全目标） | $y_k$ 只用**损失 $\ell$ 的梯度**（不掺 L1）         |

改完约 30 行代码，就是全文主角 OWL-QN。

## 公式 ↔ 代码映射

### 1. 伪梯度（公式 4 及其前方左右偏导定义）
```python
if   x_i != 0:  d = g_i + C * sign(x_i)      # ∂f/∂x_i = ℓ'_i + C·σ(x_i)
else:
    if g_i-C > 0:     d = g_i - C            # 左偏导 ∂⁻>0 → 左边下坡
    elif g_i+C < 0:   d = g_i + C            # 右偏导 ∂⁺<0 → 右边下坡
    else:             d = 0                  # 两边都上坡 → 0 是谷底，保持零
v[i] = -d                                    # v = −⋄f(x)
```

### 2. 投影 π（公式下方定义 + 公式 3）
```python
def project(u, guide):
    return np.where(sign(u) == sign(guide), u, 0.0)
# 公式(3): p = project(Hv, v)   —— 方向与 v 同号
# 线搜索: xt = project(x+αp, ξ) —— 跨零分量钉回 0
```

### 3. L-BFGS 的 $H_k v_k$（§2 讲过的"两循环递归"，唯一"重"的部分）
```python
q = v
for s,y in 最近的m对(倒序):  a = sᵀq/(yᵀs);  q -= a*y
r = γ·q                      # γ 是初始缩放（曲率估计）
for s,y in 最近的m对(正序):  β = yᵀr/(yᵀs);  r += (a-β)·s
return r                     # 就是 H_k v_k
```
**内存只存最近 m 对 (s,y)**，百万参数也扛得住。

### 4. 四个改动点（对照标准 L-BFGS）
| 改动 | 代码位置 |
|---|---|
| ① 用伪梯度 | `v = pseudo_gradient(g, C, x)` |
| ② 方向符号对齐 | `p = project(d, v)` |
| ③ 线搜索投影回象限 | `xt = project(x+α·p, ξ)`，准则 `f(xt) ≤ f(x) − γvᵀ(xt−x)` |

#### Q：更普适的优化器（梯度下降 → 近端梯度 → 坐标下降），FTRL是哪种？

都不是——FTRL 不在那张表里，因为它俩是**不同的分类维度**。

| 维度         | 算法                           | 目标                            |
| ------------ | ------------------------------ | ------------------------------- |
| 离线优化算法 | 梯度下降 / 近端梯度 / 坐标下降 | 求 `argmin f(x)` 收敛到极小点   |
| 在线学习框架 | **FTRL** / OMD / 在线梯度下降  | 数据流式到达，最小化累计 regret |

FTRL（Follow The Regularized Leader）属于**在线凸优化**：每步看到一个"全量历史损失"的新目标，然后重新求最优：

```
x_t = argmin_x ( η·Σ_{s<t} g_s·x  +  λ‖x‖₁  +  (1/2η)‖x‖² )
         └── 历史梯度累加 ──┘  └── L1 稀疏 ──┘  └── 稳定项(不让解跳太远) ──┘
```

如果把式子里二次稳定项和二范数正则合并、再求 argmin，它的闭式解**逐坐标就是一个软阈值**（shrinkage）：

```
x_{t+1,i} = sign(θ_i) · max(0, |θ_i| − λη)     // θ = 累加的梯度
```

所以按"机制血缘"对号入座：

- **最接近"在线版的近端梯度"**：软阈值就是 prox 的显式解，和近端梯度、坐标下降产生稀疏的机制**完全同源**；
- 和坐标下降的关系：坐标下降是"一次只优化一个坐标"的离线求解，FTRL 是"每步对全部坐标做一次软阈值"的在线决策；
- 和梯度下降的关系：FTRL 的更新可以改写成"梯度步 + prox 投影"（即 FTRL-Proximal，McMahan 2013），在线梯度下降只是它的退化特例。

顺带一提：FTRL 的理论基础（regret 界）就是你们 2004 那篇 Zhang 论文定理 5.1 那一支血统——所以你已经读过了它的祖先。搞懂 FTRL 不需要新数学，**它就是"在线 + L1 近端"两个你已见过的东西的杂交**。
