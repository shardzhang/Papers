## 原文的语境

这句话出自 2014 年的 Improving Pairwise Learning 论文，它延续的是 **BPR（2009）的假设框架**：

> 在隐式反馈场景中，我们只能观察到**正事件**（点击、购买、观看）。未观察到的数据是**缺失值**（missing data），而非负样本。你不知道用户是没看过、还是看了不喜欢、还是系统根本没推荐。

这是 BPR 论文第 3.2 节的核心假设：

> 训练数据同时包含正对和缺失值。两个未观测 item 之间的缺失值正是未来需要排序的 item 对。

## 你的质疑有道理

你说"曝光 属于隐式反馈，能区分正负类"——这在**拥有完整曝光日志的系统**中是正确的：

| 数据类型 | 含义 | 能否区分正负？ |
|---------|------|--------------|
| 点击 | 用户主动交互 | 正信号 ✅ |
| 曝光未点击 | 展示了但用户没点 | 可视为**弱负信号** |
| 无曝光 | 系统未展示 | **缺失值**（无法判断） |

如果你有完整的曝光日志，**曝光未点击**确实可以作为一种**隐式负反馈**，不再完全是"单类"问题。这也是 YouTube DNN（2016）、Facebook 论文等工业界工作优于 BPR 的原因之一——**它们利用了曝光数据**。

## 结论

| 角度 | 评价 |
|------|------|
| **在 BPR 框架内（2009）** | 正确——当时假设无曝光数据，确实只有正观测 |
| **在完整曝光数据下（现代工业）** | 不准确——曝光未点击可作为负信号 |
| **论文原文说的是哪类** | BPR 框架，假设无曝光数据 |

所以这句话**不是错误**，但需要补充前提：**在没有曝光数据的情况下**，隐式反馈是单类的，只有正观测可用。你有曝光数据时，情况不同。需要我在翻译文件中加注说明吗？

| **高效采样算法**（第 5.3 节） | 利用 FM 的结构特性快速计算 $\hat{r}^{-1}$，避免每次全部排序 |

### 后续如何使用它

公式 (1) 的排名被嵌入到**自适应采样分布**中（公式 14）：

$$
p(j|c) \propto \exp(-\hat{r}(j|c)/\lambda)
$$

- **$\hat{r}(j|c)$ 越小**（item 排名越靠前）→ 指数值越大 → **被采样的概率越高**
- 这比 BPR 的**均匀采样**更高效，因为排名靠前的 item 是"更难区分的负样本"，能提供更大的梯度信号

### 与 BPR 均匀采样的对比

| | BPR 均匀采样 | 论文的自适应采样 |
|--|------------|----------------|
| 采样概率 | $p(j|c) \propto 1$（均匀） | $p(j|c) \propto \exp(-\hat{r}(j|c)/\lambda)$ |
| 偏好 | 所有 item 一视同仁 | 偏好排名靠前的"难负样本" |
| 需要计算 $\hat{r}$ | 不需要 | 需要，但提供了高效近似算法 |

所以公式 (1) 是这个论文**改进 BPR 采样策略的理论基础**——通过显式定义排名 $\hat{r}$，将采样从"均匀"变为"排名-自适应"。





#### 公式10：静态全局流行度采样器

直觉动机

在论文中的角色

这是论文 **3.1 节** 提出的第一个改进基线，思想简单：**对流行 item 过采样**。

为什么有效？

- 若正 item $i$ 是热门的，均匀采样抽到它的概率低
- 若负 item $j$ 也是热门的（模型可能误判为正），则 pair $(c,i,j)$ 的梯度幅度 $\Delta_{c,i,j}$ 大 → 信息量大
- 流行度采样让热门 item 更大概率被选为负样本，从而增加信息性 pair 的比例



**为什么对流行 item 过采样？**

- 假设用户 $u$ 没买过流行 item $i_{pop}$ → $i_{pop}$ 是一个"困难的负样本"（模型容易误判为正）
- 频繁采样这类 item 能产生更大的梯度幅度 $\Delta_{c,i,j}$，加速收敛



静态全局流行度采样器（static global popularity-based sampler），用于替换 BPR 中的均匀负采样。

$$
p(j|c) \propto |\{(c', j') \in S : j = j'\}|. \tag{10}
$$

| 符号                          | 含义                                          |
| ----------------------------- | --------------------------------------------- |
| $p(j|c)$                     | 在上下文 $c$ 下采样 item $j$ 作为负样本的概率 |
| $\propto$                     | 正比于（需归一化才是概率）                    |
| $|\{(c', j') \in S : j = j'\}|$ | 数据集 $S$ 中 item 为 $j$ 的所有正观测的数量   |
| $S$                           | 所有正观测 $(c, i)$ 的集合，每条为 $(c', j')$     |

该公式定义了一个**基于全局流行度的负 item 采样分布**，用于替换 BPR 的均匀采样。



直观理解

**概率 ∝ 流行度**。一个 item 在正观测中出现的次数越多，它被选为负样本的概率就越高。

核心就是**统计 item $j$ 在全局中出现了多少次**——即 item $j$ 的全局流行度。



数学等价形式：

若用 $f(j)$ 表示 item $j$ 的出现频次，采样概率与该计数成正比，则归一化后的概率为：
$$
p(j|c) = \frac{f(j)}{\sum_{j' \in I} f(j')},\quad f(j) = \left|\{(c', j') \in S: j = j'\}\right|
$$



两个关键性质&&缺陷（论文 3.1 节讨论的两点）

1. **静态（Static）**：分布在学习过程中不变化（频次预先算好，固定不变）。训练开始时就固定，不随模型参数 $\Theta$ 变化。而模型学习过程中，item 的估计排名 $\hat{r}(j|c)$ 在变化，采样分布应随之调整。
2. **全局/上下文无关（Global）**：$p(j|c)$ 与 $c$ 无关，对所有上下文都一样。不同用户的"困难负样本"不同，但该分布对所有上下文都一样。例如，一个 item 可能对 A 用户有信息量，对 B 用户则是 trivial 的。



| 问题     | 含义                               | 后果                                                         |
| :------- | :--------------------------------- | :----------------------------------------------------------- |
| **静态** | 分布是预先算好的，不随学习动态变化 | 早期有效，后期模型已学会区分流行 item，采样仍然偏向它们，反而浪费计算 |
| **全局** | $p(j|c)$ 不依赖于上下文 $c$        | 不同用户的"困难负样本"不同，统一对待不合适                   |



与均匀采样对比

|      | 均匀采样 (BPR)   $p(j|c) \propto 1$ | 流行度采样 (10)  $p(j|c) \propto \text{pop}(j)$ |
| :--- | :---------------------------------- | :---------------------------------------------- |
| 偏向 | 所有 item 等概率                    | 流行 item 更大概率                              |
| 动机 | 无偏                                | 流行 item 更可能是"困难负样本"                  |
| 问题 | 大量样本无信息（梯度接近 0）        | 静态 + 全局，长远来看效果仍不佳                 |

公式 (10) 的改进版本是后来提出的 **自适应上下文感知采样器**（公式 14），将 $j$ 的固定流行度替换为模型估计的排名 $\hat{r}(j|c)$：



与公式 (12) / (14) 的关系

| 公式                | 采样策略                | 是否依赖 $c$ | 是否动态变化 | 实现方式                         |
| ------------------- | ----------------------- | ------------ | ------------ | -------------------------------- |
| (10) 全局流行度     | 静态 + 全局             | ❌            | ❌            | 直接统计频次                     |
| (12) 参数化流行度   | 静态 + 全局             | ❌            | ❌            | 几何分布近似                     |
| (14) **自适应采样** | **自适应 + 上下文相关** | ✅            | ✅            | 基于模型预测排名 $\hat{r}(j\|c)$ |

公式 (10) 是论文作为**基线（baseline）**提出的，它比均匀采样好但远不如后面提出的自适应采样器（公式 14），因为它既不区分上下文也不随学习动态调整。

三种采样方式的比较

| 采样策略        | 公式                                         | 上下文感知 | 动态自适应 | 长期效果                 |
| :-------------- | :------------------------------------------- | :--------- | :--------- | :----------------------- |
| 均匀采样 (BPR)  | $p(j|c) \propto 1$                           | ❌          | ❌          | 差（大部分样本无信息）   |
| 流行度采样 (10) | $p(j|c) \propto f(j)$                        | ❌          | ❌          | 中等（短期好、长期停滞） |
| 自适应采样 (14) | $p(j|c) \propto \exp(-\hat{r}(j|c)/\lambda)$ | ✅          | ✅          | **最优**                 |



困惑

直觉上的困惑是：**$S$ 里只有正观测**，为什么用正观测的计数去定义**负采样**？

关键要理解这个逻辑链条：

在隐式反馈中，你只有正例

$S = \{(c', i) \mid \text{用户在上下文 } c' \text{ 下选择了 item } i\}$

不存在"用户没选某个 item"的负例记录。

$f(j)$ 是正例出现频次 = 流行度
$$
f(j) = |\{(c', j') \in S : j = j'\}|
$$

这数的是 **item $j$ 作为正例出现了多少次**。值越大 → item 越热门。



为什么热门 item 适合做负样本？

假设你有一个**热门 item 麦当劳**（$f(\text{麦当劳}) = 10000$）：

1. 用户 Alice 没买过麦当劳 → 这是很强的负信号
2. 模型最初可能误判 Alice 爱麦当劳 → 梯度 $\Delta$ 大 → **信息量大**

假设你有一个**冷门 item 香菜冰淇淋**（$f(\text{香菜冰淇淋}) = 1$）：

1. 用户 Alice 没买过香菜冰淇淋 → 这几乎没信息量
2. 模型早就知道 Alice 不喜欢它 → 梯度 $\Delta$ 接近 0 → **浪费计算**

所以公式 (10) 的逻辑是
$$
p(\text{负item}=j|c) \propto \underbrace{f(j)}_{\text{item 在正例中的频次 = 流行度}}
$$

**用"这个 item 被选为正例的频率"来推测它作为负样本的信息量。**

图示

```
正观测 S:     Alice→麦当劳, Bob→麦当劳, Carol→麦当劳, Alice→KFC, ...
                    ↑                            ↑
item j 的频次 f(j) = 3  (麦当劳出现3次)

作为负采样的概率:   p(麦当劳|c) ∝ 3
                   p(KFC|c)     ∝ 1
                   p(香菜冰淇淋|c)  ∝ 1
```

这就是为什么论文叫它 **pop(ularity)-based sampler**——它不是在数"谁没被选过"（因为数据里没有这个信息），而是在数"谁被选得最多"，然后假设**没选热门 item 比没选冷门 item 更有信息量**。

这个逻辑成立吗？**部分成立**——早期有效，但后期模型已经学会区分热门 item了，再持续偏向它们就浪费了。这引出了论文的核心改进（公式 14）：把固定的 $f(j)$ 换成**动态的预测排名 $\hat{r}(j|c)$**。





#### 公式11：参数化全局流行度采样器

$p(j|c) = \gamma (1 - \gamma)^{r(j)}, \quad \gamma \in (0, 1) \tag{11}$ 

这是论文 3.1 节中**参数化全局流行度采样分布**，是公式 (10) 的解析近似版本。

逐部分拆解

| 符号 | 含义 |
|------|------|
| $p(j|c)$ | 采样 item $j$ 作为负样本的概率（与上下文 $c$ 无关） |
| $\gamma$ | 几何分布的参数，控制分布的"陡峭程度" |
| $r(j)$ | item $j$ 在全局流行度排序中的排名（第 1 是最流行的） |
| $\gamma (1 - \gamma)^{r(j)}$ | 几何分布的概率质量函数 |

数学结构

几何分布的形式

公式 (11) 是一个**以排名为索引的几何分布**：

$$
p(j|c) = \gamma (1 - \gamma)^{r(j)}
$$

- 排名 $r(j) = 1$（最流行 item）：$p = \gamma (1 - \gamma)^1$
- 排名 $r(j) = 2$：$p = \gamma (1 - \gamma)^2$
- 排名 $r(j) = k$：$p = \gamma (1 - \gamma)^k$

排名越靠前（值越小），概率越大。



期望排名

几何分布的期望为：

$$
\mathbb{E}[r] = \frac{1}{\gamma}
$$

例如 $\gamma = 0.1$ 时，期望排名的 item 约为第 10 名。



不同 $\gamma$ 的影响

| $\gamma$ | 期望排名 | 分布形态 | 采样偏向 |
|---------|---------|---------|---------|
| $0.5$ | $2$ | 非常陡峭 | 几乎只采前几名热门 item |
| $0.1$ | $10$ | 中等 | 偏向前 10 名，但也可能有较多样 |
| $0.01$ | $100$ | 平缓 | 近似均匀分布 |



与公式 (10) 的关系与对比



公式 (10) — 经验分布
$$
p(j|c) \propto f(j)
$$

直接用统计频次，无法调整形状。



公式 (11) — 参数化近似

根据论文，实际数据的流行度分布通常近似服从几何分布或 Zipf 分布（如图 1 所示），因此可以用一个简单的解析分布来近似：

```
排名 r = 1: ████████████████████
排名 r = 2: ██████████████
排名 r = 3: ██████████
排名 r = 4: ███████
排名 r = 5: █████
...
         ↓ 下降速度由 γ 控制
```



公式 (12) — 等价参数化形式

论文同时给出了另一种更便于后续推导的参数化形式：

$$
p(j|c) \propto \exp(-r(j)/\lambda), \quad \lambda \in \mathbb{R}^+
$$

其中 $\lambda = -1/\ln(1-\gamma)$，两种形式数学等价。



在论文中的意义

公式 (11) 是公式 (10) → (14) 演化链条中的**中间步骤**：

| 公式 | 采样策略 | 阶段 |
|------|---------|------|
| (10) | $p \propto f(j)$（经验频次） | 基线 — 静态全局 |
| (11)/(12) | $p \propto \gamma(1-\gamma)^{r(j)}$（参数化分布） | 桥接 — 可调参数 $\gamma$ |
| (14) | $p \propto \exp(-\hat{r}(j|c)/\lambda)$（动态排名） | **核心贡献** — 自适应 + 上下文相关 |

引入参数化形式 (11) 的主要目的是**为自适应采样器 (14) 做铺垫**——因为公式 (14) 的核心也是指数形式的分布，只是把**固定的全局排名 $r(j)$ 替换为动态的模型预测排名 $\hat{r}(j|c)$**。
