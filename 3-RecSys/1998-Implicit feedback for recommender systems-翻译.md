# 推荐系统中的隐式反馈

> Douglas W. Oard, Jinmook Kim | 马里兰大学帕克分校图书馆与信息学院数字图书馆研究组

本文探讨隐式反馈能否替代显式评分用于推荐系统。核心内容：

- 识别了三种隐式反馈来源：检查（Examination）、保留（Retention）和引用（Reference）
- 提出了两种使用隐式反馈进行推荐的策略：评分估计策略和预测观察策略
- 隐式反馈可避免收集显式评分的困难，极大扩展推荐系统的应用范围

关键发现：

- 检查类别捕获单次会话中开始和结束的短暂交互，包括选择、持续时间、编辑磨损和重复
- 保留类别将暗示用户有意在未来使用材料的行为归为一组，包括保存引用/对象、打印和删除
- 引用类别包括在信息对象之间创建显式或隐式链接的用户行为
- 两种策略的区别在于推理和预测的顺序：评分估计策略先推理再预测，预测观察策略先预测再推理

---

## 摘要

隐式反馈能否替代推荐系统中的显式评分？如果可以，我们就能避免从用户收集显式评分所带来的困难。那么，我们如何能不引人注地捕获有用信息，以及如何利用这些信息进行推荐？在本文中，我们识别了三种隐式反馈类型，并提出了两种使用隐式反馈进行推荐的策略。

## 引言

推荐系统利用整个用户群体提供的评分来重塑信息空间，以造福一个或多个个体（Oard, 1997b）。在研究系统中，这些评分通常由每个用户使用一个或多个序数或定性量表显式提供。分配准确评分的认知负荷努力起到了抑制作用，使得难以组建大型用户群体，并导致现有群体内的数据稀疏性。隐式反馈技术试图通过从系统可用的观察中推断用户可能分配的评分来避免这一瓶颈。这种方法可以极大地扩展推荐系统有用的应用范围。

## 隐式反馈来源

Nichols（1997）调查了隐式反馈技术的最新进展，着眼于其在信息过滤中的潜在用途。表1展示了Nichols识别的来源以及我们认为也将有用的其他一些来源¹。除了显式评分外，我们识别了三大类潜在有用的观察：检查、保留和引用。

¹ Nichols（1997）提出了与基于内容检索相关的另外两种行为：发现呈现共同查询词集的用户和发现检索相似文档的用户。通过采用查询本身即为信息对象的视角，两者都可以映射到我们的框架中。

信息系统通常使用某种选择界面显示来提供几个有前景文档的简要摘要，因此选择单个对象进行进一步检查可以提供关于用户兴趣的第一个线索。USENET新闻阅读器软件通常记录用户已查看消息的标识符，Karlgren（1994）探索了使用此类列表的推荐系统设计。Morita和Shinoda（1994）以及Konstan等人（1997）在USENET新闻应用中发现阅读时间与显式评分之间存在正相关，我们将该观察来源概括为"检查持续时间"以适应其他模态如音频和视频。Hill等人（1992）进一步发展了这一思想，将"编辑磨损"定义为物理材料随时间积累的不均匀磨损的有用效果的类比，为其他用户提供帮助发现有用材料和这些材料中有用item的线索。例如在文本浏览中，编辑磨损可以通过使用文本中特定位置的停留时间来表征滚动行为来衡量。

检查可能延伸到用户与系统之间的多次交互之外，我们试图通过表征前述用户行为的重复来捕获该观察来源。最后，当信息访问按item定价时，购买决策提供了关于对象所赋价值的极强证据。当用户购买对某些类型内容的订阅访问时（例如订阅单独定价的有线电视频道），也可以在稍粗的尺度上获得类似信息。

**表1：隐式反馈的可观察行为**

| 类别 | 可观察行为 |
|------|-----------|
| 检查 | 选择 |
| | 持续时间 |
| | 编辑磨损 |
| | 重复 |
| | 购买（对象或订阅） |
| 保留 | 保存引用或保存对象（有或无注释）（有或无组织） |
| | 打印 |
| | 删除 |
| 引用 | 对象$\rightarrow$对象（转发、回复、发布后续） |
| | 部分$\rightarrow$对象（超链接、引用） |
| | 对象$\rightarrow$部分（剪切粘贴、引用） |

我们的"保留"类别旨在将那些暗示某种程度上意图在未来使用对象的行为归为一组。为网页添加书签是此类行为的一个简单例子，我们将该思想概括为"保存引用"以适应更广泛的行动，如在文件系统中构建符号链接。例如，Rucker和Polanco（1997）使用书签列表构建了推荐系统。

保存对象本身是明显的选择，Stevens（1993）将其用作基于内容过滤的隐式反馈。在任何一种情况下，对象都可以带有或不带某种形式的注释来保存。例如，网络浏览器通常默认在书签列表中使用页面标题，但如果用户愿意，可以选择性地提供更有意义的条目。尽管可能存在许多混杂因素，但通过用户是否费力构建信息性书签条目，可能推断出用户对单个页面的价值判断。类似地，用户可以选择以显式组织的方式或默认方式保存引用或对象。例如，将关于本次研讨会的电子邮件存储在新文件夹中，可能比使用默认方案（如将其放在通常用于存放来自该发件人邮件的文件夹中）为推断用户赋予消息特殊价值提供更大支持。此案例中的突出问题不是组织行为本身，而是分配给单个对象的组织方式如何区别于分配给其他对象的类似组织方式。这种差异可能不容易表征，但值得思考如何实现。我们将打印归入保留类别是因为打印页面的永久性，但用户也可能打印文档或图像以促进检查，因为纸质在许多应用中仍比电子显示器有明显优势。打印也与下一类别（引用）重叠，因为用户可能打印文档或图像以便转发给他人或将其部分包含在另一个文档中。尽管如此，打印通常与保留的愿望相关，因此我们发现这种分组是有用的。与检查类似，可能从用户选择打印的部分推断出文档中用户认为最有价值的部分。最后，保留类别还因可以直接观察到负面评价的证据而有所区别。当保留是默认条件时（如某些电子邮件系统中），用户删除对象的决定可能支持被删除对象比其他保留对象价值较低的推断。

"引用"类别乍看之下可能包含相当折衷的可观察活动组合，但每种活动都有在两个对象之间建立某种形式链接的效果。例如，转发消息在新消息和原始消息之间建立了链接。类似地，单独回复或向某种形式的群组场所（如邮件列表）发布后续消息建立了相同类型的链接。Goldberg等人（1987）描述了一个简单例子，其中用户可以构建电子邮件过滤器来显示其同事花时间回复的消息。从一个网页到另一个网页的超链接以及学术论文中的书目引用从对象的部分（可能由链接本身周围的某个邻域表征）到另一个对象创建链接，尽管对文档部分的细化尚未被经常利用。Brin和Page（1998）提供了超链接如何被使用的例子，尽管他们的重点是群体统计而非个人偏好。Garfield（1979）描述了基于书目引用的检索系统设计。或者，选择性地包含另一个文档（使用剪切粘贴或引用）从一个信息对象到另一个对象的部分创建链接。

## 使用隐式反馈

推荐系统的目标是帮助用户找到理想的信息对象。该任务结合了推理和预测，图1和图2展示了实现此目标的替代策略。图1描绘了一种模块化策略，其中推理阶段寻求产生类似于用户会显式分配的评分，然后预测阶段使用这些估计评分来预测未来评分。Konstan等人在评估观察到的阅读时间预测单篇文章显式评分的效果时采用了这一视角。图2展示了一种替代策略，其中过去的观察用于预测用户对新信息的行为响应，然后推理阶段试图基于预测行为估计信息的价值。我们不知道这第二种方法的任何实现，但Stevens（1993）实现了该策略的简化版本。他基于过去类似文章的检查持续时间预测新USENET新闻文章的检查持续时间，然后构建会选择预测检查持续时间较长的文章的基于内容的查询。这本质上等同于退化的推理阶段，其中可取性被假设为随检查持续时间单调递增。

**图2：预测观察策略。**

在基于内容过滤的情况下，两种策略的区别相当微妙。相比之下，在推荐系统中，图1所示的策略将使用其他用户报告的检查持续时间来表征每篇文章，而图2所示的策略将使用其他用户的预测评分来表征每篇文章。基于第二种策略的推荐系统可能更灵活，因为如果参与用户不共享共同的目标集，他们可能从相同的观察中得出不同的推断。另一方面，使用第一种策略的推荐系统在本地可能有更多上下文可用于解释观察，而在网络的其他点则不可用。因此，可能值得考虑混合方法，其中在观察进行时在本地执行一些初步解释，然后在网络的其他点得出额外推断。

## 结论

我们提出了隐式反馈的三个潜在来源，并描述了推荐系统使用这些来源的两种方式。我们的"检查"类别旨在捕获在单次会话中开始和结束的短暂交互，而"保留"类别将暗示用户有意在未来使用材料的行为归为一组。我们的第三类是引用，包括在信息对象之间创建显式或隐式链接的用户行为。我们认为这些类别以一种在思考如何进行预测时有用的方式对可观察行为进行分组，为此我们提出了在推荐系统中使用隐式反馈的两种策略。我们当前的工作重点是理解如何将观察与预测评分相关联，无论是单独还是以各种可能比单源观察更具信息量的组合。然后我们希望开发和实现一个原型，使我们能够深入了解隐式反馈如何在应用环境中有效使用。如果成功，这种方法可以帮助超越当前对显式评分的依赖，从而显著扩展推荐系统在网络世界中的影响和重要性。
