五、困难负例 vs 简单负例：训练动态的差异

困难负例和简单负例对训练的影响有本质差异。简单负例让模型学到的决策边界宽松——模型只需要把完全不相关的物品排出去。困难负例迫使模型学习更精细的边界——要区分语义相近但用户偏好不同的物品。Cluster GOOBS 的混合采样（in-batch 简单负例 + 簇内困难负例）兼顾了两种信号。

从训练动态看，简单负例在训练早期提供基础信号——模型先学会区分明显不相关的物品。随着训练进行，简单负例的梯度逐渐减小（模型已经能轻松区分它们），此时困难负例的作用凸显——它们持续提供大梯度，推动模型学习精细判别。如果只用简单负例，训练中后期模型几乎不更新，性能停滞；加入困难负例后，模型能持续学习，性能持续提升。

困难负例的比例需要平衡。太多困难负例会让模型过度关注难区分的边界，可能损害对正例本身的建模（模型变得过于保守，把一些真正相关的物品也排除了）。太少困难负例又起不到足够挑战。论文通过实验确定了混合比例，in-batch 负例提供基础信号，簇内困难负例提供挑战信号，两者协同。这个比例在不同场景可能需要调整，但论文的配置可以作为起点。





六、公开数据集验证：超越主流方法

论文在公开数据集上验证了 Cluster GOOBS 的有效性，对比的基线包括 in-batch 负采样、OOB 负采样、CBNS（基于类别的簇负采样）、DNS（动态负采样）、ANCE（近似最近邻负采样）。这些方法覆盖了从简单到复杂的负采样谱系，对比结果能清晰定位 Cluster GOOBS 的优势。
