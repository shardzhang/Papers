# FM: Factorization Machines





业务场景：无

业务指标：无

离线指标：无

数据集：无

模型类型：不限制，可以做回归，可以分类（点击率预估）

创新点：

- 解决真实工业界高维稀疏数据中，传统模型面对极度稀疏数据难以学习的痛点，提出通过对每个特征构造一个emb向量，能够跨特征跨样本共享，将两个特征共现参数的学习变为单个特征独立学习，解决稀疏学习问题。
- 通过因子化参数建模特征交叉，把二次项改为隐向量内积，解决稀疏下的参数估计，同时满足线性时间复杂度。
- 将SVD++仅支持物品和用户id交叉，通用化为支持多个特征域的特征交叉。
