## 摘要 (Abstract)

大规模图中节点的低维嵌入在各种预测任务中被证明极为有用，从内容推荐到识别蛋白质功能。然而，大多数现有方法要求图中的所有节点在嵌入训练期间都存在；这些先前的方法本质上是直推式的，不能自然地泛化到未见过的节点。在本文中，我们提出了GraphSAGE，一个通用的归纳式框架，它利用节点特征信息（例如文本属性）来高效地为先前未见过的数据生成节点嵌入。我们不训练每个节点的单独嵌入，而是学习一个函数，该函数通过从节点的局部邻域中采样和聚合特征来生成嵌入。我们的算法在三个归纳式节点分类基准上优于强基线：我们根据引文和Reddit帖子数据对演化信息图中未见节点的类别进行分类，并且我们展示了我们的算法使用蛋白质-蛋白质相互作用的多图数据集泛化到完全未见过的图。

## 1 引言 (Introduction)

大规模图中节点的低维向量嵌入作为各种预测和图分析任务的特征输入已被证明极为有用[5, 11, 28, 35, 36]。节点嵌入方法背后的基本思想是使用降维技术将节点图邻域的高维信息提炼为密集向量嵌入。这些节点嵌入随后可以被输入到下游机器学习系统中，并有助于节点分类、聚类和链接预测等任务[11, 28, 35]。

然而，先前的工作集中在从单个固定图中嵌入节点，而许多实际应用要求为未见过的节点或全新的（子）图快速生成嵌入。这种归纳式能力对于高吞吐量的生产机器学习系统至关重要，这些系统在演化的图上运行并不断遇到未见过的节点（例如Reddit上的帖子、Youtube上的用户和视频）。一种生成节点嵌入的归纳式方法也促进了具有相同形式特征的图之间的泛化：例如，可以在从模式生物衍生的蛋白质-蛋白质相互作用图上训练嵌入生成器，然后使用训练好的模型轻松地为新生物体收集的数据生成节点嵌入。

与直推式设置相比，归纳式节点嵌入问题尤其困难，因为泛化到未见过的节点需要将新观察到的子图与算法已经优化过的节点嵌入进行"对齐"。归纳式框架必须学会识别节点邻域的结构属性，这些属性既揭示了节点在图中的局部角色，也揭示了其全局位置。

大多数现有的节点嵌入生成方法本质上是直推式的。这些方法中的大多数直接使用基于矩阵分解的目标优化每个节点的嵌入，并且不能自然地泛化到未见过的数据，因为它们在单个固定图上对节点进行预测[5, 11, 23, 28, 35, 36, 37, 39]。这些方法可以被修改以在归纳式设置中运行（例如[28]），但这些修改往往计算成本高昂，需要在做出新预测之前进行额外的梯度下降轮次。最近也有使用卷积算子在图结构上学习的方法，这为嵌入方法论提供了前景[17]。到目前为止，图卷积网络（GCN）仅在具有固定图的直推式设置中得到应用[17, 18]。在这项工作中，我们既将GCN扩展到归纳式无监督学习的任务，也提出了一个将GCN方法推广到使用可训练聚合函数（超出简单卷积）的框架。

当前工作。我们提出了一个通用框架，称为GraphSAGE（SAmple and aggreGatE），用于归纳式节点嵌入。与基于矩阵分解的嵌入方法不同，我们利用节点特征（例如文本属性、节点档案信息、节点度数）来学习一个泛化到未见节点的嵌入函数。通过在算法中融入节点特征，我们同时学习每个节点邻域的拓扑结构以及邻域中节点特征的分布。虽然我们专注于特征丰富的图（例如具有文本属性的引文数据、具有功能/分子标记的生物数据），但我们的方法也可以利用所有图中都存在的结构特征（例如节点度数）。因此，我们的算法也可以应用于没有节点特征的图。

我们不训练每个节点的不同嵌入向量，而是训练一组聚合函数，这些函数学习从节点的局部邻域聚合特征信息（图1）。每个聚合函数从距离给定节点不同数量的跳数或搜索深度聚合信息。在测试或推断时，我们通过应用学到的聚合函数为完全未见过的节点生成嵌入。遵循先前关于生成节点嵌入的工作，我们设计了一个无监督损失函数，使得GraphSAGE可以在没有任务特定监督的情况下进行训练。我们还展示了GraphSAGE可以以完全监督的方式进行训练。

我们在三个节点分类基准上评估我们的算法，这些基准测试GraphSAGE在未见数据上生成有用嵌入的能力。我们使用两个基于引文数据和Reddit帖子数据的演化文档图（分别预测论文和帖子类别），以及一个基于蛋白质-蛋白质相互作用数据集（预测蛋白质功能）的多图泛化实验。使用这些基准，我们展示了我们的方法能够有效地为未见节点生成表示，并以显著优势超越相关基线：在各个领域，我们的监督方法与单独使用节点特征相比，分类F1分数平均提高了51%，并且GraphSAGE始终优于强直推式基线[28]，尽管该基线在未见节点上的运行时间长约100倍。我们还展示了我们提出的新聚合器架构与受图卷积网络[17]启发的聚合器相比，提供了显著的增益（平均7.4%）。最后，我们探究了我们方法的表达能力，并通过理论分析表明，GraphSAGE能够学习关于节点在图中的角色的结构信息，尽管它本质上基于特征（第5节）。

## 2 相关工作 (Related work)

我们的算法在概念上与先前的节点嵌入方法、在图上的通用监督学习方法以及将卷积神经网络应用于图结构数据的最新进展相关。

基于分解的嵌入方法。最近有许多节点嵌入方法，它们使用随机游走统计和基于矩阵分解的学习目标来学习低维嵌入[5, 11, 28, 35, 36]。这些方法也与更经典的谱聚类[23]、多维缩放[19]以及PageRank算法[25]密切相关。由于这些嵌入算法直接训练单个节点的嵌入，它们本质上是直推式的，并且至少需要代价高昂的额外训练（例如通过随机梯度下降）才能对新节点进行预测。此外，对于许多这些方法（例如[11, 28, 35, 36]），目标函数对嵌入的正交变换是不变的，这意味着嵌入空间不能自然地泛化到图之间，并且可能在重新训练期间发生漂移。这一趋势的一个显著例外是Yang等人[40]提出的Planetoid-I算法，这是一种基于嵌入的归纳式半监督学习方法。然而，Planetoid-I在推断期间不使用任何图结构信息；相反，它在训练期间将图结构用作一种正则化形式。与这些先前方法不同，我们利用特征信息来训练一个模型，为未见节点生成嵌入。

在图上的监督学习。除了节点嵌入方法之外，关于图结构数据上的监督学习有丰富的文献。这包括各种基于核的方法，其中图的特征向量从各种图核中导出（参见[32]及其参考文献）。最近还有许多神经网络方法用于图结构上的监督学习[7, 10, 21, 31]。我们的方法在概念上受到这些算法的启发。然而，这些先前方法试图对整个图（或子图）进行分类，而本工作的重点是为单个节点生成有用的表示。

图卷积网络。近年来，已经提出了几种用于在图上学学习的卷积神经网络架构（例如[4, 9, 8, 17, 24]）。这些方法中的大多数不能扩展到大规模图，或者是为整图分类设计的（或两者兼有）[4, 9, 8, 24]。然而，我们的方法与Kipf等人[17, 18]引入的图卷积网络（GCN）密切相关。原始的GCN算法[17]是为直推式设置中的半监督学习设计的，并且该精确算法要求在训练期间已知完整的图拉普拉斯矩阵。我们算法的一个简单变体可以被视为GCN框架到归纳式设置的扩展，我们在第3.3节中重新讨论这一点。

## 3 提出的方法：GraphSAGE (Proposed method: GraphSAGE)

我们方法背后的关键思想是我们学习如何从节点的局部邻域聚合特征信息（例如附近节点的度数或文本属性）。我们首先描述GraphSAGE嵌入生成（即前向传播）算法，该算法假设GraphSAGE模型参数已经学习完毕（第3.1节），然后描述如何使用标准随机梯度下降和反向传播技术学习GraphSAGE模型参数（第3.2节）。

### 3.1 嵌入生成（即前向传播）算法 (Embedding generation (i.e., forward propagation) algorithm)

在本节中，我们描述嵌入生成或前向传播算法（算法1），该算法假设模型已经训练完毕且参数已固定。具体来说，我们假设已经学习了K个聚合器函数（记为AGGREGATEk, ∀k ∈ {1, ..., K}）的参数，这些函数从节点邻居聚合信息，以及一组权重矩阵Wk, ∀k ∈ {1, ..., K}，用于在模型的不同层或"搜索深度"之间传播信息。第3.2节描述了我们如何训练这些参数。

算法1：GraphSAGE嵌入生成（即前向传播）算法

输入：图G(V, E)；输入特征{xv, ∀v ∈ V}；深度K；权重矩阵Wk, ∀k ∈ {1, ..., K}；非线性函数σ；可微聚合器函数AGGREGATEk, ∀k ∈ {1, ..., K}；邻域函数N : v → 2^V

输出：所有v ∈ V的向量表示zv

1. h0_v ← xv, ∀v ∈ V
2. for k = 1...K do
3.   for v ∈ V do
4.     hk_N(v) ← AGGREGATEk({hk-1_u, ∀u ∈ N(v)})
5.     hk_v ← σ(Wk · CONCAT(hk-1_v, hk_N(v)))
6.     hk_v ← hk_v/||hk_v||2, ∀v ∈ V
7.   end
8. end
9. zv ← hK_v, ∀v ∈ V

算法1背后的直觉是，在每次迭代或搜索深度，节点从它们的局部邻居聚合信息，随着这个过程不断迭代，节点逐渐从图的更远范围获得越来越多的信息。

算法1描述了当整个图G = (V, E)以及所有节点xv, ∀v ∈ V的特征作为输入提供时的嵌入生成过程。我们在下面描述如何将其推广到小批量设置。算法1外循环中的每一步如下进行，其中k表示外循环中的当前步骤（或搜索深度），hk表示节点在此步骤的表示：首先，每个节点v ∈ V聚合其直接邻域中节点的表示{hk-1_u, ∀u ∈ N(v)}，得到聚合后的邻域向量hk_N(v)。注意这个聚合步骤依赖于外循环上一次迭代（即k-1）生成的表示，k=0（"基本情况"）的表示定义为输入节点特征。聚合邻域特征向量后，GraphSAGE将节点当前表示hk-1_v与聚合后的邻域向量hk_N(v)拼接起来，然后将这个拼接后的向量送入带有非线性激活函数σ的全连接层，该层将表示转换为在算法下一步要使用的形式（即hk_v, ∀v ∈ V）。为符号方便，我们将深度K处输出的最终表示记为zv ≡ hK_v, ∀v ∈ V。邻居表示的聚合可以通过多种聚合器架构完成（由算法1中的AGGREGATE占位符表示），我们在下面的第3.3节讨论不同的架构选择。

为了将算法1扩展到小批量设置，给定一组输入节点，我们首先前向采样所需的邻域集合（直到深度K），然后运行内循环（算法1中的第3行），但不再迭代所有节点，而是只计算满足每个深度递归所需的表示（附录A包含完整的小批量伪代码）。

与Weisfeiler-Lehman同构测试的关系。GraphSAGE算法在概念上受到一个经典图同构测试算法的启发。如果在算法1中，我们(i)设置K = |V|, (ii)将权重矩阵设置为单位矩阵，以及(iii)使用适当的哈希函数作为聚合器（无非线性），那么算法1就是Weisfeiler-Lehman（WL）同构测试的一个实例，也称为"朴素顶点细化"[32]。如果算法1为两个子图输出的表示集{zv, ∀v ∈ V}相同，则WL测试宣称这两个子图是同构的。这个测试在某些情况下会失败，但对于一大类图是有效的[32]。GraphSAGE是WL测试的连续近似，其中我们将哈希函数替换为可训练的神经网络聚合器。当然，我们使用GraphSAGE来生成有用的节点表示——而不是测试图同构。尽管如此，GraphSAGE与经典WL测试之间的联系为我们算法设计学习节点邻域拓扑结构提供了理论背景。

邻域定义。在这项工作中，我们对固定大小的邻居集进行均匀采样，而不是在算法1中使用完整的邻域集，以保持每个批次的计算开销固定。也就是说，使用重载的符号，我们将N(v)定义为从集合{u ∈ V : (u, v) ∈ E}中的固定大小的均匀采样，并在算法1的每次迭代k中采样不同的均匀样本。没有这种采样，单个批次的内存和预期运行时间是不可预测的，在最坏情况下为O(|V|)。相比之下，GraphSAGE的每批次空间和时间复杂度固定在O(∏K_i=1 Si)，其中Si, i ∈ {1, ..., K}和K是用户指定的常数。实际中我们发现，我们的方法可以在K=2且S1·S2 ≤ 500的情况下达到高性能（详见第4.4节）。

### 3.2 学习GraphSAGE的参数 (Learning the parameters of GraphSAGE)

为了在完全无监督的设置中学习有用的、可预测的表示，我们将基于图的损失函数应用于输出表示zu, ∀u ∈ V，并通过随机梯度下降调整权重矩阵Wk, ∀k ∈ {1, ..., K}和聚合器函数的参数。基于图的损失函数鼓励附近节点具有相似的表示，同时强制不同节点的表示高度区分：

JG(zu) = -log(σ(zu^T zv)) - Q · E_vn∼Pn(v) log(σ(-zu^T z_vn)), (1)

其中v是在固定长度随机游走中与u共现的节点，σ是sigmoid函数，Pn是负采样分布，Q定义了负样本的数量。重要的是，与先前的嵌入方法不同，我们输入到这个损失函数中的表示zu是从节点局部邻域中包含的特征生成的，而不是为每个节点训练唯一的嵌入（通过嵌入查找表）。

这种无监督设置模拟了节点特征作为服务或静态存储库提供给下游机器学习应用的情况。在表示仅用于特定下游任务的情况下，无监督损失（公式1）可以简单地被任务特定目标（例如交叉熵损失）替换或增强。

### 3.3 聚合器架构 (Aggregator Architectures)

与N维网格（例如句子、图像或3D体积）上的机器学习不同，节点的邻居没有自然的排序；因此，算法1中的聚合器函数必须在一个无序的向量集上操作。理想情况下，聚合器函数应该是对称的（即对其输入的排列不变），同时仍然可训练并保持高表示能力。聚合函数的对称性属性确保我们的神经网络模型可以训练并应用于任意排序的节点邻域特征集。我们研究了三种候选聚合器函数：

均值聚合器 (Mean aggregator)。我们的第一个候选聚合器函数是均值算子，我们只需取向量集{hk-1_u, ∀u ∈ N(v)}的元素级均值。均值聚合器几乎等价于直推式GCN框架[17]中使用的卷积传播规则。具体来说，我们可以通过将算法1中的第4行和第5行替换为以下内容来推导GCN方法的归纳式变体：

hk_v ← σ(W · MEAN({hk-1_v} ∪ {hk-1_u, ∀u ∈ N(v)})). (2)

我们将这种改进的基于均值的聚合器称为卷积聚合器，因为它是局部谱卷积的粗略线性近似[17]。这个卷积聚合器与我们提出的其他聚合器之间的一个重要区别是它不执行算法1中第5行的拼接操作——即卷积聚合器不将节点的前一层表示hk-1_v与聚合后的邻域向量hk_N(v)拼接起来。这种拼接可以被视为GraphSAGE算法不同"搜索深度"或"层"之间的一种简单形式的"跳跃连接"[13]，并且它带来了显著的性能提升（第4节）。

LSTM聚合器 (LSTM aggregator)。我们还研究了一种基于LSTM架构的更复杂的聚合器[14]。与均值聚合器相比，LSTM具有更大的表达能力优势。然而，需要注意的是LSTM本质上不是对称的（即它们不是排列不变的），因为它们以顺序方式处理输入。我们通过简单地将LSTM应用于节点邻居的随机排列来使其适应无序集。

池化聚合器 (Pooling aggregator)。我们研究的最后一个聚合器既是对称的又是可训练的。在这种池化方法中，每个邻居的向量被独立地送入一个全连接神经网络；在此变换之后，应用元素级最大池化操作来聚合整个邻居集的信息：

AGGREGATE_pool_k = max({σ(W_pool hk_ui + b), ∀ui ∈ N(v)}), (3)

其中max表示元素级最大运算符，σ是非线性激活函数。原则上，最大池化之前应用的函数可以是任意深度的多层感知器，但我们在本文中专注于简单的单层架构。这种方法受到最近将神经网络架构应用于在一般点集上学习的进展的启发[29]。直观上，多层感知器可以被视为一组函数，这些函数为邻居集中的每个节点表示计算特征。通过对每个计算出的特征应用最大池化算子，模型有效地捕捉了邻居集的不同方面。另外注意，原则上任何对称向量函数都可以用来替代最大运算符（例如元素级均值）。我们在开发测试中发现最大和均值池化之间没有显著差异，因此在其余实验中专注于最大池化。

## 4 实验 (Experiments)

我们在三个基准任务上测试GraphSAGE的性能：(i)使用Web of Science引文数据集将学术论文分类到不同学科，(ii)将Reddit帖子分类为属于不同社区，以及(iii)跨各种生物蛋白质-蛋白质相互作用（PPI）图分类蛋白质功能。第4.1和4.2节总结了数据集，补充材料包含额外信息。在所有这些实验中，我们对训练期间未见过的节点进行预测，并且在PPI数据集的情况下，我们在完全未见过的图上进行测试。

实验设置。为了将归纳式基准上的实验结果置于上下文中，我们与四个基线进行比较：随机分类器、基于逻辑回归特征的分类器（忽略图结构）、DeepWalk算法[28]作为代表性的基于分解的方法，以及原始特征和DeepWalk嵌入的拼接。我们还比较了使用不同聚合器函数的四个GraphSAGE变体（第3.3节）。由于GraphSAGE的"卷积"变体是Kipf等人半监督GCN[17]的扩展归纳式版本，我们将此变体称为GraphSAGE-GCN。我们测试了根据公式(1)中损失训练的GraphSAGE无监督变体，以及直接在分类交叉熵损失上训练的监督变体。对于所有GraphSAGE变体，我们使用修正线性单元作为非线性函数，并设置K=2，邻域采样大小S1=25和S2=10（详见第4.4节的敏感性分析）。

对于Reddit和引文数据集，我们使用Perozzi等人[28]所述的DeepWalk"在线"训练，在预测前运行新一轮SGD优化来嵌入新的测试节点（详见附录）。在多图设置中，我们无法应用DeepWalk，因为在不同不相交图上运行DeepWalk算法生成的嵌入空间可以相对于彼此任意旋转（附录D）。

所有模型在TensorFlow[1]中实现，使用Adam优化器[16]（DeepWalk除外，它在普通梯度下降优化器上表现更好）。我们设计实验的目标是(i)验证GraphSAGE相比基线方法（即原始特征和DeepWalk）的改进，以及(ii)提供不同GraphSAGE聚合器架构之间的严格比较。为了提供公平比较，所有模型共享相同的小批量迭代器、损失函数和邻域采样器（如适用）的实现。此外，为了防止GraphSAGE聚合器之间的比较中出现无意的"超参数篡改"，我们对所有GraphSAGE变体使用相同的超参数集进行扫描（根据验证集上的表现为每个变体选择最佳设置）。超参数值的可能范围是在使用引文和Reddit数据子集进行的早期验证测试中确定的，这些数据随后从我们的分析中删除。附录包含进一步的实现细节。

### 4.1 演化图上的归纳式学习：引文和Reddit数据 (Inductive learning on evolving graphs: Citation and Reddit data)

我们的前两个实验是在演化信息图上对节点进行分类，这个任务与不断遇到未见数据的高吞吐量生产系统尤其相关。

引文数据。我们的第一个任务是在大型引文数据集上预测论文主题类别。我们使用来自Thomson Reuters Web of Science核心合集的无向引文图数据集，对应2000-2005年间六个生物学相关领域的所有论文。该数据集的节点标签对应于六个不同的领域标签。总计，该数据集包含302,424个节点，平均度为9.15。我们在2000-2004年数据上训练所有算法，并使用2005年数据进行测试（30%用于验证）。对于特征，我们使用了节点度数，并根据Arora等人[2]的句子嵌入方法处理了论文摘要，使用基于GenSim word2vec实现[30]训练的300维词向量。

Reddit数据。在我们的第二个任务中，我们预测不同的Reddit帖子属于哪个社区。Reddit是一个大型在线讨论论坛，用户在不同主题社区中发布和评论内容。我们从2014年9月发布的Reddit帖子构建了一个图数据集。此情况下的节点标签是帖子所属的社区或"subreddit"。我们采样了50个大型社区，并构建了一个帖子-帖子图，如果同一用户评论了两个帖子，则连接它们。总计，该数据集包含232,965个帖子，平均度为492。我们使用前20天进行训练，剩余天数用于测试（30%用于验证）。对于特征，我们使用现成的300维GloVe CommonCrawl词向量[27]；对于每个帖子，我们拼接了(i)帖子标题的平均嵌入，(ii)帖子所有评论的平均嵌入，(iii)帖子的得分，以及(iv)帖子的评论数。

表1的前四列总结了GraphSAGE以及基线方法在这两个数据集上的性能。我们发现GraphSAGE以显著优势优于所有基线，并且可训练的神经网络聚合器相比GCN方法提供了显著的增益。例如，无监督变体GraphSAGE-pool在引文数据上比DeepWalk嵌入与原始特征的拼接高出13.8%，在Reddit数据上高出29.1%，而监督版本分别提供19.7%和37.2%的增益。有趣的是，基于LSTM的聚合器表现出强劲的性能，尽管它是为序列数据而非无序集设计的。最后，我们看到无监督GraphSAGE的性能与完全监督版本相当有竞争力，表明我们的框架可以在没有任务特定微调的情况下实现强劲性能。

### 4.2 跨图泛化：蛋白质-蛋白质相互作用 (Generalizing across graphs: Protein-protein interactions)

我们现在考虑跨图泛化的任务，这需要学习节点角色而非社区结构。我们在各种蛋白质-蛋白质相互作用（PPI）图中对蛋白质角色进行分类（依据其来自基因本体的细胞功能），每个图对应一个不同的人体组织[41]。我们使用位置基因集、基序基因集和免疫学特征作为特征，并使用基因本体集作为标签（共121个），来自分子特征数据库[34]。平均每个图包含2373个节点，平均度为28.8。我们在20个图上训练所有算法，然后在两个测试图上平均预测F1分数（另外两个图用于验证）。

### 4.3 运行时间和参数敏感性 (Runtime and parameter sensitivity)

图2.A总结了不同方法的训练和测试运行时间。这些方法的训练时间相当（GraphSAGE-LSTM最慢）。然而，需要采样新的随机游走并运行新轮次的SGD来嵌入未见节点使得DeepWalk在测试时慢100-500倍。

对于GraphSAGE变体，我们发现设置K=2相比K=1平均提供约10-15%的持续准确率提升；然而，将K增加到2以上带来的性能回报边际（0-5%），同时运行时间增加了禁止性的10-100倍（取决于邻域采样大小）。我们还发现采样大邻域存在边际收益递减（图2.B）。因此，尽管子采样邻域引入了更高方差，GraphSAGE仍然能够维持强大的预测准确性，同时显著改善运行时间。

### 4.4 不同聚合器架构的总结比较 (Summary comparison between the different aggregator architectures)

总体而言，我们发现基于LSTM和基于池化的聚合器在平均性能和作为最优方法的实验设置数量方面表现最佳（表1）。为了对这些趋势提供更多定量洞见，我们将六个不同的实验设置（即（3个数据集）×（无监督 vs. 监督））视为试验，并考虑哪些性能趋势可能泛化。具体来说，我们使用非参数Wilcoxon符号秩检验[33]来量化不同聚合器在试验中的差异，并在适用时报告T统计量和p值。注意此方法基于排序，本质上测试是否我们预期一种特定方法在另一种方法之上在新的实验设置中表现更优。考虑到我们只有6个不同设置的小样本量，这个显著性检验有些统计功效不足；尽管如此，T统计量和相关的p值是评估聚合器相对性能的有用定量度量。

我们看到基于LSTM、基于池化和基于均值的聚合器都提供了相对于基于GCN方法的统计显著增益（三者均为T=1.0, p=0.02）。然而，LSTM和池化方法相对于基于均值的聚合器的增益更为边际（LSTM vs. 均值：T=1.5, p=0.03；池化 vs. 均值：T=4.5, p=0.10）。LSTM和池化方法之间没有显著差异（T=10.0, p=0.46）。然而，GraphSAGE-LSTM比GraphSAGE-pool慢得多（约2倍），这可能使基于池化的聚合器总体上略占优势。

## 5 理论分析 (Theoretical analysis)

在本节中，我们探究GraphSAGE的表达能力，以深入了解GraphSAGE如何学习图结构，尽管它本质上基于特征。作为一个案例研究，我们考虑GraphSAGE是否能学习预测节点的聚类系数，即节点1 hop邻域内闭合三角形的比例[38]。聚类系数是衡量节点局部邻域聚类程度的流行度量，它是许多更复杂结构基序的构建块[3]。我们可以证明算法1能够以任意精度逼近聚类系数：

定理1. 设xv ∈ U, ∀v ∈ V表示图G = (V, E)上算法1的特征输入，其中U是Rd的任意紧子集。假设存在一个固定的正常数C ∈ R+，使得对所有节点对都有||xv - xv'||2 > C。那么∀ε > 0，存在算法1的参数设置Θ*，使得在K = 4次迭代后

|zv - cv| < ε, ∀v ∈ V,

其中zv ∈ R是算法1生成的最终输出值，cv是节点聚类系数。

定理1表明，对于任何图，如果每个节点的特征都是不同的（且模型维度足够高），则存在算法1的参数设置使其能够以任意精度逼近该图中的聚类系数。定理1的完整证明在附录中。注意作为定理1的推论，即使节点特征输入来自绝对连续随机分布，GraphSAGE也能学习局部图结构（详见附录）。证明的基本思想是，如果每个节点都有唯一的特征表示，那么我们可以学习将节点映射到指示向量并识别节点邻域。定理1的证明依赖于池化聚合器的一些性质，这也揭示了为什么GraphSAGE-pool优于GCN和基于均值的聚合器。

## 6 结论 (Conclusion)

我们引入了一种新颖的方法，使得能够为未见节点高效生成嵌入。GraphSAGE始终优于最先进的基线，通过采样节点邻域有效权衡了性能和运行时间，并且我们的理论分析提供了关于我们的方法如何学习局部图结构的洞见。许多扩展和潜在改进是可能的，例如将GraphSAGE扩展到有向图或多模态图。未来工作一个特别有趣的方向是探索非均匀邻域采样函数，甚至可能将这些函数的学习作为GraphSAGE优化的一部分。

### A 小批量伪代码 (Minibatch pseudocode)

为了使用随机梯度下降，我们调整算法以允许节点和边的小批次的前向和后向传播。这里我们专注于小批次前向传播算法，类似于算法1。在GraphSAGE的前向传播中，小批量B包含我们要为其生成表示的节点。算法2给出了小批量方法的伪代码。

算法2：GraphSAGE小批次前向传播算法

输入：图G(V, E)；输入特征{xv, ∀v ∈ B}；深度K；权重矩阵Wk, ∀k ∈ {1, ..., K}；非线性函数σ；可微聚合器函数AGGREGATEk, ∀k ∈ {1, ..., K}；邻域采样函数Nk : v → 2^V, ∀k ∈ {1, ..., K}

输出：所有v ∈ B的向量表示zv

1. BK ← B
2. for k = K...1 do
3.   Bk-1 ← Bk
4.   for u ∈ Bk do
5.     Bk-1 ← Bk-1 ∪ Nk(u)
6.   end
7. end
8. h0_v ← xv, ∀v ∈ B0
9. for k = 1...K do
10.  for u ∈ Bk do
11.    hk_N(u) ← AGGREGATEk({hk-1_u', ∀u' ∈ Nk(u)})
12.    hk_u ← σ(Wk · CONCAT(hk-1_u, hk_N(u)))
13.    hk_u ← hk_u/||hk_u||2
14.  end
15. end
16. zu ← hK_u, ∀u ∈ B

主要思想是首先采样计算所需的所有节点。算法2的第2-7行对应采样阶段。每个集合Bk包含计算节点v ∈ Bk+1表示所需的节点，即算法1的第(k+1)次迭代或"层"中的节点。第9-15行对应聚合阶段，这与批量推断算法几乎相同。注意在第12和13行，可以计算集合Bk中任何节点在迭代k的表示，因为它在迭代k-1的表示及其采样邻居在迭代k-1的表示已经在之前的循环中计算完毕。该算法因此避免为不在当前小批次中且不在当前随机梯度下降迭代期间使用的节点计算表示。我们使用符号Nk(u)表示一个确定性函数，它指定节点邻域的随机样本（即随机性被假定为在映射中预先计算）。我们用k索引此函数以表示随机样本在k的迭代之间是独立的。我们在此工作中使用均匀采样函数，并在样本大小大于节点度数时进行有放回采样。

注意算法2中的采样过程在概念上与算法1中k的迭代顺序相反：我们从想要生成表示的"第K层"节点（即B中的节点）开始；然后我们采样它们的邻居（即算法的"第K-1层"节点），依此类推。这样做的一个后果是邻域采样大小的定义可能有些反直觉。具体来说，如果我们使用K=2次总迭代，采样大小S1和S2，这意味着我们在算法1的迭代k=1期间采样S1个节点，在迭代k=2期间采样S2个节点，并且——从我们想要在经过迭代k=2后生成表示的B中的"目标"节点的角度来看——这相当于采样S2个它们的一跳邻居和S1·S2个它们的二跳邻居。

### C 实验设置和超参数调优的细节 (Details on the Experimental Setup and Hyperparameter Tuning)

无监督目标的随机游走 对于所有设置，我们从每个节点运行50次长度为5的随机游走，以获得无监督损失所需的节点对（公式1）。我们的随机游走实现是纯Python的，直接基于Perozzi等人[28]提供的Python代码。

逻辑回归模型 对于仅特征模型以及用于对无监督模型输出的嵌入进行预测，我们使用了scikit-learn Python包[26]中的逻辑SGDClassifier，使用所有默认设置。注意该模型始终只在训练节点上进行优化，不对测试数据生成的嵌入进行微调。

超参数选择 在所有设置中，我们对学习率和模型维度进行超参数选择。除DeepWalk外，我们对监督模型的初始学习率在{0.01, 0.001, 0.0001}范围内进行参数扫描，对无监督模型在{2×10^-6, 2×10^-7, 2×10^-8}范围内进行扫描。在适用的情况下，我们测试了每个模型的"大"和"小"版本，并尝试保持总体模型大小可比。对于池化聚合器，"大"模型的池化维度为1024，而"小"模型维度为512。对于LSTM聚合器，"大"模型的隐藏维度为256，而"小"模型隐藏维度为128；注意LSTM的实际参数数量大约是这个数字的4倍，因为不同门有权重。在所有实验和所有模型中，我们将递归中每个深度k的hk向量输出维度指定为256。所有模型使用修正线性单元作为非线性激活函数。所有无监督GraphSAGE模型和DeepWalk使用20个负样本，使用0.75的平滑参数对节点度数进行上下文分布平滑，遵循[11, 22, 28]。初步实验显示DeepWalk在较大学习率下表现更好，因此我们在{0.2, 0.4, 0.8}范围内扫描了学习率。对于监督式GraphSAGE方法，所有模型运行10个epoch。除DeepWalk外的所有方法使用512的批次大小。我们发现DeepWalk使用较小的64批次大小可以达到更快的墙钟收敛。

硬件 除DeepWalk外，我们在单台机器上运行实验，配备4块NVIDIA Titan X Pascal GPU（12GB RAM，10Gbps速度）、16个Intel Xeon CPU（E5-2623 v4 @ 2.60GHz）和256GB RAM。DeepWalk在使用144个Intel Xeon CPU（E7-8890 v3 @ 2.50GHz）和2TB RAM的高CPU密集机器上运行更快。总体而言，我们的实验在共享资源环境中花费了大约3天。我们预计一个消费级单GPU机器（例如配备Titan X GPU）如果其全部资源专用，可以在4-7天内完成我们全部实验。

关于DeepWalk实现的说明 现有的DeepWalk实现[28, 11]只是专用word2vec代码的包装，不轻易支持嵌入新节点和其他变体。此外，这使得比较这些方法的运行时间和其他统计数据变得困难。为此，我们在纯TensorFlow中重新实现了DeepWalk，使用了TensorFlow word2vec教程中描述的向量初始化等。

我们发现DeepWalk收敛比其他方法慢得多，由于它在训练时快2-5倍，我们给它5次随机游走数据的遍历而不是1次。为了在新数据上更新DeepWalk方法，我们运行了50次长度为5的随机游走（如上所述），并在保持已训练嵌入固定的情况下对新节点的嵌入进行更新。我们还测试了两个变体，一个将采样的随机游走"上下文节点"限制为仅来自已训练节点集（这减轻了统计漂移），另一个没有此限制。我们总是选择性能更好的变体。请注意，尽管DeepWalk在归纳式任务上表现不佳，但在直推式设置中测试时，它更具竞争力，可以在单个固定图上进行大量训练。（也就是说，Kipf等人[17][18]发现基于GCN的方法始终优于DeepWalk，即使在直推式设置的链接预测任务上，而该任务理论上有利于DeepWalk。）我们确实观察到DeepWalk的性能可以通过进一步训练得到改善，在某些情况下，如果让它运行的时间比其他方法长1000倍以上（就测试集预测的墙钟时间而言），它可以与无监督GraphSAGE方法（但不是监督方法）竞争；然而，我们认为这对归纳式任务不是有意义的比较。

注意DeepWalk也等价于p=q=1时的node2vec模型[11]。

关于邻域采样的说明 由于度数分布的重尾性质，我们在将所有图输入GraphSAGE算法之前对边进行下采样。具体来说，我们对边进行子采样，使得没有节点的度数大于128。由于我们每个节点最多只采样25个邻居，这是一个合理的权衡。这种下采样允许我们将邻域信息存储为密集邻接表，这大大提高了计算效率。对于Reddit数据，我们还作为预处理步骤对原始图的边进行了下采样，因为原始图非常密集。所有实验都在下采样版本上进行，但我们在项目网站上发布了完整版本供参考。

### D DeepWalk及相关方法的对齐问题和正交不变性 (Alignment Issues and Orthogonal Invariance for DeepWalk and Related Approaches)

DeepWalk[28]、node2vec[11]和其他最近成功的节点嵌入方法使用的目标函数形式如下：

∑_{i,j∈A} f(zi^T zj) + β ∑_{i,j∈B} g(zi^T zj) (4)

其中f, g是光滑连续函数，zi是被直接优化的节点表示（即通过嵌入查找表），A, B是节点对集合。注意在许多情况下，在这些方法的实际代码实现中，节点与两个唯一的嵌入向量相关联，f和g中点积的参数来自不同的嵌入查找表（例如[11, 28]）；然而，这并不根本性地改变学习算法。大多数方法还将学到的嵌入归一化到单位长度，因此我们也假设这个后处理。

通过与词嵌入方法以及[20]的论证的联系，这些方法也可以被视为随机隐式矩阵分解，我们试图学习一个矩阵Z ∈ R^{|V|×d}使得

ZZ^T ≈ M, (5)

其中M是包含随机游走统计的某个矩阵。

这种结构的一个重要后果是嵌入可以被任意正交矩阵旋转而不影响目标：

ZQ^T QZ^T = ZZ^T, (6)

其中Q ∈ R^{d×d}是任意正交矩阵。由于嵌入在其他方面不受约束，唯一的误差信号来自正交不变的目标(4)，整个嵌入空间在训练期间可以自由地任意旋转。

这有两个明显的后果：

1. 假设我们在两个分离的图A和B上使用相同的输出维度运行基于(4)的嵌入方法。如果没有一些明确的惩罚来强制对齐，两个图学到的嵌入空间将在训练后相对于彼此任意旋转。因此，对于任何在图A的单个嵌入上训练的分类方法，输入来自图B的嵌入基本上是随机的。这个事实也因为这两个图的M矩阵完全不相交而成立。当然，如果我们有一种方法来匹配图之间的"相似"节点，那么就有可能使用对齐程序在图之间共享信息，例如[12]提出的对齐词嵌入算法输出的程序。研究这样的对齐程序是未来工作的一个有趣方向；尽管这些方法在新数据上运行时不可避免地比GraphSAGE这样的方法慢，因为GraphSAGE可以简单地生成新节点的嵌入而无需任何额外训练或对齐。

2. 假设我们在时间t在图C上运行基于(4)的嵌入方法，并在学到的嵌入上训练一个分类器。然后在时间t+1，我们向C添加更多节点，运行新的一轮SGD并更新所有嵌入。这里出现两个问题：首先，类比于上面的第1点，如果新节点只连接到非常少的旧节点，那么新节点的嵌入空间基本上可以相对于原始嵌入空间发生旋转。此外，如果我们在训练期间更新所有嵌入（而不仅仅是新节点的），如[28]对DeepWalk的流式方法所建议的，那么嵌入空间可以相对于我们训练分类器的嵌入空间任意旋转，这只会使问题更加恶化。

注意这种旋转不变性对于仅依赖于成对节点距离（例如通过点积进行链接预测）的任务不是问题。此外，一些合理的方法来缓解这个统计漂移问题是：(1)优化新测试节点的嵌入时不更新已训练的嵌入，以及(2)只保留现有节点作为采样随机游走中的"上下文节点"，即确保skip-gram目标中的每个点积都是一个已训练节点和一个新/测试节点的乘积。我们在本文中尝试了这两种方法，并始终选择性能最佳的DeepWalk变体。

另外注意，从经验上看，DeepWalk在引文数据上比Reddit数据表现更好（第4.1节），因为这种统计漂移在Reddit数据中比在引文图中更严重。具体来说，Reddit数据中从测试集到训练集的边较少，这有助于防止错位：96%的2005年引文链接连接回2000-2004年的数据，而Reddit测试集中只有73%的边连接回训练数据。

### E 定理1的证明 (Proof of Theorem 1)

为证明定理1，我们首先证明三个引理：

- 引理1：存在一个连续函数，保证只在固定数量点周围的闭球内为正，具有一定的噪声容限。
- 引理2：我们可以使用具有单个隐藏层的多层感知器以任意精度逼近引理1中的函数。
- 引理3：在前两个引理的基础上，证明池化架构可以学习将节点映射到唯一的指示向量，假设所有输入特征向量足够不同。

我们还依赖于最大池化算子（至少有一个隐藏层）能够以任意ε精度逼近任何Hausdorff连续对称函数[29]。

我们注意到以下所有内容本质上都是可辨识性论证。我们证明存在一个参数设置使得算法1可以学习节点的聚类系数，考虑到它通过聚合特征信息来操作，这是不明显的。所描述函数的高效可学习性是未来工作的主题。我们还注意到这些证明是保守的，因为聚类系数实际上可能在更少的迭代次数或更少的限制条件下就可辨识。此外，由于我们依赖于两个通用逼近定理[15, 29]，所需的维度原则上是O(|V|)。我们可以提供一些特定层的所需输出维度的更具信息性的界（例如引理3）；然而，在最坏情况下，这个可辨识性论证依赖于O(|V|)的维度。值得注意的是，Kipf等人的"无特征"GCN方法的参数维度为O(|V|)，因此这个要求并非完全不合理[17, 18]。

在定理1之后，设xv ∈ U, ∀v ∈ V表示图G = (V, E)上算法1的特征输入，其中U是Rd的任意紧子集。

引理1. 设C ∈ R+是一个固定的正常数。那么对于任意非空有限节点子集D ⊆ V，存在一个连续函数g : U → R使得

如果对某个v ∈ D有||x - xv||2 = 0，则g(x) > ε
如果对所有v ∈ D有||x - xv||2 > C，则g(x) ≤ -ε

其中ε < 0.5是选择的误差容限。

证明：存在许多这样的函数。为具体起见，我们提供一个满足这些标准的构造。设x ∈ U表示g的任意输入，设dv = ||x - xv||2, ∀v ∈ D，并设g定义为g(x) = ∑_{v∈D} gv(x)，其中

gv(x) = 3|D|ε/(bdv^2 + 1) - 2ε (8)

其中b = (3|D| - 1)/C^2 > 0。通过构造：

1. gv在dv=0处有唯一最大值3|D|ε - 2ε > 2|D|ε。
2. lim_{dv→∞} (3|D|ε/(bdv^2+1) - 2ε) = -2ε
3. 如果dv ≥ C，则3|D|ε/(bdv^2+1) - 2ε ≤ -ε。

同时注意g在其定义域(dv ∈ R+)上连续，因为它是一组有限连续函数的和。此外，对于给定输入x ∈ U，如果所有点v ∈ D都有dv ≥ C，则根据上述性质3，g(x) = ∑_{v∈D} gv(a) ≤ -ε。并且，如果对任何v ∈ D有dv = 0，则通过构造，g是正的，因为在这种情况下，

gv(x) + ∑_{v'∈D\v} gv'(x) ≥ gv(x) - (|D|-1)2ε > gv(x) - 2(|D|)ε > 2(|D|)ε - 2(|D|)ε > 0,

所以我们知道当任何节点的dv=0时g为正，当所有节点的dv > C时g为负。

引理2. 函数g : U → R可以由至少有一个隐藏层和非恒定单调递增激活函数（例如修正线性单元）的标准多层感知器（MLP）以任意精度逼近。精确地说，如果设f_θ^σ表示这个MLP，θ_σ其参数，则∀ε, ∃θ_σ使得|f_θ^σ(x) - g(x)| < ε, ∀x ∈ U。

证明：这是[15]中定理2的直接推论。

引理3. 设A是G的邻接矩阵，设N^2(v)表示节点v的二跳邻域，定义χ(G^4)为具有邻接矩阵A^4（忽略自环）的图的色数。假设存在一个固定的正常数C ∈ R+，使得对所有节点对都有||xv - xv'||2 > C。那么存在算法1的一个参数设置，在深度k=1使用具有≥2个隐藏层和修正非线性单元的池化聚合器，使得

h1_v ≠ h1_v', ∀(v, v') ∈ {(v, v') : ∃u ∈ V, v, v' ∈ N^2(u)}, h1_v, h1_v' ∈ E_I^{χ(G^4)}

其中E_I^{χ(G^4)}是维度χ(G^4)的一组独热指示向量。

证明：根据色数的定义，我们知道可以用χ(G^4)种唯一颜色标记V中的每个节点，使得在任何节点的二跳邻域中共现的任意两个节点不被分配相同颜色。因此，恰好用χ(G^4)个维度，我们可以为每个节点分配一个唯一的独热指示向量，使得任何二跳邻域中共现的两个节点不具有相同向量。换句话说，每种颜色定义了一个节点子集D ⊆ V，该子集中的所有节点可以映射到相同的指示向量而不引入冲突。

由引理1和2以及假设对所有节点对都有||xv - xv'||2 > C，我们可以选择ε < 0.5，存在一个单层MLP f_θ^σ，使得对于任何节点子集D ⊆ V：

f_θ^σ(xv) > 0, ∀v ∈ D
f_θ^σ(xv) < 0, ∀v ∈ V \ D. (9)

通过使这个MLP更深一层并特别使用修正线性激活函数，我们可以仅对子集D中的节点返回正值，其他返回零，并且由于我们在应用聚合器层后进行归一化，这个单一正值可以被映射为指示向量。此外，我们可以创建χ(G^4)个这样的MLP，每个MLP对应一个不同的颜色/子集；等价地，每个MLP对应正文中公式3中的一个不同最大池化维度。

我们现在重述定理1并提供证明。

定理1. 设xv ∈ Rd, ∀v ∈ V表示图G = (V, E)上算法1的特征输入，其中U是Rd的任意紧子集。假设存在一个固定的正常数C ∈ R+，使得对所有节点对都有||xv - xv'||2 > C。那么∀ε > 0，存在算法1的参数设置Θ*，使得在K = 4次迭代后

|zv - cv| < ε, ∀v ∈ V,

其中zv ∈ R是算法1生成的最终输出值，cv是[38]中定义的节点聚类系数。

证明：不失一般性，我们描述如何计算任意节点v的聚类系数。为符号方便，我们使用⊕表示向量拼接，用dv表示节点v的度数。这个证明需要算法1的4次迭代，我们在所有深度使用池化聚合器。为清晰起见，我们忽略向量归一化相关的问题，并利用池化聚合器可以以任意ε精度逼近任何Hausdorff连续函数的事实[29]。注意我们总是可以通过让聚合器在所有输出表示前添加一个单位值来计及归一化常数（算法1第7行）；然后归一化常数可以通过在后面层取这个前置值的倒数来恢复。还要注意几乎肯定存在某些设置，其中下面描述的对称函数可以由池化聚合器（或其变体）精确计算，但[29]的对称通用逼近定理连同Lipschitz连续性论证足以证明聚类系数的可辨识性（达到任意精度）。特别地，下面描述的我们需要逼近以计算聚类系数的函数在其定义域上都是Lipschitz连续的（假设我们只在正度数节点上运行），因此逼近引入的误差仍由固定常数（可以设为任意小）界定。

我们假设深度k=2和k=3的权重矩阵W1, W2为单位矩阵，所有非线性为修正线性单元。此外，对于最后一轮迭代（即k=4），我们完全忽略邻域信息，仅将此层视为具有单个隐藏层的MLP。定理1可以等价地表述为需要算法1的K=3次迭代，然后将表示送入单层MLP。

由引理3，我们可以假设在深度k=1时，v的二跳邻域中的所有节点都有唯一的独热指示向量h1_v ∈ E_I。因此，在算法1的深度k=2，假设我们对相邻节点的未归一化表示求和。那么不失一般性，我们将有h2_v = h1_v ⊕ Av，其中A是包含G^4中所有连接到v的节点的子图的邻接矩阵，Av是邻接矩阵对应于v的行。然后，在深度k=3，再次假设我们对相邻表示求和（权重矩阵为单位矩阵），那么我们将有

h3_v = h1_v ⊕ Av ⊕ (∑_{v∈N(v)} h1_v ⊕ Av). (10)

设m表示h1_v向量的维度（即m ≡ χ(G^4)），并使用方括号表示向量索引，我们可以观察到

- a ≡ h3_v[0 : m] 是v的独热指示向量。
- b ≡ h3_v[m : 2m] 是v在邻接矩阵A中的行。
- c ≡ h3_v[3m : 4m] 是v邻居的邻接行之和。

因此，我们有b^T c是仅包含v及其直接邻居的子图中的边数，且∑_{i=0}^{m} b[i] = dv。最后我们可以计算

2(b^T c - dv) / (dv)(dv-1) = 2|{e_{v,v'} : v, v' ∈ N(v), e_{v,v'} ∈ E}| / (dv)(dv-1) = cv, (11)

由于这是h3_v的连续函数，我们可以用单层MLP（或等价地，再迭代一次算法1，忽略邻域信息）以任意ε精度逼近它。这最后一步再次直接来自[15]。

推论2. 假设我们从任意概率分布μ（相对于Lebesgue测度绝对连续）在x ∈ U上采样节点特征。则定理1的条件在特征输入xv ∼ μ下几乎必然满足。

推论2是定理1的直接推论，因为对于任何相对于Lebesgue测度绝对连续的概率分布，采样到两个相同点的概率为零。从经验上，我们发现GraphSAGE-pool实际上能够通过利用图结构来保持适度的性能，即使使用完全随机的特征输入（见图3）。然而，GraphSAGE-GCN的性能不那么稳健，这直观上是有道理的，因为引理1、2和3直接依赖于池化聚合器的通用表达能力。

最后，我们注意到定理1和推论2是针对特定给定图表述的，因此有些直推式。对于归纳式设置，我们可以陈述

推论3. 假设对于属于某类图G*的所有图G = (V, E)，存在k, d ≥ 0, k, d ∈ Z使得

h_k_v ≠ h_k_v', ∀(v, v') ∈ {(v, v') : ∃u ∈ V, v, v' ∈ N^3(u)}, h_k_v, h_k_v' ∈ E_I^d,

则经过算法1的K = k + 4次迭代后，我们可以以任意epsilon逼近聚类系数。

推论3简单地指出，如果在算法1的k次迭代后，我们可以学习唯一地识别某一类图中的节点，那么我们也能够以任意精度逼近这类图的聚类系数。
