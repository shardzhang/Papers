# Learning Piece-wise Linear Models from Large Scale Data for Ad Click Prediction.



重要意义：淘宝第一代自研浅层机器学习算法，为阿里带来显著线上增长。盖坤封神之作。

业务场景：点击率预估

业务指标：无，没有介绍线上效果

离线指标：AUC

数据集：淘宝内部数据集（阿里巴巴移动展示广告CTR预测数据集）

模型类型：精排模型点击率预估

创新点：

- 是LR的改进版本。分而治之思想，将原本特征空间划分为m个，在各个特征子空间内用LR进行拟合，然后将各个结果加权平均。本质是扩展了LR的非线性学习能力，从而能够从海量稀疏数据中捕获非线性，解放了耗时耗力的特征工程。

- 模型参数分为两大部分，一块是特征空间划分参数（用于加权平均），一块是特征空间拟合参数（用于计算特征子空间打分）。

  输入的特征空间维度为d，参数空间为dx2m，如果去掉划分参数，则参数空间变为d（即一个特征维度对应一个参数维度）

- 由于非线性能力引入，导致整个优化loss变为非凸问题。同时为了稀疏化，引入的L1和L2,1正则项导致loss不平滑。非凸+非平滑问题的求解方法，主要来自参考文献[1]：OWL-QN

个人收获：

- 传统LR模型为了能够让模型具有非线性拟合能力，一般通过大量特征工程构造非线性特征交叉组合，耗时又耗力。

## FQA

#### Q：明明可以使用L2范数这种光滑的函数，为什么还要使用L2,1范数这种非光滑函数？自己给自己找麻烦么？

因为 **L2 不产生精确零，做不了特征选择**。三种范数的行为正好互补：

| 正则       | 数学形状             | 效果                                                  |
| ---------- | -------------------- | ----------------------------------------------------- |
| L2（平方） | 光滑球面             | 只把参数**缩小**，永远缩不到精确 0 → 特征一个也剪不掉 |
| L1         | 菱形（有尖角）       | 逐参数归零（元素级稀疏）                              |
| L2,1       | 组内 L2、**组间 L1** | 整组归零（结构稀疏）                                  |

关键在 LS-PLM 的参数布局：**每个特征维度 i 挂着 2m 个参数**（m 个分片各自的 u、w）。"剪掉一个特征" = 这 2m 个参数同时归零，只有 L2,1 能做到：

- L2,1 把第 i 维的 2m 个参数捆成一组：组内用 L2（只看整组幅度），组间用 L1（让整组幅度精确为 0）→ 要么整组全零（特征被丢弃），要么全保留。这就是 group lasso（Yuan & Lin 2006）的思想，专为"特征层面剪枝"设计。
- L1 只保证**单个参数**归零：一个特征 2m 个参数里零几个、留几个，特征还"活着"，线上还得存它的参数、算它的贡献，剪不掉。
- L2 连精确零都没有，工业上毫无意义——CTR 场景特征数千万，参数必须真零才能省内存、省计算。

所以论文一句"提供不同属性"不是废话：**L2,1 负责"整特征剪掉"（特征选择），L1 负责"留下的特征内部也尽量稀疏"**（可解释性）。表 2 也验证了分工：L2,1 剪到只剩 18.7% 的特征（9.4% 参数），L1 继续把参数压到 1.9%，组合后最稀疏且 AUC 最高。

一句话记忆：L2 只会"缩"，L1 只会"单个归零"，L2,1 才能"整组归零"——后者才是特征选择需要的。



不是找麻烦，而是**光滑性和稀疏性天生互斥**——这是数学上绕不开的取舍，不是论文作者的选择题。

**光滑正是 L2 不能归零的原因。** 看一维例子，最小化 $g(x)=(x-1)^2+\lambda\,\phi(x)$：

- $\phi=x^2$（L2）：处处可导，最优解 $x^*=\dfrac{1}{1+\lambda}$——**对任何有限 λ 都不等于 0**，只是变小。
- $\phi=|x|$（非光滑）：原点是尖角（不可导点）。λ 够大时 $g$ 在原点左侧下降、右侧上升，$x^*$ 就被"卡"在尖角上得 0。

所以规律是：**正则项在 0 点越"钝"（不可导），越能把解钉在 0；在 0 点越光滑，解越躲开 0。** L2 的"光滑"本身就是它零稀疏能力的死穴——你想要精确归零，就必然引入非光滑。这不是"自找麻烦"，而是"要稀疏就得付这个代价"。

论文真正"自找麻烦"的地方其实在别处：

1. **目标函数非凸**（LS-PLM 是分片线性混合，这决定了它连凸都没有）；
2. **L2,1 是非光滑**（L1 也是），所以梯度下降、EM 全用不了。

而作者把这个麻烦 **转化成了论文的贡献**：专门设计了"方向导数 + 基于 OWL-QN 思想的**分片正交拟牛顿法**"来求解——这正是我们前几天看的 OWL-QN 家族的用法。整篇论文卖点之一就是"我们能把非光滑问题在高规模下高效解出来"，表 2 证明稀疏目标（特征剩 18.7%）值得这个麻烦。

一句话：非光滑不是副作用，是**稀疏性的必要条件**；作者愿意为它在优化上多花功夫，因为工业规模下"剪掉特征"省下的内存和计算远超优化代价。



#### Q：在损失函数中加入L2范数和L2范数的平方，对求解过程有区别么？为什么？

分两问回答：**解一样，但"求导过程"和"组的命运"差很远。**

1. 最优解：没有区别

$\|\theta\|_2$ 和 $\|\theta\|_2^2$ 是同一个**凸函数的严格单调变换**，它们的**水平集是同一族球** $\{\|\theta\|\le t\}$。罚函数形式不同，但每个解都对应"损失在某个球上的极小"（KKT/拉格朗日对偶），球一样 → 解一样。λ 按标度对应即可：

$$\min f(\theta)+\lambda\|\theta\|_2 \quad\Longleftrightarrow\quad \min f(\theta)+\tfrac{\lambda'}{2}\|\theta\|_2^2$$

所以"加哪个"对"解是什么"完全无所谓。

2. 求解过程：区别很大

梯度差一个"除以自身模长"：

$$\nabla\|\theta\|_2^2 = 2\theta \qquad \nabla\|\theta\|_2 = \frac{\theta}{\|\theta\|}$$

- **平方版** $2\theta$：梯度全局 Lipschitz（斜率恒为 2），任何一阶方法的步长理论都成立；Hessian 是单位阵，Newton/拟牛顿直接可用。**标准 ridge 用它的原因，纯粹是求导方便。**
- **非平方版** $\theta/\|\theta\|$：在 0 附近"梯度模长为 1"，方向总是一个单位向量 → 梯度不 Lipschitz、在零点无定义。固定步长的收敛理论失效，线搜索要专门设计，二阶方法更是不能用。**现实中没人单独用 $\|\cdot\|_2$ 做岭回归，就是这个原因。**

3. 但最关键的区别：组结构会不会保留

对你正在读的论文这才是命门。把 2,1 的**组内 L2 平方掉**：

$$\sum_i\sqrt{\sum_j\theta_{ij}^2}\ \xrightarrow{\ \text{平方}\ }\ \sum_i\sum_j\theta_{ij}^2 = \sum_{i,j}\theta_{ij}^2$$

**变成了逐元素 ridge，组完全溶解**——2,1 退化成 2，特征选择机制消失。这正是前面说的"组内必须用不平方的 L2"的深层原因：

- 平方后梯度 $2\theta_{ij}$ 在 0 附近**趋于零**，对微弱参数的拉扯越来越小 → 只能"缩"；
- 不平方时组模长的梯度是 $\theta/\|\theta\|$，在 0 附近**恒为 1**，配合外层求和（组间 L1 的那个"1"）的尖角，才能把整组钉到精确 0。

一句话总结：**平方与否不改变题意，但改变梯度几何——不平方才有"恒定拉力"和组间 L1 可作用的尖角，平方就让组结构蒸发。**





#### Q：L2,1 是什么意思？,1是什么？

**命名规则：$L_{p,q}$ 表示"组内用 $L_p$，组间用 $L_q$"。** 读法：先对每一组内部取 $p$ 阶范数得到"组模长"，再对这些模长取 $q$ 阶"和"。

一般定义（矩阵按行分组）：

$$\|A\|_{p,q}=\Big(\sum_{i}\big(\sum_{j}|a_{ij}|^p\big)^{q/p}\Big)^{1/q}= \Big(\sum_{\text{组 }i}\underbrace{\|A_{i\cdot}\|_p^q}_{\text{组模长的 }q\text{ 阶}}\Big)^{1/q}$$

代入 $p=2,\ q=1$（此时 $q/p$ 次方和 $1/q$ 次根都退化成 1，只剩一个求和）：

$$\|\Theta\|_{2,1}=\sum_i\sqrt{\sum_j\theta_{ij}^2}=\sum_i\|\theta_{i\cdot}\|_2$$

所以 **",1" 就是最外面那个"对组模长们求和"**——即"组间用 $L_1$"：把所有组的模长 $(\|\theta_{1\cdot}\|_2,\dots,\|\theta_{d\cdot}\|_2)$ 打包成一个向量再取 $L_1$。正是这个最外层的 **1**（求和）提供了"尖角"，负责把不重要的整组模长钉到精确 0——这就是 $L_{2,1}$ 产生组稀疏的机理。

换几个 $q$ 对照就知道 $1$ 的作用：

| 记号      | 组内   | 组间           | 效果                        |
| --------- | ------ | -------------- | --------------------------- |
| $L_{1,1}$ | 绝对值 | 求和           | = 逐元素 L1（无组结构）     |
| $L_{2,1}$ | 欧氏   | 求和           | **组稀疏**（LS-PLM 用的）   |
| $L_{2,2}$ | 欧氏   | 平方求和再开方 | = Frobenius（无稀疏，光滑） |

一句话记忆：**逗号左边管"一组长什么样"（2＝欧氏），逗号右边管"组之间怎么较劲"（1＝求和＝L1 式剪枝）**。



把式子拆开看：

$$\|\Theta\|_{2,1} = \sum_{i=1}^d \underbrace{\sqrt{\sum_{j=1}^{2m}\theta_{ij}^2}}_{\|\,·\,\|_2 \text{: 第 i 组}的"幅度"} = \Big\|\big(\|\theta_{1\cdot}\|_2,\ \|\theta_{2\cdot}\|_2,\ \dots,\ \|\theta_{d\cdot}\|_2\big)\Big\|_1$$

外层求和就是**对这些组幅度组成的向量取 L1 范数**——和普通 L1 把单个标量归零是同一个机制：$\Sigma_i\|g_i\|$ 在每个 $g_i=0$ 处不可导（有尖角），最优解会坐进这些尖角里，让某些 $\|g_i\|$ **精确为 0**，于是整个组向量 = 0。

严谨的充要条件（group lasso 的 KKT）可以印证：某组 $g$ 被归零，当且仅当"该组上的损失梯度范数"小于阈值 $\lambda$：

$$\| \nabla \text{loss}(\Theta)_{g} \|_2 < \lambda \iff \Theta_{g} = \mathbf{0}$$

对照一下两种稀疏的"判定对象"：

- 逐元素 L1：判定的是**单个参数**的梯度 $|\nabla_i|<\beta \Rightarrow \theta_i=0$
- L2,1：判定的是**整组梯度**的范数 $\|\nabla_g\|_2<\lambda \Rightarrow \theta_g=\mathbf{0}$

这正是它被叫做"组稀疏"的原因——把 L1 的判断单元从"1 个标量"换成了"1 个向量"。

唯一值得留意的细节：组内必须用**不平方的** L2（$\sqrt{\sum\theta^2}$）。如果写成 $(\sum\theta^2)$ 的平方形式，外层就变成对幅度的线性函数，"尖角"消失，整组归零的机制就没了——所以记法才必须是 $\|\cdot\|_{2,1}$ 而不是 $\|\cdot\|^2_{2,1}$。



关键在于**组的方向**：矩阵 $\Theta$ 是 $d \times 2m$ 的——行是"特征 i"，列是"该特征在 2m 个分片里的参数"。开根号作用在**行内**（固定 i，对 j 求和开方）＝一个特征组的模长；外层求和是在**行之间**（对所有 d 个组的模长求和）＝L1。

如果你把外层求和放进根号里，得到的是：

$$\sqrt{\sum_{i=1}^d \sum_{j=1}^{2m} \theta_{ij}^2} = \|\Theta\|_F \quad\text{(Frobenius 范数)}$$

那整个式子就变成了"整个矩阵的模长"——一个**全局平滑**的函数。它只在"全部矩阵为零"这一处不可导，对单个特征组没有任何尖角，所以它既不能把某个特征整组归零，也不能做任何逐组的稀疏。而且它整体是光滑的，退化成了你上一个问题里说的 L2。

判断对错就记一条：**开根号的是"一组"，求和的是"组与组"**。论文要"按特征分组剪枝"，所以组 = 一行（i 固定），根号必然在行内；外层 Σ 是 L1 聚合，必然在根号外。放进去，组就没了。



要看"L2 范数"指的是谁的 L2：

- **把 $\Theta$ 当向量看**（拉平成 $d\cdot 2m$ 维）：是的，$\sqrt{\sum_{i,j}\theta_{ij}^2}$ 就是那个向量的欧氏长度，即 L2 范数。
- **把 $\Theta$ 当矩阵看**：不是。矩阵的 L2 范数（算子范数/谱范数）另有所指：
  $$\|\Theta\|_2 = \sigma_{\max}(\Theta)\quad\text{（最大奇异值）}$$
  而 $\sqrt{\sum_{i,j}\theta_{ij}^2}$ 在矩阵论里叫 **Frobenius 范数** $\|\Theta\|_F$。

所以精确的说法是：**Frobenius 范数 = "把矩阵拉平成长向量后"的 L2 范数**。这也是为什么你会觉得"它长得就像 L2"——它就是 L2 的元素形式，只是发生在矩阵上时名字换了。

和 L2,1 的对应关系值得一提：

$$\|\Theta\|_{2,1}\ \xrightarrow{\ \text{只有}1\text{个组}\ }\ \sqrt{\sum_{i,j}\theta_{ij}^2} = \|\Theta\|_F$$

即"2,1"里的 **2** 指的就是组内的欧氏（L2）范数；如果把所有元素打成一组，2,1 就退化成一个纯粹的 Frobenius/L2——回到我们上一个问题的结论：光滑、无任何逐组稀疏。

一句话记忆：**"2" 是组内范数（欧氏），"1" 是组间聚合（绝对值求和）；Frobenius 就是"只有一组"时的 2,1。**



#### Q：参数 $\beta$ 和 $\lambda$ 通过网格搜索选择。网格搜索是什么意思？具体如何操作？

**网格搜索（grid search）＝把每个超参数的候选值列成一个"网格"，穷举所有组合，逐个训练、逐个在验证集上打分，取指标最好的那组。** 没有任何智能，就是"全试一遍"。

以论文的 $\beta,\lambda$ 为例（翻译文件第 304 行），具体操作就五步：

**1. 每个超参数列出候选值**
$$\beta \in \{0.01,\ 0.1,\ 1,\ 10\},\qquad \lambda \in \{0.01,\ 0.1,\ 1,\ 10\}$$
注意是对数刻度、每档差 10 倍——因为正则强度通常跨数量级才有效果，线性刻度取 $\{0.1,0.2,0.3,\dots\}$ 纯属浪费算力。

**2. 取笛卡尔积，得到全部组合**
$$4\times 4 = 16 \text{ 组}:\ \ (\beta{=}0.01,\lambda{=}0.01),\ (\beta{=}0.01,\lambda{=}0.1),\ \dots$$

**3. 每组组合完整做一遍"训练 + 验证"**
- 用训练集跑完整优化算法（LS-PLM 就是那套方向导数拟牛顿法）训练到收敛，得到模型；
- 在**独立的验证集**上算 AUC（λ 和 β 都在这张表里，所以表 2 那些稀疏性/指标都是这么评出来的）。

**4. 挑验证集指标最好的组合**
论文结论：LS-PLM 最优是 $\beta=1,\lambda=1$；LR 最优是 $\beta=1$。

**5. （可选）最后把这个最优组合在测试集上评估一次**，得到无偏的最终性能估计。

代价是线性的：**训练成本 × 组合数**。16 组合 × "数百台机器全量训练"，这就是论文里只敢列 4×4 网格、每档差 10 倍的原因——网格越密，钱越多。

三点补充：

- **先粗后细**是实务标准做法：先 $\{0.01,0.1,1,10\}$ 粗扫定位（比如最佳落在 1），再在 1 附近细扫 $\{0.5,0.75,1,1.5\}$。
- 高维超参数时（≥3 个），网格的"组合爆炸"太浪费，业界常用**随机搜索**（在每个参数区间内随机采样组合数），Bergstra & Bengio 2012 证明同样预算下随机搜索几乎总优于网格。
- 小数据集上还会用 k 折交叉验证（每组合 train k 次取平均），但工业大数据（论文的十亿样本）根本经不起 k 倍成本，只用单次划分的验证集。

一句话记忆：**网格搜索 = 假设超参数候选都已知，暴力试遍笛卡尔积，用验证集指标投票。**



骂得对，但也不算全对——它"笨"，但**没笨到你想的那个程度**，关键是三点：

**1. 组合数其实很少。** 网格搜索只在超参数个数 ≤2~3 时才是合理选择。论文只有 β、λ 两个参数，4×4=16 组。16 次全量训练对"调好一个 λ 就能明显涨 AUC"的收益来说，是便宜的投资。真正的组合爆炸是 5 个以上参数时的事（那时网格才该被枪毙）。

**2. 16 个组合是完美并行的。** 每个组合独立训练，可以同时开 16 个作业——**墙钟时间 ≈ 训练一次的时间，不是 16 倍**。"浪费"的白话其实是"烧机器小时"，但论文本来就是几百台机器常态并行训练，多开 16 份只是调度问题。Grid 是集群上最自然的并行调度方式，这恰恰是它活下来的工业原因。

**3. 它不需要任何"建模假设"。** 贝叶斯优化要拟合"超参数→指标"的代理模型（初始采样几十次才进入状态，代理模型本身可能不准）；如果指标不光滑、有噪声，代理模型的推断会带歪你。网格搜索则零假设、零风险，结果永远可复现可解释——**在参数少时，花哨方法的收益追不上它们的开销**。

真正该骂的浪费长这样，论文都没踩：

- 网格取**线性刻度**（0.1, 0.2, 0.3…）——正则参数跨数量级才有效，这是纯烧钱；
- 一次网格里每个作业都从零开始训，**不做热身共享**（贝叶斯优化/多保真度的价值就在这：用短训练先筛，只对少数候选跑全量）；
- 网格一次跑完不留中间检查点，无法"先粗后细"中途止损。

更聪明的替代品按性价比排序：

1. **先粗后细网格**：零成本智力升级，+0 算力；
2. **随机搜索**：参数 ≥3 个时，同样预算下几乎全面优于网格（Bergstra & Bengio 2012）；
3. **贝叶斯优化/TPE、Hyperband、ASHA**：真正省算力的大杀器，但对 2 参数、10 倍档距的问题，收益约等于零。

一句话：**网格搜索是"参数少 + 可并行 + 不求最优只求够好"前提下的理性选择，不是头铁**。它被骂，是因为有人拿它在 10 个超参数上无脑用——那是用法问题，不是算法原罪。

#### Q：MLR Trainer 使用 Proximal SGD 优化器。

Proximal SGD 原理

$$
Θ_{t+1} = prox_{η·g}(Θ_t - η · ∇loss(Θ_t))
$$
1. 梯度下降步: $Θ' = Θ - lr * ∇loss(Θ)$
2. L1 近端映射: 软阈值 $sign(Θ') * max(|Θ'| - threshold, 0)$
3. L2,1 近端映射: 组软阈值，对每行（特征维度）做 L2 范数软阈值
