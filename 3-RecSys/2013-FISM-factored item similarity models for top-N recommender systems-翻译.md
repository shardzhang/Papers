## 摘要

现有Top-N推荐方法的效果随着数据集稀疏度的增加而下降。为了缓解这一问题，我们提出了一种基于item的方法来生成Top-N推荐，该方法将item-item相似度矩阵学习为两个低维隐因子矩阵的乘积。这些矩阵使用结构方程建模方法进行学习，其中被估计的值不用于其自身的估计。在多个数据集上、三种不同稀疏度水平下进行的一组全面实验表明，所提出的方法能够有效处理稀疏数据集，并优于其他最先进的Top-N推荐方法。实验结果还表明，随着数据变得更加稀疏，与竞争方法相比的相对性能增益也在增加。

最近，一种新颖的Top-N推荐方法被开发出来，称为SLIM[7]，它通过直接从数据中学习一个稀疏的聚合系数矩阵（该矩阵类似于传统的item-item相似度），改进了传统的基于item的最近邻协同过滤方法。SLIM已被证明在多种数据集上取得了良好的性能，并优于其他最先进的方法。然而，SLIM的一个固有限制是它只能建模那些被至少一些用户共同购买/共同评分的item之间的关系。因此，它无法捕获item之间的传递关系，而这种关系对于基于item的方法在稀疏数据集上的良好性能至关重要。

在本文中，我们提出了一种称为FISM的方法，该方法将item-item相似度矩阵学习为两个低维隐因子矩阵的乘积。这种item-item相似度矩阵的分解表示使得FISM即使在非常稀疏的数据集上也能捕获和建模item之间的关系。我们在多个数据集上、不同稀疏度水平下的实验评估证实了这一点，并表明FISM的性能优于SLIM和其他最先进的方法。此外，相对性能增益随着数据集的稀疏度增加而增加。

(iii) 使用平方误差和排序损失两种方式估计分解item基Top-N模型；以及

(iv) 研究了各种参数在偏置、邻域一致性和模型诱导稀疏性方面的影响。

3. 相关工作综述

本文开发的方法受到最近为Top-N推荐和评分预测开发的两种方法类别的启发。

第一种方法SLIM，由Ning等人[7]提出，将用户u对所有item的推荐分数预测为

˜ru = ruS,       (1)

其中ru是u对所有item的评分向量，S是一个m × m的稀疏聚合系数矩阵。

矩阵S可以被视为一个item-item相似度矩阵，因此SLIM采用的推荐策略在本质上类似于传统的基于item的最近邻Top-N推荐方法[3]。然而，与这些方法不同，SLIM使用一种同时回归方法直接从数据中估计相似度值，这类似于没有外生变量的结构方程建模[10]。具体来说，SLIM估计稀疏矩阵S作为以下正则化优化问题的最小化器：

最小化
S

1/2 ‖R − RS‖²_F + \beta/2 ‖S‖²_F + \lambda‖S‖₁       (2)

满足 S \geq 0, diag(S) = 0,

其中‖S‖_F是S的矩阵Frobenius范数，‖S‖₁是S的逐元素ℓ₁范数。在等式2中，RS是推荐分数的估计矩阵（即˜R）。约束diag(S) = 0符合结构方程建模，也被应用以确保rui不用于计算rui。对S施加非负约束，使得学习到的S对应于item上的正聚合。为了学习稀疏的S，SLIM在等式2中引入S的ℓ₁范数作为正则化项[13]。SLIM学习到的矩阵S被称为SLIM的聚合系数矩阵。[7]中的大量实验表明，SLIM优于其他最先进的Top-N推荐方法。

第二种方法称为NSVD，由Paterek在[8]中提出。这是一种为评分预测问题开发的分解item-item协同过滤方法。在该方法中，item-item相似度被学习为两个低秩矩阵P和Q的乘积，其中P \in R^{m×k}，Q \in R^{m×k}，且k ≪ m。该方法通过将item之间的相似度学习为其对应隐因子的乘积，扩展了传统的基于item的邻域方法。给定两个itemi和j，它们之间的相似度sim(i, j)被计算为P和Q中对应因子的点积，即sim(i, j) = p_i · q^T_j。给定用户u对itemi的评分被同时预测和估计为

ˆ$r_{ui}$ = ˜$r_{ui}$ = b_u + b_i + \Sigma_{j\inR^+_u} p_j q^T_i,       (3)

其中b_u和b_i是用户和item偏置，R^+_u是u已评分的item集合。该模型的参数被估计为以下优化问题的最小化器：

最小化
P,Q

1/2 \Sigma_{u\inC} \Sigma_{i\inR^+_u} ‖$r_{ui}$ − ˆ$r_{ui}$‖²_F + \beta/2 (‖P‖²_F + ‖Q‖²_F),       (4)

其中ˆ$r_{ui}$是用户u和itemi的估计值（如等式3所示）。

在另一种基于NSVD的方法中，Koren提出了一种称为SVD++[5]的混合方法。该方法融合了隐因子模型和传统基于邻域模型的思想，以学习用户或item之间的相似度。这两种模型（即NSVD和SVD++）都是通过在Netflix竞赛数据集上计算测试评分的均方根误差（RMSE）来评估的。因此，这些模型的目标是最小化RMSE，并且只有评分矩阵的非零条目被用于训练。

4. 动机

在现实世界场景中，用户通常只对可能成千上万或数百万item中的少数item提供反馈（购买、评分或评论）。这导致用户-item评分矩阵变得非常稀疏。像SLIM（以及像ItemKNN[3]这样的传统方法）依赖于学习item之间相似度的方法，无法捕获那些没有被至少一个用户共同评分的item之间的依赖关系。可以证明，如果i和j没有被至少一个用户共同评分，则等式2中的最小化器将导致$s_{ij}$=0。但是，两个这样的item可以通过另一个与它们都相似的item（传递关系）而彼此相似。

基于矩阵分解的方法通过将数据投影到低维空间来缓解这一问题，从而隐式地学习用户和item之间更好的关系（包括未被共同评分的item）。然而，这些方法一直被SLIM[7]稳定地超越。

为了克服这一问题，我们提出的面向item的FISM方法使用了在精神上类似于NSVD和SVD++所使用的分解item相似度模型。通过将相似度矩阵投影到维度小得多的隐空间中学习，隐式地帮助学习item之间的传递关系。因此，该模型即使在稀疏数据上也有望表现更好，因为它可以学习未共同评分的item之间的关系。

比较FISM和NSVD，除了这两种方法设计用于解决不同问题（Top-N与评分预测）之外，它们的关键区别在于分解矩阵的估计方式。FISM采用基于结构方程建模的回归方法，与NSVD（和SVD++）不同，在估计某个item的评分时，不使用特定用户-item对的已知评分信息（$r_{ui}$）。这影响了item-item相似度矩阵中对应于S = PQ^T的对角线条目对推荐分数估计的影响。item相似度矩阵中的对角线条目对应于在计算某个item的预测时包含该item自身的值。NSVD在学习和预测阶段的评分估计中不排除对角线条目，而FISM在估计时明确排除对角线条目。NSVD的这一缺点在因子数量变大时会影响估计因子的质量。在这种情况下，它可能导致相当平凡的估计，即一个item最终推荐自身。这一点在我们的实验结果（第7节）中得到了说明，该结果表明，对于少量因子，两种估计方法产生相似的结果，而当因子数量适度增加时，FISM的估计方法一致且显著地优于NSVD使用的方法。

5. FISM——分解item相似度方法

在FISM中，用户u对未评分itemi的推荐分数（记作˜$r_{ui}$）被计算为u已评分item与P中p_j隐向量和Q中q_i隐向量的相应乘积的聚合。即：

˜$r_{ui}$ = b_u + b_i + (n^+_u)^{-\alpha} \Sigma_{j\inR^+_u} p_j q^T_i,       (5)

其中R^+_u是用户u已评分的item集合，p_j和q_i是学习到的item隐因子，n^+_u是u已评分的item数量，\alpha是用户指定的介于0和1之间的参数。

等式5中的项(n^+_u)^{-\alpha}用于控制用户已评分item相对于与被估计评分的item（即itemi）的相似度的一致性程度。为了更好地理解这一点，考虑\alpha=1的情况。在这种情况下（排除偏置），预测评分是用户已评分item（即R^+_u）与itemi之间的平均相似度。如果R^+_u中几乎所有item都与i相似，那么itemi将获得高评分。另一方面，如果\alpha=0，则预测评分是i与R^+_u中item之间的聚合相似度。因此，即使R^+_u中只有一个（或少数）item与i相似，i也可以获得高评分。这两种设置代表了不同的极端情况，我们相信在大多数情况下，正确的选择介于两者之间。也就是说，被预测评分的item需要与大量item相似才能获得高评分。为了捕捉这种差异，我们引入了参数\alpha来控制需要有多少邻域item相似才能使item获得高评分。\alpha的值预计取决于数据集的特性，其最佳性能值通过经验确定。

我们开发了两种不同类型的FISM模型，它们使用不同的损失函数和相关的优化方法，将在接下来的两节中描述。

5.1 FISMrmse

在FISMrmse中，我们使用平方误差损失函数计算损失，由下式给出：

L(·) = \Sigma_{i\inD} \Sigma_{u\inC} ($r_{ui}$ − ˆ$r_{ui}$)²,       (6)

其中$r_{ui}$是真实值，ˆ$r_{ui}$是估计值。给定用户u和itemi的估计值ˆ$r_{ui}$计算如下：

ˆ$r_{ui}$ = b_u + b_i + (n^+_u − 1)^{-\alpha} \Sigma_{j\inR^+_u \{i}} p_j q^T_i,       (7)

其中R^+_u \{i}是用户u已评分的item集合，排除当前被估计值的itemi。这种排除是为了符合基于结构方程建模的回归模型。这也是FISM与其他分解item相似度模型（如NSVD和SVD++）之间的重要区别之一，如第4节所述。

在FISMrmse中，矩阵P和Q通过最小化以下正则化优化问题来学习：

最小化
P,Q

1/2 \Sigma_{u,i\inR} ‖$r_{ui}$ − ˆ$r_{ui}$‖²_F + \beta/2 (‖P‖²_F + ‖Q‖²_F) + \lambda/2 ‖b_u‖²₂ + \gamma/2 ‖b_i‖²₂,       (8)

其中向量b_u和b_i分别对应于用户偏置向量和item偏置向量。正则化项用于防止过拟合，\beta、\lambda和\gamma分别是隐因子矩阵、用户偏置向量和item偏置向量的正则化权重。

遵循Top-N推荐的常见实践[2, 7]，注意等式6中的损失函数是在R的所有条目（即已评分和未评分的）上计算的。这与评分预测方法形成对比，后者仅对已评分item计算损失。然而，为了减少优化的计算需求，零条目被采样并与R的所有非零值一起使用。在每次学习迭代中，\rho · nnz(R)个零被采样并用于优化。这里\rho是一个常数，nnz(R)是R中非零条目的数量。我们的实验结果表明，较小的\rho值（在3–15范围内）就足以产生

最佳模型。这种采样策略使FISMrmse在计算上高效。

5.2 FISMauc

作为第二种损失函数，我们考虑基于排序误差的损失函数。这是基于以下事实：Top-N推荐问题涉及以正确的顺序对item进行排序，这与评分预测问题（以最小化RMSE为目标）不同。我们使用了基于贝叶斯个性化排序（BPR）[11]的排序损失函数，该函数优化曲线下面积（AUC）。给定用户在R^+_u中的已评分item和R^-_u中的未评分item，总体排序损失由下式给出：

L(·) = \Sigma_{u\inC} \Sigma_{i\inR^+_u, j\inR^-_u} (($r_{ui}$ − $r_{uj}$) − (ˆ$r_{ui}$ − ˆ$r_{uj}$))²,       (9)

其中估计值ˆ$r_{ui}$和ˆ$r_{uj}$按等式7计算。正如我们在等式9中看到的，误差被计算为实际非零和零条目之间的相对差异与其对应估计值之差之间的差异。因此，该损失函数关注的不是估计正确的值，而是零和非零值的排序。

在FISMauc中，矩阵P和Q通过最小化以下正则化优化问题来学习：

最小化
P,Q

1/2 \Sigma_{u\inC} \Sigma_{i\inR^+_u, j\inR^-_u} ‖($r_{ui}$ − $r_{uj}$) − (ˆ$r_{ui}$ − ˆ$r_{uj}$)‖²_F + \beta/2 (‖P‖²_F + ‖Q‖²_F) + \gamma/2 (‖b_i‖²₂),       (10)

其中各项的含义与等式8中相同。注意没有用户偏置项（即b_u），因为在取评分差值时这些项会相互抵消。对于每个用户，FISMauc计算R^+_u和R^-_u中所有可能条目对的损失。与FISMrmse类似，为了减少计算需求，每个用户的零条目基于采样因子(\rho)从R^-_u中采样。

等式10中的优化问题使用基于随机梯度下降（SGD）的算法求解。算法2提供了详细的过程。

5.3 可扩展性

这些方法的可扩展性包括两个方面。首先，训练阶段需要具有可扩展性，以便这些方法可以用于更大的数据集。其次，计算推荐所需的时间需要减少，并且理想情况下应独立于可推荐item的总数。关于第一个方面，FISMrmse和FISMauc的训练都是使用SGD算法完成的。SGD的梯度计算和更新可以并行化，因此这些算法可以轻松应用于更大的数据集。

在[4]中，提出了一种分布式SGD。可以使用类似的算法进行修改，以将FISM方法扩展到更大的数据集。主要区别在于计算可以并行独立更新的P的行。也有像Spark¹这样的软件包可用于在大型处理节点集群上实现基于SGD的算法。

为了在运行时高效计算推荐，像SLIM这样的方法在学习时对S施加稀疏性约束，并利用这种稀疏结构来减少运行时的计算量。然而，在FISM中，学习到的分解矩阵通常是密集的，因此预测向量˜ru将是密集的（因为PQ^T是密集的）。可以通过计算S = PQ^T然后将较小的值设为零来在˜ru中引入稀疏性。一种系统化的方法是选择性地仅保留那些对条目所属的S列所表示的item相似度向量长度贡献最大的非零条目。这种稀疏化的影响将在实验结果中进一步探讨。

6.2 评估方法

为了评估所提出模型的性能，采用了5折留一交叉验证（LOOCV）。对于每一折，通过为每个用户随机选择一个item并将其放入测试集，将数据集分为训练集和测试集。其余数据用作训练集。使用这样的训练集构建模型，然后使用训练好的模型为每个用户生成大小为N的排序列表。然后通过将排序后的推荐列表与测试集中的item进行比较来评估模型。对于本文中呈现的所有结果，N等于10。

推荐质量使用命中率（HR）和平均倒数命中排名（ARHR）[3]来衡量。HR定义为：

HR = #hits / #users

其中#users是测试用户的总数，#hits是模型成功在大小为N的推荐列表中召回测试item的用户数。ARHR定义为：

ARHR = (1/#users) \Sigma_{i=1}^{#hits} (1/pos_i)

其中pos_i是第i次命中中测试item在排序推荐列表中的位置。ARHR代表HR的加权版本，因为它衡量推荐item在排序列表中位置的倒数。

我们选择HR和ARHR作为评估指标，因为它们直接衡量模型在真实数据（即用户已经提供反馈的数据）上的性能。

其次，我们展示在所有数据集上与其他竞争方法（第6.3节）的比较结果。我们还比较FISM在不同N值（如top-N中的N）下的性能，最后比较FISM相对于数据稀疏度的性能。

7.1 偏置的影响

图3展示了不同数据集的结果。我们可以看到，对于较小的k值，两种方案的性能非常相似。然而，当k值增加时，FISM开始优于FISM(F)，并且随着k值的增加，方法之间的性能差距也在增大。这证实了FISM使用的估计方法优于NSVD和SVD++等方法使用的估计方法，并且有助于在因子数量变大时避免平凡解。

7.5 非负性的影响

8. 结论

在本文中，我们提出了一种基于分解item相似度的方法（FISM）用于Top-N推荐问题。FISM将item相似度学习为两个矩阵的乘积，使其即使在稀疏数据集上也能生成高质量的推荐。这种分解表示使用结构方程建模方法进行估计，随着因子数量的增加，这种方法能产生更好的估计器。我们在多个数据集上、不同稀疏度水平下进行了一组全面的实验，并将FISM的性能与其他最先进的Top-N推荐算法进行了比较。结果表明，FISM优于其余方法，并且性能差距随着数据集变得更稀疏而增大。为了更快的推荐，我们展示了可以在结果item相似度矩阵中诱导稀疏性，同时推荐质量的降低极小。
