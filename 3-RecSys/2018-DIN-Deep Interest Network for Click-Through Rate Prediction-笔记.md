# 2018-DIN-Deep Interest Network for Click-Through Rate Prediction



## DIN论文注意力

> 但与传统注意力机制不同，公式(3)放宽了「所有权重之和$\sum_i w_i=1$」的约束，目的是保留用户兴趣的强度信息。

公式(3)里的本地激活单元，思路和机器翻译（NMT）领域提出的注意力机制相近。但和传统注意力机制存在关键区别：DIN放松了**所有权重求和等于1**这个硬性约束，以此保留用户兴趣的强弱程度。

也就是说，模型不再对激活单元$a(\cdot)$的输出做Softmax归一化；取而代之，所有注意力权重的累加和，在一定程度上代表用户被唤醒兴趣的整体强度。

举个例子：假设用户历史行为里90%是服饰、10%是电子产品。现在有两个候选广告：T恤、手机。
T恤广告会激活用户绝大多数服饰类历史行为，最终得到的用户兴趣向量$\boldsymbol{v}_U$整体数值会更大（代表兴趣强度更高）；而手机广告激活的行为很少，向量数值更小。

传统注意力会对权重做归一化，直接抹平了$\boldsymbol{v}_U$的数值尺度差异，丢失了这份兴趣强弱区分度。



二、核心概念拆解

1、传统Attention（NMT/常规推荐注意力）的局限

常规注意力最后一步一定会用 **Softmax**：

$$w_i = \frac{\exp(a_i)}{\sum_j \exp(a_j)}$$

强制满足：$\sum_i w_i = 1$

- 优点：权重是概率分布，可解释；
- 致命缺点：**抹平了兴趣总量差异**
  比如用户A疯狂买衣服、用户B只偶尔买一件衣服，当候选商品是T恤时：
  Softmax归一化后，两者权重总和都是1，模型无法区分「用户对服饰的兴趣强弱」。

2、DIN本地激活单元的创新：去掉Softmax，放开权重和约束

DIN的激活单元直接输出原始打分$w_i$，**不做归一化**，$\sum w_i$可以是任意正数：
1. 用户历史行为和候选广告越匹配，单条$w_i$数值越大；
2. 匹配的行为越多，整体$\sum w_i$总和越大；
3. 加权求和得到的用户兴趣向量$\boldsymbol{v}_U=\sum w_i e_i$，向量整体L2范数天然携带**兴趣强度**信息。

3、论文举例通俗理解

用户历史：90%服饰、10%数码
- 候选=T恤：大量服饰行为被激活，每个$w_i$都偏大，$\sum w_i$很大 → $\boldsymbol{v}_U$向量数值大，代表**强兴趣**；
- 候选=手机：只有少量数码行为被激活，$\sum w_i$很小 → $\boldsymbol{v}_U$向量数值小，代表**弱兴趣**。

如果用传统Softmax注意力：
无论匹配多少行为，权重总和固定为1，$\boldsymbol{v}_U$的尺度被压缩，模型无法感知“用户对这个品类到底有多感兴趣”，丢失关键特征信号。

4、设计目的总结

1. 传统Attention：只区分**各条历史行为相对重要性**，丢失兴趣总量；
2. DIN Local Activation Unit：同时保留「行为间相对权重」+「整体兴趣强度」，更贴合推荐CTR预估场景，能精准建模用户对不同商品的兴趣浓烈程度。
