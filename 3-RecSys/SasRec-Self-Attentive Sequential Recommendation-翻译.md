**摘要**—序列动态是许多现代推荐系统的一个关键特征，这些系统试图基于用户最近执行的动作来捕获其活动的"上下文"。为了捕获此类模式，主要有两种方法：马尔可夫链（MC）和循环神经网络（RNN）。马尔可夫链假设用户的下一个动作仅基于其最后（或最后几个）动作即可预测，而RNN原则上允许发现更长周期的语义。一般来说，基于MC的方法在极其稀疏的数据集上表现最佳，此时模型的简洁性至关重要；而RNN在密度较高的数据集上表现更好，此时可以承担更高的模型复杂度。我们的目标是平衡这两个目标，提出一个基于自注意力的序列模型（SASRec），它既能捕获长期语义（像RNN一样），又能使用注意力机制基于相对较少的动作进行预测（像MC一样）。在每个时间步，SASRec试图从用户的动作历史中识别哪些项目是"相关的"，并用它们来预测下一个项目。大量的实验研究表明，我们的方法在稀疏和密集数据集上都优于各种最先进的序列模型（包括基于MC/CNN/RNN的方法）。此外，该模型比可比的基于CNN/RNN的模型快一个数量级。注意力权重的可视化也展示了我们的模型如何自适应地处理不同密度的数据集，并揭示活动序列中有意义的模式。

最近，一种新的序列模型——Transformer——在机器翻译任务中取得了最先进的性能和效率[3]。与使用卷积或循环模块的现有序列模型不同，Transformer 完全基于一种称为"自注意力"（self-attention）的注意力机制，该机制非常高效，能够揭示句子中单词之间的句法和语义模式。

受此方法的启发，我们试图将自注意力机制应用于序列推荐问题。我们希望这一思想能够解决上述两个问题：一方面能够从过去的所有动作中提取上下文（像RNN一样），另一方面能够仅基于少量动作进行预测（像MC一样）。具体来说，我们构建了一个基于自注意力的序列推荐模型（SASRec），该模型在每个时间步自适应地为之前的项目分配权重（图1）。

所提出的模型在多个基准数据集上显著优于最先进的基于MC/CNN/RNN的序列推荐方法。我们特别考察了作为数据集稀疏度函数的性能表现，模型性能与上述模式高度吻合。由于自注意力机制，SASRec 在密集数据集上倾向于考虑长距离依赖，而在稀疏数据集上则聚焦于更近期的活动。这对于自适应地处理不同密度的数据集至关重要。

此外，SASRec 的核心组件（即自注意力块）适合并行加速，使得该模型比基于CNN/RNN的替代方案快一个数量级。我们还分析了 SASRec 的复杂度和可扩展性，进行了全面的消融研究以展示关键组件的效果，并可视化了注意力权重以定性揭示模型的行为。

## I. 引言

序列推荐系统的目标是将用户行为的个性化模型（基于历史活动）与基于用户近期动作的某种"上下文"概念相结合。从序列动态中捕获有用模式具有挑战性，主要原因在于输入空间的维度随用作上下文的过去动作数量呈指数增长。因此，序列推荐的研究主要关注如何简洁地捕获这些高阶动态。

马尔可夫链（MC）是一个经典例子，它假设下一个动作仅取决于前一个动作（或前几个动作），并已成功应用于刻画推荐中的短距离项目转换[1]。另一类工作使用循环神经网络（RNN）通过隐藏状态汇总所有之前的动作，并用其预测下一个动作[2]。

两种方法虽然在特定场景下都很强，但在某种程度上受限于特定类型的数据。基于MC的方法通过做出强简化假设，在高稀疏度设置下表现良好，但可能无法捕获更复杂场景中的精细动态。相反，RNN虽然表达能力丰富，但需要大量数据（尤其是密集数据）才能超越简单的基线方法。

## II. 相关工作

有几类工作与我们的研究密切相关。我们首先讨论通用推荐，然后是时间推荐，接着讨论序列推荐（特别是MC和RNN）。最后介绍注意力机制，特别是作为我们模型核心的自注意力模块。

### A. 通用推荐

推荐系统关注于基于历史反馈（如点击、购买、点赞）对用户和项目之间的兼容性建模。用户反馈可以是显式的（如评分）或隐式的（如点击、购买、评论）[4]，[5]。由于解释"未观测"（如未购买）数据的模糊性，隐式反馈建模具有挑战性。为了解决这个问题，提出了逐点（point-wise）[4]和成对（pairwise）[5]方法。

矩阵分解（MF）方法试图发现潜在维度来表示用户的偏好和项目的属性，并通过用户与项目嵌入之间的内积来估计交互[6]，[7]。此外，另一类工作基于项目相似度模型（ISM），不显式地用潜在因子建模每个用户（如FISM [8]）。它们学习项目到项目的相似度矩阵，通过衡量项目与用户之前交互过的项目的相似度来估计用户对某个项目的偏好。

最近，由于深度学习在相关问题上的成功，各种深度学习技术被引入推荐系统[9]。一类工作试图使用神经网络提取项目特征（如图像[10]，[11]、文本[12]，[13]等）用于内容感知推荐。另一类工作试图取代传统的MF。例如，NeuMF [14]使用多层感知机（MLP）估计用户偏好，AutoRec [15]使用自编码器预测评分。

### B. 时间推荐

追溯到 Netflix Prize，时间推荐通过显式建模用户活动的时间戳，在各种任务上表现出强大的性能。TimeSVD++ [16]通过将时间划分为多个片段并在每个片段中分别建模用户和项目取得了很好的效果。这类模型对于理解表现出显著（短期或长期）时间"漂移"的数据集至关重要（例如"过去10年电影偏好如何变化"或"用户在下午4点访问什么样的商户"等）[16]–[18]。序列推荐（或下一个项目推荐）与这一设置略有不同，因为它只考虑动作的顺序，并对独立于时间的序列模式进行建模。本质上，序列模型试图基于用户的近期活动来建模用户动作的"上下文"，而非考虑时间模式本身。

### C. 序列推荐

许多序列推荐系统试图建模项目-项目转移矩阵，以捕获连续项目之间的序列模式。例如，FPMC 融合了 MF 项和项目-项目转移项，分别捕获长期偏好和短期转移[1]。本质上，捕获的转移是一阶马尔可夫链（MC），而高阶MC假设下一个动作与之前多个动作相关。由于最后访问的项目通常是影响用户下一个动作的关键因素（本质上提供了"上下文"），基于一阶MC的方法表现出强劲的性能，尤其是在稀疏数据集上[19]。

也有方法采用高阶MC来考虑更多的历史项目[20]，[21]。特别地，卷积序列嵌入（Caser）是一种基于CNN的方法，它将 L 个历史项目的嵌入矩阵视为一幅"图像"，并应用卷积操作来提取转移模式[22]。

除了基于MC的方法，另一类工作采用RNN来建模用户序列[2]，[23]–[25]。例如，GRU4Rec 使用门控循环单元（GRU）建模点击序列以进行基于会话的推荐[2]，改进版本进一步提升了 Top-N 推荐性能[26]。在每个时间步，RNN将上一时间步的状态和当前动作作为输入。这种依赖关系使得RNN效率较低，尽管已经提出了"会话并行"等技术来提高效率[2]。

### D. 注意力机制

注意力机制已被证明在诸如图像描述[27]和机器翻译[28]等各种任务中非常有效。这些机制的核心思想在于，序列输出（例如）依赖于模型应依次关注的输入的某些"相关"部分。另一个好处是基于注意力的方法通常更具可解释性。最近，注意力机制已被引入推荐系统[29]–[31]。例如，注意力分解机（AFM）[30]为内容感知推荐学习每个特征交互的重要性。

然而，上述技术使用的注意力本质上是对原始模型的附加组件（如注意力+RNN、注意力+FM等）。最近，一种纯基于注意力的序列到序列方法——Transformer [3]——在机器翻译任务上取得了最先进的性能和效率，而此前该领域由基于RNN/CNN的方法主导[32]，[33]。Transformer 模型严重依赖所提出的"自注意力"模块来捕获句子中的复杂结构，并检索相关词语（源语言中）以生成下一个词（目标语言中）。受Transformer启发，我们试图基于自注意力方法构建一个新的序列推荐模型，尽管序列推荐问题与机器翻译截然不同，需要专门设计的模型。

## III. 方法

在序列推荐的设定中，我们给定用户的动作序列 Su = ($S_u1$, $S_u2$, ..., $S_u$|Su|)，并试图预测下一个项目。在训练过程中，在时间步 t，模型依赖于之前的 t 个项目来预测下一个项目。如图1所示，将模型的输入视为 ($S_u1$, $S_u2$, ..., $S_u$|Su|−$_1$)，其期望输出视为同一序列的"移位"版本：($S_u2$, $S_u3$, ..., $S_u$|Su|)，是比较方便的。本节中，我们描述如何通过嵌入层、多个自注意力块和预测层来构建序列推荐模型。我们还分析了其复杂度，并进一步讨论了 SASRec 与相关模型的区别。我们的符号总结在表 I 中。

**表 I: 符号说明**

| 符号 | 描述 |
|------|------|
| U, I | 用户集和项目集 |

| S^(b) $∈$ R^{n$×$d} | 经过第 b 个自注意力层后的项目嵌入 |
| F^(b) $∈$ R^{n$×$d} | 经过第 b 个前馈网络后的项目嵌入 |

### A. 嵌入层

我们将训练序列 ($S_u1$, $S_u2$, ..., $S_u$|Su|−$_1$) 转换为固定长度的序列 s = ($s_1$, $s_2$, ..., $s_n$)，其中 n 表示我们的模型能处理的最大长度。如果序列长度大于 n，我们考虑最近的 n 个动作。如果序列长度小于 n，我们重复在左侧添加"填充"项目直到长度为 n。我们创建项目嵌入矩阵 M $∈$ R^{|I|$×$d}，其中 d 是潜在维度，并获取输入嵌入矩阵 E $∈$ R^{n$×$d}，其中 $E_i$ = $M_{si}$。零向量 0 作为填充项目的嵌入。

**位置嵌入 (Positional Embedding)**：如下一节所述，由于自注意力模型不包含任何循环或卷积模块，它无法感知之前项目的位置。因此我们将一个可学习的位置嵌入 P $∈$ R^{n$×$d} 注入到输入嵌入中：

```
Ê = [M_{s₁} + P₁, M_{s₂} + P₂, ..., M_{sₙ} + Pₙ]ᵀ     (1)
```

我们还尝试了[3]中使用的固定位置嵌入，但发现在我们的场景中这会导致较差的性能。我们在实验中对位置嵌入的效果进行了定量和定性分析。

### B. 自注意力块

缩放点积注意力 (scaled dot-product attention) [3] 定义为：

```
Attention(Q, K, V) = softmax(QKᵀ / √d) V            (2)
```

其中 Q 表示查询（queries），K 表示键（keys），V 表示值（values）（每行代表一个项目）。直观上，注意力层计算所有值的加权和，其中查询 i 和值 j 之间的权重与查询 i 和键 j 之间的交互有关。缩放因子 √d 是为了避免内积值过大，特别是在维度较高时。

**自注意力层 (Self-Attention layer)**：在机器翻译等 NLP 任务中，注意力机制通常使用 K = V（例如使用 RNN 编码器-解码器进行翻译：编码器的隐藏状态作为键和值，解码器的隐藏状态作为查询）[28]。最近，提出了一种自注意力方法，它使用相同的对象作为查询、键和值[3]。在我们的情况下，自注意力操作将嵌入 Ê 作为输入，通过线性投影将其转换为三个矩阵，并送入注意力层：

```
S = SA(Ê) = Attention(ÊW^Q, ÊW^K, ÊW^V)             (3)
```

其中投影矩阵 W^Q, W^K, W^V $∈$ R^{d$×$d}。投影使模型更加灵活。例如，模型可以学习非对称交互（即 <查询 i, 键 j> 和 <查询 j, 键 i> 可以有不同的交互）。

**因果性 (Causality)**：由于序列的性质，模型在预测第 (t+1) 个项目时应仅考虑前 t 个项目。然而，自注意力层的第 t 个输出 (S_t) 包含后续项目的嵌入，这将使模型不适定。因此，我们修改注意力机制，禁止 $Q_i$ 和 $K_j$ (j > i) 之间的所有连接。

**逐点前馈网络 (Point-Wise Feed-Forward Network)**：尽管自注意力能够以自适应权重聚合所有之前项目的嵌入，但它本质上仍是一个线性模型。为了使模型具有非线性并考虑不同潜在维度之间的交互，我们对所有 $S_i$ 应用相同的（共享参数）逐点两层前馈网络：

```
Fᵢ = FFN(Sᵢ) = ReLU(Sᵢ W^(1) + b^(1)) W^(2) + b^(2)   (4)
```

其中 W^(1), W^(2) $∈$ R^{d$×$d} 是矩阵，b^(1), b^(2) $∈$ R^d 是向量。注意 $S_i$ 和 $S_j$ (i $≠$ j) 之间没有交互，这意味着我们仍然防止信息泄露（从后向前）。

### C. 堆叠自注意力块

在第一个自注意力块之后，F 本质上聚合了所有之前项目的嵌入（即 $Ê_j$, j $≤$ i）。然而，通过基于 F 的另一个自注意力块来学习更复杂的项目转换可能是有用的。具体来说，我们堆叠自注意力块（即一个自注意力层和一个前馈网络），第 b 个（b > 1）块定义为：

```
S^(b) = SA(F^(b−1)),  Fᵢ^(b) = FFN(Sᵢ^(b)), ∀i ∈ {1,2,...,n}   (5)
```

第一个块定义为 S^(1) = S 和 F^(1) = F。

然而，当网络变深时，几个问题会加剧：1）模型容量增加导致过拟合；2）训练过程变得不稳定（由于梯度消失等）；3）参数更多的模型通常需要更长的训练时间。受[3]启发，我们执行以下操作来缓解这些问题：

```
g(x) = x + Dropout(g(LayerNorm(x)))
```

其中 g(x) 表示自注意力层或前馈网络。也就是说，对于每个块中的层 g，我们在将输入 x 送入 g 之前对 x 应用层归一化，对 g 的输出应用 dropout，并将输入 x 加到最终输出上。下面介绍这些操作。

**残差连接 (Residual Connections)**：在某些情况下，多层神经网络已证明能够分层学习有意义的特征[34]。然而，简单地增加层数并不容易带来更好的性能，直到残差网络被提出[35]。残差网络的核心思想是通过残差连接将低层特征传播到高层。因此，如果低层特征有用，模型可以轻松将其传播到最终层。类似地，我们假设残差连接在我们的场景中也是有用的。例如，现有的序列推荐方法已经表明，最后访问的项目对预测下一个项目起着关键作用[1]，[19]，[21]。然而，经过多个自注意力块后，最后访问的项目的嵌入会与所有之前的项目纠缠在一起；添加残差连接将最后访问的项目的嵌入传播到最终层，将使模型更容易利用低层信息。

**层归一化 (Layer Normalization)**：层归一化用于对跨特征的输入进行归一化（即零均值和单位方差），这有利于稳定和加速神经网络训练[36]。与批归一化[37]不同，层归一化中使用的统计量与同一批次中的其他样本无关。具体来说，假设输入是包含一个样本所有特征的向量 x，操作为：

```
LayerNorm(x) = α ⊙ (x − μ) / √(σ² + ε) + β
```

其中 $⊙$ 是逐元素乘积（即 Hadamard 积），μ 和 σ 是 x 的均值和方差，α 和 β 是可学习的缩放因子和偏置项。

**Dropout**：为缓解深度神经网络中的过拟合问题，"Dropout"正则化技术已被证明在各种神经网络架构中有效[38]。Dropout 的思想很简单：在训练期间以概率 p 随机"关闭"神经元，测试时使用所有神经元。进一步分析指出，dropout 可以被视为一种集成学习形式，它考虑了共享参数的大量模型（指数级于神经元和输入特征的数量）[39]。我们还在嵌入 Ê 上应用了 dropout 层。

### D. 预测层

在经过 b 个自适应且分层地提取已消费项目信息的自注意力块之后，我们基于 F_t^(b) 预测下一个项目（给定前 t 个项目）。具体来说，我们采用 MF 层来预测项目 i 的相关性：

```
r_{i,t} = F_t^(b) N_iᵀ
```

其中 $r_{i,t}$ 是在给定前 t 个项目（即 $s_1$, $s_2$, ..., $s_t$）的情况下项目 i 是下一个项目的相关性分数，N $∈$ R^{|I|$×$d} 是一个项目嵌入矩阵。因此，高交互分数 $r_{i,t}$ 意味着高相关性，我们可以通过对分数进行排序来生成推荐。

**共享项目嵌入 (Shared Item Embedding)**：为减少模型规模并缓解过拟合，我们考虑另一种方案，仅使用单一项目嵌入 M：

```
r_{i,t} = F_t^(b) M_iᵀ                                 (6)
```

注意 F_t^(b) 可以表示为依赖于项目嵌入 M 的函数：F_t^(b) = f($M_{s1}$, $M_{s2}$, ..., $M_{st}$)。使用同质项目嵌入的一个潜在问题是它们的内积不能表示非对称项目转移（例如，项目 i 经常在 j 之后被购买，但反之不然），因此像 FPMC 这样的现有方法倾向于使用异质项目嵌入。然而，我们的模型没有这个问题，因为它学习了一个非线性变换。例如，前馈网络可以轻松地用相同的项目嵌入实现非对称性：FFN(M_i)M_jᵀ $≠$ FFN(M_j)M_iᵀ。实验证明，使用共享的项目嵌入显著提高了我们模型的性能。

**显式用户建模 (Explicit User Modeling)**：为提供个性化推荐，现有方法通常采用两种方法之一：1）学习一个显式的用户嵌入来表示用户偏好（如 MF [40]、FPMC [1] 和 Caser [22]）；2）考虑用户之前的动作，并从已访问项目的嵌入中推导出隐式用户嵌入（如 FSIM [8]、Fossil [21]、GRU4Rec [2]）。我们的方法属于后一类，因为我们通过考虑用户的所有动作来生成嵌入 F_n^(b)。然而，我们也可以在最后一层插入显式用户嵌入，例如通过加法：$r_{u,i,t}$ = (U_u + F_t^(b)) M_iᵀ，其中 U 是用户嵌入矩阵。但实验发现，添加显式用户嵌入并不能提升性能（可能是因为模型已经考虑了用户的所有动作）。

### E. 网络训练

回顾一下，我们将每个用户序列（排除最后一个动作）($S_u1$, $S_u2$, ..., $S_u$|Su|−$_1$) 通过截断或填充转换为固定长度序列 s = {$s_1$, $s_2$, ..., $s_n$}。定义 $o_t$ 为时间步 t 的期望输出：

```
oₜ = <pad>   如果 sₜ 是填充项目
oₜ = sₜ$_{+}$₁    如果 1 ≤ t < n
oₜ = Sᵤ|Su|  如果 t = n
```

其中 <pad> 表示填充项目。我们的模型将序列 s 作为输入，对应的序列 o 作为期望输出，并采用二元交叉熵损失作为目标函数：

```
− Σ_{Sᵤ} Σ_{t∈[1,2,...,n]} [ log(σ(r_{oₜ,t})) + Σ_{j∉Sᵤ} log(1 − σ(r_{j,t})) ]
```

注意我们忽略 $o_t$ = <pad> 的项。

网络使用 Adam 优化器[41]进行优化，它是带有自适应矩估计的随机梯度下降（SGD）的变体。在每个 epoch 中，我们为每个序列中的每个时间步随机生成一个负样本项目 j。更多的实现细节将在后面描述。

### F. 复杂度分析

**空间复杂度**：我们模型中的学习参数来自嵌入层以及自注意力层、前馈网络和层归一化中的参数。参数总数为 O(|I|d + nd + d²)，与其他方法相比是适度的（例如 FPMC 为 O(|U|d + |I|d)），因为它不随用户数量增长，且 d 在推荐问题中通常很小。

**时间复杂度**：我们模型的计算复杂度主要来自自注意力层和前馈网络，为 O(n²d + nd²)。主导项通常是自注意力层的 O(n²d)。然而，我们的模型有一个便利的特性：每个自注意力层中的计算是完全可并行的，这有利于 GPU 加速。相比之下，基于RNN的方法（如 GRU4Rec [2]）存在时间步依赖（即时间步 t 的计算必须等待时间步 t-1 的结果），这导致顺序操作的时间复杂度为 O(n)。我们实验发现，我们的方法在 GPU 上比基于 RNN 和 CNN 的方法快十倍以上（结果与[3]中机器翻译任务的结果类似），且最大长度 n 可以轻松扩展到几百，这通常足以满足现有的基准数据集。

测试时，对于每个用户，在计算出嵌入 F_n^(b) 后，过程与标准 MF 方法相同（评估对某个项目偏好的复杂度为 O(d)）。

**处理长序列**：虽然我们的实验实证验证了方法的效率，但它最终无法扩展到非常长的序列。有几个可选的方案值得在未来研究中探索：1）使用受限自注意力[42]，只关注最近的动作而非所有动作，远距离动作可以在更高层中考虑；2）如[22]中将长序列分割为短片段。

### G. 讨论

我们发现 SASRec 可以视为某些经典协同过滤模型的泛化。我们还在概念上讨论了我们的方法和现有方法如何处理序列建模。

**简化为现有模型：**

- **分解马尔可夫链 (FMC)**：FMC 分解一阶项目转移矩阵，并基于最后一项 i 预测下一项 j：P(j|i) ∝ M_i N_jᵀ。如果我们将自注意力块设为零，使用非共享的项目嵌入，并移除位置嵌入，SASRec 将简化为 FMC。此外，SASRec 也与分解个性化马尔可夫链 (FPMC) [1] 密切相关，后者融合了 MF 和 FMC 来分别捕获用户偏好和短期动态：P(j|u,i) ∝ [U_u, M_i] N_jᵀ。在上述 FMC 的简化操作基础上，再添加一个显式的用户嵌入（通过拼接），SASRec 等价于 FPMC。

- **分解项目相似度模型 (FISM) [8]**：FISM 通过考虑 i 与用户之前消费过的项目之间的相似度来估计对项目 i 的偏好分数：P(j|u) ∝ (1/|$S_u$|) Σ_{i$∈$$S_u$} M_i N_jᵀ。如果我们使用一层自注意力（排除前馈网络），对项目设置均匀注意力权重（1/|$S_u$|），使用非共享项目嵌入，并移除位置嵌入，SASRec 将简化为 FISM。因此，我们的模型可以被视为一种自适应的、分层的、序列化的项目相似度模型，用于下一个项目推荐。

**基于MC的推荐**：马尔可夫链（MC）可以有效捕获局部序列模式，假设下一个项目只依赖于之前的 L 个项目。现有的基于MC的序列推荐方法要么依赖一阶MC（如 FPMC [1]、HRM [43]、TransRec [19]），要么依赖高阶MC（如 Fossil [21]、Vista [20]、Caser [22]）。第一类方法在稀疏数据集上表现最好。相比之下，基于高阶MC的方法有两个局限性：（1）MC 阶数 L 需要在训练前指定，而不是自适应选择；（2）性能和效率不会随 L 很好地扩展，因此 L 通常很小（例如小于 5）。我们的方法解决了第一个问题，因为它可以自适应地关注相关的历史项目（例如，在稀疏数据集上只关注最后一个项目，在密集数据集上关注更多项目）。此外，我们的模型本质上以 n 个历史项目为条件，实验上可以扩展到数百个历史项目，在适度增加训练时间的情况下带来性能提升。

**基于RNN的推荐**：另一类工作使用 RNN 对用户动作序列进行建模[2]，[17]，[26]。RNN 通常适用于序列建模，尽管最近的研究显示 CNN 和自注意力在某些序列设置中可以更强[3]，[44]。我们基于自注意力的模型可以从项目相似度模型推导而来，后者是推荐序列建模的一个合理替代方案。对于 RNN，除了其并行计算效率低下（第三节-F）之外，其最大路径长度（从输入节点到相关输出节点）为 O(n)。相比之下，我们的模型具有 O(1) 的最大路径长度，这有利于学习长距离依赖[45]。

- **RQ1**：SASRec 是否优于包括基于CNN/RNN方法在内的最先进模型？
- **RQ2**：SASRec 架构中各种组件的影响是什么？
- **RQ3**：SASRec 的训练效率和可扩展性（关于 n）如何？
- **RQ4**：注意力权重是否能学习到与位置或项目属性相关的有意义的模式？

### A. 数据集

- **Amazon**：[46]中引入的一系列数据集，包含从 Amazon.com 抓取的大型产品评论语料。Amazon 上的顶级产品类别被视为单独的数据集。我们考虑两个类别："Beauty"（美妆）和"Games"（游戏）。该数据集以其高稀疏性和变异性著称。

- **MovieLens**：一个广泛使用的用于评估协同过滤算法的基准数据集。我们使用包含 100 万用户评分的版本（MovieLens-1M）。

### B. 对比方法

为展示我们方法的有效性，我们包括三组推荐基线方法。第一组包括仅考虑用户反馈而不考虑动作序列顺序的通用推荐方法：

- **PopRec**：一个简单基线，根据项目流行度（即关联的动作数量）对项目进行排序。
- **贝叶斯个性化排序 (BPR) [5]**：BPR 是一种从隐式反馈中学习个性化排名的经典方法。使用有偏矩阵分解作为底层推荐器。

第二组包含基于一阶马尔可夫链的序列推荐方法，这些方法考虑最后访问的项目：

- **分解马尔可夫链 (FMC)**：一阶马尔可夫链方法。FMC 使用两个项目嵌入分解项目转移矩阵，并仅基于最后访问的项目生成推荐。
- **分解个性化马尔可夫链 (FPMC) [1]**：FPMC 使用矩阵分解和分解一阶马尔可夫链的组合作为其推荐器，捕获用户的长期偏好以及项目到项目的转移。
- **基于平移的推荐 (TransRec) [19]**：一种最先进的一阶序列推荐方法，将每个用户建模为一个平移向量，以捕获从当前项目到下一个项目的转移。

最后一组包含基于深度学习的序列推荐系统，它们考虑多个（或所有）历史访问项目：

- **GRU4Rec [2]**：一种开创性方法，使用 RNN 对用户动作序列进行建模以进行基于会话的推荐。我们将每个用户的反馈序列视为一个会话。
- **GRU4Rec+ [26]**：GRU4Rec 的改进版本，采用不同的损失函数和采样策略，在 Top-N 推荐上显示出显著的性能提升。
- **卷积序列嵌入 (Caser) [22]**：最近提出的基于 CNN 的方法，通过在最近 L 个项目的嵌入矩阵上应用卷积操作来捕获高阶马尔可夫链，取得了最先进的序列推荐性能。

由于其他序列推荐方法（如 PRME [47]、HRM [43]、Fossil [21]）在上述基线中的类似数据集上已被超越，我们省略了对它们的比较。我们也不包括像 TimeSVD++ [16] 和 RRN [17] 这样的时间推荐方法，它们与我们在此考虑的设置不同。

为公平比较，我们使用 TensorFlow 和 Adam [41] 优化器实现了 BPR、FMC、FPMC 和 TransRec。对于 GRU4Rec、GRU4Rec+ 和 Caser，我们使用相应作者提供的代码。除 PopRec 外，所有方法我们考虑潜在维度 d $∈$ {10, 20, 30, 40, 50}。对于 BPR、FMC、FPMC 和 TransRec，L2 正则化项从 {0.0001, 0.001, 0.01, 0.1, 1} 中选择。所有其他超参数和初始化策略使用各方法作者建议的值。我们使用验证集调整超参数，如果验证性能在 20 个 epoch 内没有提升，则终止训练。

### C. 实现细节

对于默认版本的 SASRec 架构，我们使用两个自注意力块（b = 2），并使用可学习的位置嵌入。嵌入层和预测层中的项目嵌入是共享的。我们使用 TensorFlow 实现 SASRec。优化器为 Adam [41]，学习率设为 0.001，批量大小为 128。dropout 率（神经元关闭概率）在 MovieLens-1M 上为 0.2，在其他三个数据集上为 0.5（由于它们的稀疏性）。最大序列长度 n 在 MovieLens-1M 上设为 200，在其他三个数据集上设为 50，大致与每个用户的平均动作数成比例。下面对变体及不同超参数的性能进行了检验。

### D. 评估指标

我们采用两种常见的 Top-N 指标，Hit Rate@10 和 NDCG@10，来评估推荐性能[14]，[19]。Hit@10 计算真实下一个项目出现在前 10 个项目中的比例，而 NDCG@10 是一个位置感知指标，对较高位置的排名赋予更大的权重。注意由于每个用户只有一个测试项目，Hit@10 等价于 Recall@10，并与 Precision@10 成正比。

为避免在所有用户-项目对上计算的高昂开销，我们遵循[14]，[48]中的策略。对于每个用户 u，我们随机采样 100 个负项目，并将这些项目与真实项目一起排序。基于这 101 个项目的排名，可以评估 Hit@10 和 NDCG@10。

### F. 消融研究

由于我们的架构中有许多组件，我们通过消融研究（RQ2）分析它们的影响。表 IV 展示了我们的默认方法及其 8 个变体在所有四个数据集上的性能（d = 50）。我们介绍这些变体并分别分析它们的效果：

- **(1) 移除 PE（位置嵌入）**：没有位置嵌入 P 时，每个项目上的注意力权重仅取决于项目嵌入。也就是说，模型基于用户过去的动作进行推荐，但它们的顺序无关紧要。该变体可能适用于用户序列通常较短的稀疏数据集。该变体在最稀疏的数据集（Beauty）上优于默认模型，但在其他较密集的数据集上表现较差。

- **(2) 非共享 IE（项目嵌入）**：我们发现使用两个项目嵌入 consistently 损害了性能，可能是由于过拟合。

- **(3) 移除 RC（残差连接）**：没有残差连接时，我们发现性能显著变差。这可能是因为低层信息（如最后一个项目的嵌入和第一个块的输出）不能轻易传播到最终层，而这些信息对做推荐非常有用，尤其是在稀疏数据集上。

- **(4) 移除 Dropout**：我们的结果表明，dropout 可以有效地正则化模型以达到更好的测试性能，尤其是在稀疏数据集上。结果还表明过拟合问题在密集数据集上不那么严重。

- **(5)-(7) 块的数量**：毫不奇怪，零个块的结果较差，因为模型将仅依赖于最后一个项目。一个块的变体表现相当不错，尽管使用两个块（默认模型）仍然提升了性能，特别是在密集数据集上，这意味着层次化的自注意力结构有助于学习更复杂的项目转换。使用三个块的性能与默认模型相似。

- **(8) 多头**：Transformer [3] 的作者发现使用"多头"注意力是有用的，它在 h 个子空间（每个为 d/h 维）中应用注意力。然而，在我们的场景中，两个头的性能 consistently 略差于单头注意力。这可能归因于我们问题中 d 较小（Transformer 中 d = 512），不适合分解为更小的子空间。

### H. 注意力权重可视化

回顾一下，在时间步 t，我们模型中的自注意力机制根据位置嵌入和项目嵌入，自适应地为前 t 个项目分配权重。为回答 RQ4，我们检查所有训练序列，并通过展示位置和项目上的平均注意力权重来揭示有意义的模式。

**位置上的注意力**：图4展示了最后 15 个时间步在最后 15 个位置上的平均注意力权重的四个热力图。注意，在计算平均权重时，分母是有效权重的数量，以避免短序列中填充项目的影响。

我们考虑热力图之间的几个比较：

- **(a) vs. (c)**：这一比较表明，模型在稀疏数据集 Beauty 上倾向于关注更近期的项目，而在密集数据集 ML-1M 上关注更远期的项目。这是我们的模型能够自适应处理稀疏和密集数据集的关键因素，而现有方法往往只关注谱系的一端。

- **(b) vs. (c)**：这一比较显示了使用位置嵌入（PE）的效果。没有位置嵌入时，注意力权重在历史项目上基本均匀分布，而默认模型（c）在位置上更敏感，倾向于关注近期项目。

- **(c) vs. (d)**：由于我们的模型是层次化的，这显示了注意力在不同块之间的变化。显然，高层中的注意力倾向于聚焦于更近的位置。这可能是因为第一个自注意力块已经考虑了所有之前的项目，第二个块不需要考虑较远的位置。

总体而言，可视化显示我们自注意力机制的行为是自适应的、位置感知的且层次化的。

## V. 结论

在这项工作中，我们提出了一种新颖的基于自注意力的序列模型 SASRec，用于下一个项目推荐。SASRec 对整个用户序列进行建模（没有任何循环或卷积操作），并自适应地考虑已消费项目来进行预测。在稀疏和密集数据集上的大量实验结果表明，我们的模型优于最先进的基线方法，并且比基于CNN/RNN的方法快一个数量级。在未来，我们计划通过融入丰富的上下文信息（如停留时间、动作类型、位置、设备等）来扩展该模型，并研究处理超长序列（如点击序列）的方法。
