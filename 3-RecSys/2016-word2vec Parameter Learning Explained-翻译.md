## 摘要

Mikolov等人提出的word2vec模型及应用在过去两年中引起了广泛关注。通过word2vec模型学习到的词向量表示已被证明能够承载语义信息，并在各种自然语言处理任务中发挥作用。随着越来越多的研究人员希望尝试word2vec或类似技术，我注意到目前缺乏一份能够全面、详细解释词嵌入模型参数学习过程的资料，这使得非神经网络专家的研究者难以理解此类模型的工作机制。

本文详细推导和解释了word2vec模型的参数更新方程，包括原始的连续词袋（CBOW）和跳字（SG）模型，以及先进的优化技术，包括层次化softmax和负采样。在数学推导之外，还提供了梯度方程的直观解释。

在附录中，本文回顾了神经元网络和反向传播的基础知识。我还创建了一个交互式演示工具wevi，以帮助读者直观理解该模型¹。

## 1 连续词袋模型

### 1.1 单词上下文

我们从Mikolov等人（2013a）提出的连续词袋模型（CBOW）的最简版本开始。我们假设每个上下文只考虑一个词，这意味着模型将根据一个上下文词预测一个目标词，类似于一个二元语法模型。对于刚接触神经网络的读者，建议先阅读附录A以快速回顾重要的概念和术语，然后再继续阅读。

图1展示了简化上下文定义下的网络模型²。在我们的设定中，词汇表大小为V，隐藏层大小为N。相邻层之间的单元是全连接的。输入是一个独热编码向量，这意味着对于给定的输入上下文词，V个单元{x₁,···,x_V}中只有一个为1，其余所有单元均为0。

输入层和输出层之间的权重可以用一个V$\times$N矩阵W表示。W的每一行都是输入层关联词的N维向量表示v_w。形式化地，W的第i行是v_wᵀ。给定一个上下文（一个词），假设x_k=1且对k'\neqk有x_k'=0，我们有：

h = Wᵀx = Wᵀ_(k,·) := $v_{w_I}$ᵀ (1)

这实际上是将W的第k行复制到h。$v_{w_I}$是输入词w_I的向量表示。这意味着隐藏层单元的链接（激活）函数就是简单的线性函数（即直接将其加权和传递给下一层）。

从隐藏层到输出层，有一个不同的权重矩阵W' = {w'_{ij}}，它是一个N$\times$V矩阵。使用这些权重，我们可以为词汇表中的每个词j计算一个分数u_j：

u_j = v'_{w_j}ᵀ h (2)

其中v'_{w_j}是矩阵W'的第j列。然后我们可以使用softmax（一种对数线性分类模型）来获得词的后验分布，这是一个多项分布：

p(w_j|w_I) = y_j = exp(u_j) / \Sigma_{j'=1}^V exp($u_{j'}$) (3)

其中y_j是输出层第j个单元的输出。将(1)和(2)代入(3)，我们得到：

p(w_j|w_I) = exp(v'_{w_j}ᵀ $v_{w_I}$) / \Sigma_{j'=1}^V exp(v'_{$w_{j'}$}ᵀ $v_{w_I}$) (4)

注意v_w和v'_w是词w的两种表示。v_w来自W的行，即输入\rightarrow隐藏权重矩阵；v'_w来自W'的列，即隐藏\rightarrow输出矩阵。在下文中，我们将v_w称为词w的"输入向量"，将v'_w称为词w的"输出向量"。

#### 隐藏\rightarrow输出权重的更新方程

现在让我们推导该模型的权重更新方程。尽管实际计算是不切实际的（下文会解释），但我们进行推导是为了深入了解这个未使用任何技巧的原始模型。有关反向传播基础知识的回顾，请参见附录A。

训练目标（对于一个训练样本）是在给定输入上下文词w_I的条件下，最大化观察到实际输出词w_O（其在输出层中的索引记为j*）的条件概率：

max p(w_O|w_I) = max $y_{j*}$ (5)
= max log $y_{j*}$ (6)
= $u_{j*}$ - log \Sigma_{j'=1}^V exp($u_{j'}$) := -E (7)

其中E = -log p(w_O|w_I)是我们的损失函数（我们想要最小化E），j*是实际输出词在输出层中的索引。注意，该损失函数可以理解为两个概率分布之间交叉熵测量的一种特殊情况。

现在让我们推导隐藏层和输出层之间权重的更新方程。对第j个单元的网络输入u_j求E的偏导，我们得到：

\partialE/\partialu_j = y_j - t_j := e_j (8)

其中t_j = 1(j = j*)，即仅当第j个单元是实际输出词时t_j=1，否则t_j=0。注意该导数就是输出层的预测误差e_j。

接下来我们对w'_{ij}求导，以获得隐藏\rightarrow输出权重的梯度：

\partialE/\partialw'_{ij} = (\partialE/\partialu_j)·(\partialu_j/\partialw'_{ij}) = e_j·h_i (9)

因此，使用随机梯度下降，我们得到隐藏\rightarrow输出权重的更新方程：

w'_{ij}(new) = w'_{ij}(old) - \eta·e_j·h_i (10)

或者：

v'_{w_j}(new) = v'_{w_j}(old) - \eta·e_j·h, 对于 j = 1,2,···,V (11)

其中\eta > 0是学习率，e_j = y_j - t_j，h_i是隐藏层中的第i个单元；v'_{w_j}是w_j的输出向量。注意，这个更新方程意味着我们必须遍历词汇表中的每一个可能的词，检查其输出概率y_j，并将y_j与其期望输出t_j（0或1）进行比较。如果y_j > t_j（"高估"），那么我们从v'_{w_j}中减去隐藏向量h（即$v_{w_I}$）的一部分，从而使v'_{w_j}远离$v_{w_I}$；如果y_j < t_j（"低估"，这仅在t_j=1时成立，即w_j = w_O），我们将一些h加到v'_{w_O}上，从而使v'_{w_O}更接近³ $v_{w_I}$。如果y_j非常接近t_j，那么根据更新方程，权重几乎不会发生变化。再次注意，v_w（输入向量）和v'_w（输出向量）是词w的两种不同的向量表示。

#### 输入\rightarrow隐藏权重的更新方程

在得到W'的更新方程之后，我们现在可以转向W。我们对隐藏层的输出求E的偏导，得到：

\partialE/\partialh_i = \Sigma_{j=1}^V (\partialE/\partialu_j)·(\partialu_j/\partialh_i) = \Sigma_{j=1}^V e_j·w'_{ij} := EH_i (12)

其中h_i是隐藏层第i个单元的输出；u_j在(2)中定义，是输出层第j个单元的网络输入；e_j = y_j - t_j是输出层第j个词的预测误差。EH是一个N维向量，是词汇表中所有词的输出向量按其预测误差加权后的和。

接下来，我们应该对W求E的偏导。首先，回顾隐藏层对输入层的值进行线性计算。展开(1)中的向量符号，我们得到：

h_i = \Sigma_{k=1}^V x_k·$w_{ki}$ (13)

现在我们可以对W的每个元素求E的偏导，得到：

\partialE/\partial$w_{ki}$ = (\partialE/\partialh_i)·(\partialh_i/\partial$w_{ki}$) = EH_i·x_k (14)

这等价于x和EH的张量积，即：

\partialE/\partialW = x \otimes EH = x·EHᵀ (15)

由此我们得到一个V$\times$N矩阵。由于x只有一个非零分量，因此\partialE/\partialW只有一行非零，该行的值是一个N维向量EHᵀ。我们得到W的更新方程为：

$v_{w_I}$(new) = $v_{w_I}$(old) - \eta·EHᵀ (16)

其中$v_{w_I}$是W的一行，即唯一上下文词的"输入向量"，也是W中导数非零的唯一一行。W的所有其他行在这次迭代后将保持不变，因为它们的导数为零。

直观地理解，由于向量EH是词汇表中所有词的输出向量按其预测误差e_j = y_j - t_j加权后的和，我们可以将(16)理解为将词汇表中每个输出向量的一部分加到上下文词的输入向量上。如果在输出层中，某个词w_j作为输出词的概率被高估（y_j > t_j），那么上下文词w_I的输入向量将趋向于远离w_j的输出向量；反之，如果w_j作为输出词的概率被低估（y_j < t_j），那么w_I的输入向量将趋向于靠近w_j的输出向量；如果w_j的概率被准确预测，那么它对w_I输入向量的移动影响很小。w_I输入向量的移动由词汇表中所有向量的预测误差共同决定；预测误差越大，该词对上下文词输入向量移动的影响就越显著。

当我们通过遍历训练语料生成的上下文-目标词对来迭代更新模型参数时，对向量的影响会逐渐累积。我们可以想象，词w的输出向量被w的共现邻居的输入向量来回"拖拽"，就像w的向量与其邻居的向量之间存在着物理弹簧一样。类似地，输入向量也可以看作被许多输出向量拖拽。这种解释可以让我们联想到引力或力导向图布局。每根虚拟弹簧的平衡长度与相关词对之间的共现强度以及学习率有关。经过多次迭代后，输入向量和输出向量的相对位置最终将趋于稳定。

### 1.2 多词上下文

图2展示了多词上下文设置下的CBOW模型。在计算隐藏层输出时，CBOW模型不是直接复制输入上下文词的输入向量，而是取输入上下文词向量的平均值，并将输入\rightarrow隐藏权重矩阵与平均向量的乘积作为输出：

h = (1/C)·Wᵀ(x₁ + x₂ + ··· + x_C) (17)
= (1/C)·($v_{w₁}$ + $v_{w₂}$ + ··· + $v_{w_C}$)ᵀ (18)

其中C是上下文中的词数，w₁,···,w_C是上下文中的词，v_w是词w的输入向量。损失函数为：

E = -log p(w_O|$w_{I,1}$,···,$w_{I,C}$) (19)
= -$u_{j*}$ + log \Sigma_{j'=1}^V exp($u_{j'}$) (20)
= -v'_{w_O}ᵀ·h + log \Sigma_{j'=1}^V exp(v'_{$w_{j'}$}ᵀ·h) (21)

这与(7)相同，即单词语境模型的目标函数，但h不同，如(18)而非(1)所定义。

隐藏\rightarrow输出权重的更新方程与单词语境模型（11）相同。我们将其复制如下：

v'_{w_j}(new) = v'_{w_j}(old) - \eta·e_j·h, 对于 j = 1,2,···,V (22)

注意，对于每个训练实例，我们需要对隐藏\rightarrow输出权重矩阵的每个元素应用此更新。

输入\rightarrow隐藏权重的更新方程与(16)类似，不同之处在于现在我们需要对上下文中的每个词$w_{I,c}$应用以下方程：

$v_{w_{I,c}$}(new) = $v_{w_{I,c}$}(old) - (1/C)·\eta·EHᵀ, 对于 c = 1,2,···,C (23)

其中$v_{w_{I,c}$}是输入上下文中第c个词的输入向量；\eta是正学习率；EH = \partialE/\partialh_i由(12)给出。该更新方程的直观理解与(16)相同。

## 2 跳字模型

跳字模型由Mikolov等人（2013a,b）提出。图3展示了跳字模型。它与CBOW模型相反：目标词现在位于输入层，而上下文词位于输出层。

我们仍然用$v_{w_I}$表示输入层上唯一词的输入向量，因此隐藏层输出h的定义与(1)相同，即h简单地复制（并转置）与输入词w_I关联的输入\rightarrow隐藏权重矩阵W的一行。我们将在下面复制h的定义：

h = Wᵀ_(k,·) := $v_{w_I}$ᵀ (24)

在输出层上，不是输出一个多项分布，而是输出C个多项分布。每个输出使用相同的隐藏\rightarrow输出矩阵计算：

p($w_{c,j}$ = $w_{O,c}$|w_I) = $y_{c,j}$ = exp($u_{c,j}$) / \Sigma_{j'=1}^V exp($u_{j'}$) (25)

其中$w_{c,j}$是输出层第c个面板上的第j个词；$w_{O,c}$是输出上下文中的实际第c个词；w_I是唯一的输入词；$y_{c,j}$是输出层第c个面板上第j个单元的输出；$u_{c,j}$是输出层第c个面板上第j个单元的网络输入。由于输出层面板共享相同的权重，因此：

$u_{c,j}$ = u_j = v'_{w_j}ᵀ·h, 对于 c = 1,2,···,C (26)

其中v'_{w_j}是词汇表中第j个词w_j的输出向量，且v'_{w_j}取自隐藏\rightarrow输出权重矩阵W'的一列。

参数更新方程的推导与单词语境模型没有太大区别。损失函数变为：

E = -log p($w_{O,1}$, $w_{O,2}$, ···, $w_{O,C}$ | w_I) (27)
= -log $\Pi$_{c=1}^C [ exp($u_{c,j*_c}$) / \Sigma_{j'=1}^V exp($u_{j'}$) ] (28)
= - \Sigma_{c=1}^C $u_{j*_c}$ + C·log \Sigma_{j'=1}^V exp($u_{j'}$) (29)

其中j*_c是词汇表中第c个实际输出上下文词的索引。

我们对输出层每个面板上每个单元的网络输入$u_{c,j}$求E的偏导，得到：

\partialE/\partial$u_{c,j}$ = $y_{c,j}$ - $t_{c,j}$ := $e_{c,j}$ (30)

这就是该单元上的预测误差，与(8)相同。为简化符号，我们定义一个V维向量EI = {EI₁,···,EI_V}作为所有上下文词预测误差的和：

EI_j = \Sigma_{c=1}^C $e_{c,j}$ (31)

接下来，我们对隐藏\rightarrow输出矩阵W'求E的偏导，得到：

\partialE/\partialw'_{ij} = \Sigma_{c=1}^C (\partialE/\partial$u_{c,j}$)·(\partial$u_{c,j}$/\partialw'_{ij}) = EI_j·h_i (32)

因此我们得到隐藏\rightarrow输出矩阵W'的更新方程：

w'_{ij}(new) = w'_{ij}(old) - \eta·EI_j·h_i (33)

或者：

v'_{w_j}(new) = v'_{w_j}(old) - \eta·EI_j·h, 对于 j = 1,2,···,V (34)

该更新方程的直观理解与(11)相同，不同之处在于预测误差是在输出层的所有上下文词上求和。注意，对于每个训练实例，我们需要对隐藏\rightarrow输出矩阵的每个元素应用此更新方程。

输入\rightarrow隐藏矩阵的更新方程推导与(12)到(16)相同，只是需要将预测误差e_j替换为EI_j。我们直接给出更新方程：

$v_{w_I}$(new) = $v_{w_I}$(old) - \eta·EHᵀ (35)

其中EH是一个N维向量，其每个分量定义为：

EH_i = \Sigma_{j=1}^V EI_j·w'_{ij} (36)

(35)的直观理解与(16)相同。

## 3 优化计算效率

到目前为止，我们讨论的模型（"二元语法"模型、CBOW和跳字模型）都是其原始形式，没有应用任何效率优化技巧。

对于所有这些模型，词汇表中的每个词都存在两种向量表示：输入向量v_w和输出向量v'_w。学习输入向量是廉价的；但学习输出向量非常昂贵。从更新方程(22)和(33)中，我们可以发现，为了更新v'_w，对于每个训练实例，我们必须遍历词汇表中的每个词w_j，计算其网络输入u_j、概率预测y_j（对于跳字模型是$y_{c,j}$）、预测误差e_j（对于跳字模型是EI_j），最后使用其预测误差来更新其输出向量v'_j。

对于每个训练实例对所有词进行这样的计算非常昂贵，使得其难以扩展到大型词汇表或大型训练语料库。为解决这个问题，直观的想法是限制每个训练实例必须更新的输出向量数量。实现这一目标的一种优雅方法是层次化softmax；另一种方法是通过采样，这将在下一节讨论。

这两种技巧都只优化输出向量更新的计算。在我们的推导中，我们关注三个值：(1) E，新的目标函数；(2) \partialE/\partialv'_w，新的输出向量更新方程；(3) \partialE/\partialh，用于反向传播更新输入向量的预测误差加权和。

### 3.1 层次化Softmax

层次化softmax是一种高效计算softmax的方法（Morin and Bengio, 2005; Mnih and Hinton, 2009）。该模型使用一棵二叉树来表示词汇表中的所有词。V个词必须是树的叶子单元。可以证明有V-1个内部单元。对于每个叶子单元，存在一条从根到该单元的唯一路径；该路径用于估计叶子单元所代表词的概率。参见图4中的示例树。

在层次化softmax模型中，词没有输出向量表示。取而代之的是，每个V-1个内部单元都有一个输出向量v'_{n(w,j)}。一个词作为输出词的概率定义为：

p(w = w_O) = $\Pi$_{j=1}^{L(w)-1} \sigma(⟦n(w,j+1) = ch(n(w,j))⟧ · v'_{n(w,j)}ᵀ h) (37)

其中ch(n)是单元n的左子节点；v'_{n(w,j)}是内部单元n(w,j)的向量表示（"输出向量"）；h是隐藏层的输出值（在跳字模型中h = $v_{w_I}$；在CBOW中，h = (1/C)·\Sigma_{c=1}^C $v_{w_c}$）；⟦·⟧是一个特殊函数，定义为：

⟦x⟧ = 1 如果 x 为真，否则 -1 (38)

让我们通过一个示例来直观地理解这个方程。观察图4，假设我们要计算w₂作为输出词的概率。我们将此概率定义为从根开始到目标叶子单元结束的随机游走的概率。在每个内部单元（包括根单元），我们需要分配向左和向右的概率⁴。我们定义在内部单元n处向左走的概率为：

p(n, left) = \sigma(v'_nᵀ·h) (39)

该概率由内部单元的向量表示和隐藏层的输出值（后者由输入词的向量表示决定）共同决定。显然，在单元n处向右走的概率为：

p(n, right) = 1 - \sigma(v'_nᵀ·h) = \sigma(-v'_nᵀ·h) (40)

按照从根到w₂的路径（图4），我们可以计算w₂作为输出词的概率为：

p(w = w₂) = p(n(w₂,1), left)·p(n(w₂,2), left)·p(n(w₂,3), right) (41)
= \sigma(v'_{n(w₂,1)}ᵀ h)·\sigma(v'_{n(w₂,2)}ᵀ h)·\sigma(-v'_{n(w₂,3)}ᵀ h) (42)

这正是(37)所给出的。不难验证 \Sigma_{i=1}^V p(w = w_i) = 1 (43)，这使得层次化softmax在所有词中成为一个定义良好的多项分布。

现在让我们推导内部单元向量表示的参数更新方程。为简单起见，我们首先查看单词语境模型。将更新方程扩展到CBOW和跳字模型是容易的。

为简化符号，我们定义以下缩写（不引入歧义）：

⟦·⟧ := ⟦n(w,j+1) = ch(n(w,j))⟧ (44)
v'_j := v'_{n(w,j)} (45)

对于一个训练实例，误差函数定义为：

E = -log p(w = w_O|w_I) = - \Sigma_{j=1}^{L(w)-1} log \sigma(⟦·⟧·v'_jᵀ h) (46)

我们对v'_jᵀ h求E的偏导，得到：

\partialE/\partial(v'_jᵀ h) = \sigma(⟦·⟧·v'_jᵀ h) - 1·⟦·⟧ (47)
= { \sigma(v'_jᵀ h) - 1 (如果 ⟦·⟧ = 1), \sigma(v'_jᵀ h) (如果 ⟦·⟧ = -1) } (48)
= \sigma(v'_jᵀ h) - t_j (49)

其中如果⟦·⟧ = 1则t_j = 1，否则t_j = 0。

接下来我们对内部单元n(w,j)的向量表示求E的偏导，得到：

\partialE/\partialv'_j = (\partialE/\partial(v'_jᵀ h))·(\partial(v'_jᵀ h)/\partialv'_j) = (\sigma(v'_jᵀ h) - t_j)·h (50)

由此得到以下更新方程：

v'_j(new) = v'_j(old) - \eta·(\sigma(v'_jᵀ h) - t_j)·h (51)

该方程应对j = 1,2,···,L(w)-1应用。我们可以将\sigma(v'_jᵀ h) - t_j理解为内部单元n(w,j)的预测误差。每个内部单元的"任务"是预测在随机游走中应该走左子节点还是右子节点。t_j = 1表示真实情况是走左子节点；t_j = 0表示应该走右子节点。\sigma(v'_jᵀ h)是预测结果。对于一个训练实例，如果内部单元的预测非常接近真实情况，那么它的向量表示v'_j将移动很小；否则v'_j将向适当方向移动（靠近或远离⁵ h），以减少该实例的预测误差。该更新方程可用于CBOW和跳字模型。当用于跳字模型时，我们需要对输出上下文中的每个C个词重复此更新过程。

为了反向传播误差以学习输入\rightarrow隐藏权重，我们对隐藏层的输出求E的偏导，得到：

\partialE/\partialh = \Sigma_{j=1}^{L(w)-1} (\partialE/\partial(v'_jᵀ h))·(\partial(v'_jᵀ h)/\partialh) (52)
= \Sigma_{j=1}^{L(w)-1} (\sigma(v'_jᵀ h) - t_j)·v'_j (53)
:= EH (54)

可以直接将其代入(23)以获得CBOW输入向量的更新方程。对于跳字模型，我们需要为跳字上下文中的每个词计算一个EH值，并将所有EH值的和代入(35)以获得输入向量的更新方程。

从更新方程可以看出，每个训练实例每个上下文词的计算复杂度从O(V)降低到O(log V)，这是一个巨大的速度提升。我们仍然拥有大致相同数量的参数（V-1个内部单元向量，对比原来的V个输出向量）。

### 3.2 负采样

负采样的思想比层次化softmax更直接：为了处理每次迭代需要更新太多输出向量的困难，我们只更新其中的一个样本。

显然，输出词（即真实值，或称正样本）应该保留在我们的样本中并得到更新，同时我们需要采样几个词作为负样本（因此称为"负采样"）。采样过程需要一个概率分布，可以任意选择。我们将这个分布称为噪声分布，记为P_n(w)。可以通过经验确定一个好的分布⁶。

在word2vec中，作者没有采用能产生明确定义的后验多项分布的负采样形式，而是认为以下简化的训练目标能够产生高质量的词嵌入⁷：

E = -log \sigma(v'_{w_O}ᵀ h) - \Sigma_{w_j \in $W_{neg}$} log \sigma(-v'_{w_j}ᵀ h) (55)

其中w_O是输出词（即正样本），v'_{w_O}是其输出向量；h是隐藏层的输出值：在CBOW模型中h = (1/C)·\Sigma_{c=1}^C $v_{w_c}$，在跳字模型中h = $v_{w_I}$；$W_{neg}$ = {w_j | j = 1,···,K}是基于P_n(w)采样的词集，即负样本。

为获得负采样下词向量的更新方程，我们首先对输出单元w_j的网络输入求E的偏导：

\partialE/\partial(v'_{w_j}ᵀ h) = { \sigma(v'_{w_j}ᵀ h) - 1 (如果 w_j = w_O), \sigma(v'_{w_j}ᵀ h) (如果 w_j \in $W_{neg}$) } (56)
= \sigma(v'_{w_j}ᵀ h) - t_j (57)

其中t_j是词w_j的"标签"。当w_j是正样本时t_j = 1，否则t_j = 0。

接下来我们对词w_j的输出向量求E的偏导：

\partialE/\partialv'_{w_j} = (\partialE/\partial(v'_{w_j}ᵀ h))·(\partial(v'_{w_j}ᵀ h)/\partialv'_{w_j}) = (\sigma(v'_{w_j}ᵀ h) - t_j)·h (58)

由此得到其输出向量的以下更新方程：

v'_{w_j}(new) = v'_{w_j}(old) - \eta·(\sigma(v'_{w_j}ᵀ h) - t_j)·h (59)

这只需要对w_j \in {w_O} \cup $W_{neg}$应用，而不是词汇表中的每个词。这说明为什么我们可以在每次迭代中节省大量计算开销。

上述更新方程的直观理解应与(11)相同。该方程可用于CBOW和跳字模型。对于跳字模型，我们每次对一个上下文词应用该方程。

为了将误差反向传播到隐藏层并从而更新词的输入向量，我们需要对隐藏层的输出求E的偏导，得到：

\partialE/\partialh = \Sigma_{w_j \in {w_O}\cup$W_{neg}$} (\partialE/\partial(v'_{w_j}ᵀ h))·(\partial(v'_{w_j}ᵀ h)/\partialh) (60)
= \Sigma_{w_j \in {w_O}\cup$W_{neg}$} (\sigma(v'_{w_j}ᵀ h) - t_j)·v'_{w_j} := EH (61)

将EH代入(23)可以得到CBOW模型输入向量的更新方程。对于跳字模型，我们需要为跳字上下文中的每个词计算一个EH值，并将所有EH值的和代入(35)以获得输入向量的更新方程。

## 附录A 反向传播基础

### A.1 单个单元的学习算法

图5展示了一个人工神经元（单元）。{x₁,···,x_K}是输入值；{w₁,···,w_K}是权重；y是标量输出；f是链接函数（也称为激活/决策/传递函数）。

该单元的工作方式如下：

y = f(u) (62)

其中u是一个标量，是神经元的网络输入（或"净输入"）。u定义为：

u = \Sigma_{i=0}^K w_i x_i (63)

使用向量符号，我们可以写成：

u = wᵀ x (64)

注意这里我们省略了u中的偏置项。要包含偏置项，只需添加一个恒为1的输入维度（例如x₀）。

显然，不同的链接函数会导致神经元的不同行为。我们在此讨论两种链接函数的示例选择。

第一个示例选择f(u)是单位阶跃函数（又称赫维赛德阶跃函数）：

f(u) = 1 如果 u > 0，否则 0 (65)

具有这种链接函数的神经元称为感知机。感知机的学习算法是感知机算法。其更新方程定义为：

w(new) = w(old) - \eta·(y - t)·x (66)

其中t是标签（黄金标准），\eta是学习率（\eta > 0）。注意，感知机是一种线性分类器，意味着其描述能力非常有限。如果我们想要拟合更复杂的函数，需要使用非线性模型。

第二个示例选择f(u)是逻辑函数（最常见的一种sigmoid函数），定义为：

\sigma(u) = 1 / (1 + e^{-u}) (67)

逻辑函数有两个主要优点：(1) 输出y始终在0和1之间；(2) 与单位阶跃函数不同，\sigma(u)是平滑且可微的，使得更新方程的推导非常容易。

注意，\sigma(u)还有以下两个非常方便的性质，将在后续推导中使用：

\sigma(-u) = 1 - \sigma(u) (68)
d\sigma(u)/du = \sigma(u)·\sigma(-u) (69)

我们使用随机梯度下降作为该模型的学习算法。为了推导更新方程，我们需要定义误差函数，即训练目标。以下目标函数似乎很方便：

E = (1/2)·(t - y)² (70)

我们对w_i求E的偏导：

\partialE/\partialw_i = (\partialE/\partialy)·(\partialy/\partialu)·(\partialu/\partialw_i) (71)
= (y - t)·y(1-y)·x_i (72)

其中\partialy/\partialu = y(1-y)，因为y = f(u) = \sigma(u)，以及利用了(68)和(69)。一旦得到导数，我们就可以应用随机梯度下降：

w(new) = w(old) - \eta·(y - t)·y(1-y)·x (73)

### A.2 多层网络的反向传播

图6展示了一个多层神经网络，包含一个输入层{x_k} = {x₁,···,x_K}、一个隐藏层{h_i} = {h₁,···,h_N}和一个输出层{y_j} = {y₁,···,y_M}。为清晰起见，我们分别使用k、i、j作为输入层、隐藏层和输出层单元的下标。我们使用u_i和u'_j分别表示隐藏层单元和输出层单元的网络输入。

我们想要推导输入层和隐藏层之间权重$w_{ki}$以及隐藏层和输出层之间权重w'_{ij}的更新方程。我们假设所有计算单元（即隐藏层和输出层中的单元）都使用逻辑函数\sigma(u)作为链接函数。因此，对于隐藏层中的单元h_i，其输出定义为：

h_i = \sigma(u_i) = \sigma(\Sigma_{k=1}^K $w_{ki}$ x_k) (74)

类似地，对于输出层中的单元y_j，其输出定义为：

y_j = \sigma(u'_j) = \sigma(\Sigma_{i=1}^N w'_{ij} h_i) (75)

我们使用以下平方误差和函数：

E(x,t,W,W') = (1/2)·\Sigma_{j=1}^M (y_j - t_j)² (76)

其中W = {$w_{ki}$}，是一个K$\times$N权重矩阵（输入-隐藏）；W' = {w'_{ij}}，是一个N$\times$M权重矩阵（隐藏-输出）。t = {t₁,···,t_M}，是一个M维向量，是输出的黄金标准标签。

为获得$w_{ki}$和w'_{ij}的更新方程，我们只需分别对误差函数E关于权重求偏导。为使推导直观，我们从最右侧的层（即输出层）开始计算导数，然后向左移动。对于每一层，我们将计算分为三个步骤，分别计算误差对输出、网络输入和权重的导数。下面展示这个过程。

我们从输出层开始。第一步是计算误差对输出的导数：

\partialE/\partialy_j = y_j - t_j (77)

第二步是计算误差对输出层网络输入的导数。注意，当对某个量求导时，我们需要保持其他所有量不变。同时注意，这个值非常重要，因为它将在后续计算中被多次重用。为简便起见，我们将其记为EI'_j：

\partialE/\partialu'_j = (\partialE/\partialy_j)·(\partialy_j/\partialu'_j) = (y_j - t_j)·y_j(1-y_j) := EI'_j (78)

第三步是计算误差对隐藏层和输出层之间权重的导数：

\partialE/\partialw'_{ij} = (\partialE/\partialu'_j)·(\partialu'_j/\partialw'_{ij}) = EI'_j·h_i (79)

到目前为止，我们已经得到隐藏层和输出层之间权重的更新方程：

w'_{ij}(new) = w'_{ij}(old) - \eta·(\partialE/\partialw'_{ij}) (80)
= w'_{ij}(old) - \eta·EI'_j·h_i (81)

其中\eta > 0是学习率。

我们可以重复同样的三个步骤来获得前一层权重的更新方程，这本质上就是反向传播的思想。

我们重复第一步，计算误差对隐藏层输出的导数。注意，隐藏层的输出与输出层中的所有单元都有关：

\partialE/\partialh_i = \Sigma_{j=1}^M (\partialE/\partialu'_j)·(\partialu'_j/\partialh_i) = \Sigma_{j=1}^M EI'_j·w'_{ij} (82)

然后我们重复上面的第二步，计算误差对隐藏层网络输入的导数。这个值也非常重要，我们将其记为EI_i：

\partialE/\partialu_i = (\partialE/\partialh_i)·(\partialh_i/\partialu_i) = \Sigma_{j=1}^M EI'_j·w'_{ij}·h_i(1-h_i) := EI_i (83)

接下来我们重复上面的第三步，计算误差对输入层和隐藏层之间权重的导数：

\partialE/\partial$w_{ki}$ = (\partialE/\partialu_i)·(\partialu_i/\partial$w_{ki}$) = EI_i·x_k (84)

最后，我们可以得到输入层和隐藏层之间权重的更新方程：

$w_{ki}$(new) = $w_{ki}$(old) - \eta·EI_i·x_k (85)

从上述例子中我们可以看到，计算某一层导数时的中间结果（EI'_j）可以被前一层重用。想象一下如果在输入层之前还有另一层，那么EI_i也可以被重用，以继续高效地计算导数链。比较方程(78)和(83)，我们可以发现在(83)中，因子\Sigma_{j=1}^M EI'_j·w'_{ij}就像是隐藏层单元h_i的"误差"。我们可以将这一项解释为从下一层"反向传播"的误差，如果网络有更多隐藏层，这种传播可以进一步向后进行。

## 附录B wevi：词嵌入可视化检查器

一个交互式可视化界面wevi（词嵌入可视化检查器）可在线上使用，以演示本文所述模型的工作机制。参见图7中的wevi截图。

该演示允许用户直观地检查每个训练实例被消费时输入向量和输出向量的运动。训练过程也可以批量模式运行（例如，连续消费500个训练实例），这可以揭示权重矩阵和相应词向量中模式的出现。采用主成分分析（PCA）将"高"维向量可视化在二维散点图中。该演示支持CBOW和跳字模型。

训练完模型后，用户可以手动激活一个或多个输入层单元，并检查哪些隐藏层单元和输出层单元变得活跃。用户还可以自定义训练数据、隐藏层大小和学习率。提供了几个预设的训练数据集，可以生成看起来有趣的不同结果，例如使用玩具词汇表重现著名的词类比：king - queen = man - woman。

希望通过与此演示的交互，用户可以快速深入了解模型的工作机制。该系统可在http://bit.ly/wevi-online 获取。源代码可在http://github.com/ronxin/wevi 获取。
