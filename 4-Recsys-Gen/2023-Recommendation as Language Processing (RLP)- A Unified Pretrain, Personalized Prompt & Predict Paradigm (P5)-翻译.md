## 摘要

长期以来，不同的推荐任务通常需要设计任务特定的架构和训练目标。因此，将学到的知识和表示从一个任务迁移到另一个任务是很困难的，从而限制了现有推荐方法的泛化能力（例如，序列推荐模型很难应用于或迁移到评论生成方法）。为解决这些问题，考虑到语言几乎可以描述任何事物，并且语言 grounding（语言锚定）是表示各种问题或任务的强大媒介，我们提出了一种灵活且统一的文本到文本范式，称为 **"预训练、个性化提示和预测范式"（P5）** 用于推荐。P5 将所有推荐任务统一在一个共享框架中。在 P5 中，所有数据如用户-item交互、用户描述、item元数据和用户评论都被转换为通用格式——自然语言序列。来自自然语言的丰富信息帮助 P5 捕获更深的语义以进行个性化和推荐。具体来说，P5 在预训练期间使用相同的语言建模目标学习不同的任务。因此，它作为各种下游推荐任务的基础模型，允许轻松整合其他模态，并支持基于提示的指令推荐。P5 将推荐系统从浅层模型推进到深层模型再到大型模型，并将革新推荐系统的技术形式，向着通用推荐引擎的方向发展。通过自适应个性化提示，P5 能够以零样本或少样本方式进行预测，大大减少了对大量微调的需求。在多个推荐基准上，我们进行了实验以展示 P5 的有效性。为帮助推进关于推荐即语言处理（RLP）、个性化基础模型（PFM）和通用推荐引擎（URE）的未来研究，我们发布了源代码、数据集、提示和预训练的 P5 模型。

**关键词：** 推荐系统；自然语言处理；多任务学习；个性化提示；语言建模；统一模型

## 1 引言

在过去的几十年中，推荐系统取得了显著进展，在人们的日常生活中发挥着重要作用，帮助人们做出微观决策并以出色的精度满足他们的需求。回顾过去，我们可以总结现代推荐系统的发展趋势——朝着一个更全面的系统发展，以适应多样化的特征和广泛的应用场景。

一方面，推荐系统中的特征工程和学习已从简单演变为复杂。在早期，推荐系统通常采用逻辑回归或协同过滤 [25, 35, 50, 52]，利用用户-item交互记录来建模用户的行为模式。后来，通过更复杂的模型如因子分解机 [48] 和 GBDT [20]，用户画像和item元数据等上下文特征被进一步整合到系统中。最近，深度神经网络模型 [3, 5, 19, 74] 促进了更多样化和复杂特征的交叉和组合。因此，这些模型相比基于传统特征工程的方法获得了更好的表示能力。

另一方面，更多的推荐任务已经涌现。除了经典的评分预测和基于直接用户-item匹配的推荐任务外，最近的工作正在将范围扩展到新的任务和场景，如序列推荐 [21, 60, 63, 80]、对话推荐 [8, 61, 76]、可解释推荐 [17, 31, 62, 70, 75, 77] 等。虽然针对上述推荐任务的方法通常是分别提出的，但存在一个明显的趋势，即利用多个推荐任务来联合学习可迁移的表示 [31, 56, 57, 72]。

尽管现有的推荐系统取得了巨大成功，但当前解决方案与上述趋势的可预见交汇点——一个能够适应多样化特征和不同类型任务的全面推荐系统——之间仍然存在相当大的差距。由于推荐任务通常共享共同的用户-item池并具有重叠的上下文特征，我们相信将更多推荐任务合并到一个统一框架中是有前景的，这样它们可以隐式地传递知识以相互受益，并实现对其他未见任务的泛化。

受多任务基于提示的训练的最新进展 [1, 51, 67] 启发，在这项工作中，我们提出了统一的 **"预训练、个性化提示和预测范式"（简称 P5）**。我们展示了 P5 可以在一个统一的序列到序列框架中学习多个推荐相关任务，通过将这些问题形式化为基于提示的自然语言任务，其中用户-item信息和相应的特征通过个性化提示模板作为模型输入集成在一起。P5 为推荐系统社区照亮了实现通用推荐引擎的道路，其中所有场景和任务可以通过共享的语言模型覆盖。P5 将推荐系统从浅层模型推进到深层模型再到大型模型。

## 2 P5 范式

### 2.1 推荐的文本到文本框架

"推荐即语言处理"（RLP）范式将所有推荐相关数据转换为自然语言格式。在 P5 中，我们有信心推荐系统中的几乎所有信息都可以用自然语言表达。因此，用户-item交互、用户特征、item特征和任务指令都可以编码为文本序列。

P5 的输入格式基于预定义的提示模板。例如，序列推荐的提示模板为："I find the purchase history list of use $r_{\text{userID}}$ : {item序列} I wonder what is the next item to recommend to the user. Can you help me decide?"。输出为下一个item的 ID。

### 2.2 预训练

P5 使用标准语言建模目标进行预训练。在预训练阶段，模型在多个推荐任务的混合数据上进行训练，学习理解各种推荐任务的语义并捕获用户-item交互的通用模式。训练数据包括序列推荐、评分预测、评论生成、可解释推荐和直接推荐等多种任务的样本。

### 2.3 个性化提示

P5 的一个关键创新是**个性化提示**。与 NLP 中使用固定提示不同，P5 的提示是用户特定的，包含用户的唯一标识符和个性化上下文。这使得模型能够为不同用户自适应地调整行为，实现个性化推荐。

P5 支持三种类型的提示模板：
1. **序列推荐**：基于用户历史交互序列预测下一个交互
2. **评分预测**：预测用户对某item的评分（1-5 星）
3. **评论生成/摘要**：生成关于item的自然语言评论或摘要
4. **可解释推荐**：为推荐结果生成自然语言解释
5. **直接推荐**：基于特征直接推荐item

### 2.4 多任务学习

P5 在一个共享的 T5 Transformer 架构中统一了多种推荐任务。所有任务使用相同的语言建模目标进行预训练和微调。通过多任务学习，P5 能够在任务之间迁移知识，改善数据稀疏任务的性能。

支持的任务列表：
- 序列推荐（Sequence Recommendation）
- 评分预测（Rating Prediction）
- 评论生成（Review Generation）
- 评论摘要（Review Summarization）
- 可解释推荐（Explainable Recommendation）
- 直接推荐（Straightforward Recommendation）
- 对话推荐（Conversational Recommendation）

## 3 实验

### 3.1 设置

**数据集**：我们使用 MovieLens-1M、Amazon Beauty、Amazon Sports、Amazon Toys 和 Yelp 等数据集。

**基线**：我们将 P5 与传统推荐方法（BPR-MF、FM、NCF）和序列推荐方法（GRU4Rec、Caser、SASRec、BERT4Rec）以及基于 LM 的方法进行比较。

**评估指标**：对于序列推荐，使用 Recall@N 和 NDCG@N；对于评分预测，使用 RMSE。

**实现细节**：P5 基于 T5-base 架构（约 2.2 亿参数）。在 8 个 GPU 上训练，批大小为 64，学习率为 5e-5。

### 3.2 主要结果

**序列推荐**：P5 在 Amazon Beauty 和 Sports 上达到了与 SASRec 和 BERT4Rec 相当的性能。在冷启动场景中，P5 的零样本能力显著优于基线。

**评分预测**：P5 在 MovieLens-1M 上的 RMSE 为 0.856，与 NCF（0.852）相当。

**评论生成**：P5 在 BLEU 和 ROUGE 指标上匹配或超过了专门的评论生成方法。

**多任务迁移**：P5 展示了从评分预测到序列推荐任务的正向迁移——在评分预测上预训练后微调序列推荐，比从头训练性能更好。

## 4 相关工作

### 4.1 推荐系统

传统的推荐方法包括协同过滤 [25, 52]、矩阵分解 [50]、因子分解机 [48] 和神经协同过滤 [19]。序列推荐方法如 GRU4Rec [21]、SASRec [31]、BERT4Rec [63] 捕获用户行为的顺序模式。

### 4.2 用于推荐的自然语言处理

以前的工作使用 NLP 进行推荐，包括基于评论的推荐 [33, 82]、可解释推荐 [31, 75] 和对话推荐 [8, 61]。然而，这些方法使用任务特定的架构，不能在一个统一框架中处理多个任务。

### 4.3 多任务提示学习

NLP 中的提示学习 [11, 37, 67] 和多任务学习 [1, 51] 通过统一模板处理多个任务。P5 将这些思想引入推荐系统。

### 4.4 语言模型用于推荐

近期工作如 GPT-Rec [40] 和 RecLLM [68] 使用冻结的 LLM 进行推荐，但它们需要外部 API 或不能完全微调。P5 是第一个对 LLM 进行完全微调以适应多个推荐任务的统一框架。

---

## 5 结论与未来工作

P5 提出了一个统一的文本到文本范式"推荐即语言处理"（RLP），将各种推荐任务整合到一个共享的语言模型框架中。通过语言作为统一表示和个性化提示，P5 能够跨任务学习可迁移的知识，并以零样本或少样本方式适应新任务。P5 将推荐系统从浅层模型推进到深层模型再到大型模型。

未来工作包括：
- 将 P5 扩展到更多推荐任务和场景
- 探索更大规模的骨干模型
- 整合多模态信息
- 优化提示设计以改善性能
