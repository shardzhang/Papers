## FQA

#### Q：第 3 节在干什么？

第 3 节是 GloVe 论文的核心推导章节。我帮你把整条逻辑线拆开讲清楚（包括你标注"看不懂了"的 3.1 节）。

一句话：**从"共现统计"出发，用数学推导出词向量应该满足什么方程，然后把它变成一个可训练的优化目标。**

---

第 1 步：从概率出发，但真正要建模的是"比值"

**记号**（很简单，先记住这三个）：
- $X_{ij}$：词 $j$ 出现在词 $i$ 上下文中的**次数**
- $X_i$：任意词出现在词 $i$ 上下文中的总次数
- $P_{ij}$：词 $j$ 出现在词 $i$ 上下文中的**概率** $= X_{ij}/X_i$

**ice/steam 例子**（这是全章最重要的直觉）：
- 想表达 ice 和 steam 的区别（固相 vs 气相）
- 用概率 $P(k|ice)$ 本身不好使——water 和 fashion 这些无关词的干扰很大
- 用**比值** $P(k|ice)/P(k|steam)$ 就好使了：
  - solid（与冰相关）：**8.9**（很大）
  - gas（与蒸汽相关）：**0.085**（很小）
  - water / fashion（都相关或都无关）：≈1（噪声被抵消了）

**结论**：词向量应该编码**概率比值**，而不是概率本身。这就是全章推导的起点。

---



第 2 步：从一般到具体，一步步"逼"出唯一解

起点：$F(w_i, w_j, \tilde{w}_k) = \frac{P_{ik}}{P_{jk}}$ (式1) —— 函数 $F$ 可以是任何东西，但目标就是让词向量能还原比值。

接着施加 4 个约束，每步都在缩小 $F$ 的范围：

| 步骤 | 施加的约束 | 直觉 |
|---|---|---|
| 式(2) | $F$ 只依赖**向量差** $w_i - w_j$ | 向量空间是线性的，"关系的方向"用差表示（像 king−queen ≈ man−woman） |
| 式(3) | 先取**点积** $(w_i - w_j)^T \tilde{w}_k$ | 左边是向量、右边是标量，点积把两个向量压成一个数，还防止维度被胡乱混合 |
| 式(4) | $F$ 是**同态**：$F(a-b) = F(a)/F(b)$ | 要求"交换对称性"——词和上下文词角色互换后模型不变，减法对应到除法 |
| 式(5)(6) | 解出 $F = \exp$ | 唯一的解：$w_i^T \tilde{w}_k = \log P_{ik} = \log X_{ik} - \log X_i$ |

**为什么必须有式(4)（同态）这一步？**
因为"词 i 的上下文词"和"作为上下文词的词 i"在共现矩阵里是对称的（交换 $w↔\tilde{w}$ 的同时 $X↔X^T$，模型必须不变）。式(3) 不满足这个对称性，加上同态约束后就满足了。

**式(7)（关键收尾）**：$\log X_{ik} - \log X_i$ 里的 $\log X_i$ 与 $k$ 无关，就把它吸收成词 $i$ 的偏置 $b_i$；再给上下文词加个偏置 $\tilde{b}_k$ 恢复对称：

$$w_i^T \tilde{w}_k + b_i + \tilde{b}_k = \log X_{ik} \qquad (7)$$

**到这里，推导完成了**：词向量的内积 + 两个偏置 = 共现计数的对数。就这么简单。

---



第 3 步：式(7) 有两个毛病 → 加权最小二乘（式 8）

直接拿式(7) 做分解有两个问题：
1. $X_{ij} = 0$ 时 $\log$ 发散（共现矩阵 75-95% 是 0）
2. 所有共现一视同仁，稀有共现是噪声 却和 频繁共现权重相同

解法：**把式(7) 变成最小二乘回归问题，并加权重 $f(X_{ij})$**：

$$J = \sum_{i,j} f(X_{ij}) \left( w_i^T \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij} \right)^2 \qquad (8)$$

直觉：对每个共现对 $(i,j)$，希望"模型预测的 $\log$ 值"尽量接近"真实的 $\log X_{ij}$"，但给不同共现对不同的重视程度。加权函数 $f$ 的三个性质：$f(0)=0$（零共现直接忽略）、非递减（稀有不过度加权）、大值时要小（频繁不过度加权）。具体形式：$f(x) = (x/x_{max})^\alpha$，截断 $x_{max}=100$，$\alpha=3/4$。

---



第 4 步：3.1 节——为什么 GloVe 和 skip-gram 殊途同归（你卡住的地方）

这节想证明：**GloVe 和 skip-gram 看似不同，本质是同一个东西**。

**推导链**：

1. skip-gram 用 softmax 定义 $Q_{ij}$（词 j 在词 i 上下文中的概率模型），训练时最大化 log 概率（式 10-11）。
2. 把"逐个上下文窗口扫描"重写成"按词对聚合"（式 12）——因为同样的 $(i,j)$ 对会出现 $X_{ij}$ 次，所以：

$$J = -\sum_i \sum_j X_{ij} \log Q_{ij} = \sum_i X_i H(P_i, Q_i) \qquad (13)$$

这就是**交叉熵**形式：$H(P_i, Q_i)$ 是真实分布 $P_i$ 和模型分布 $Q_i$ 的交叉熵，按 $X_i$ 加权。

**关键对比在这里**：

| | 交叉熵目标（式 13，skip-gram 本质） | 最小二乘目标（式 8，GloVe） |
|---|---|---|
| 度量 | 交叉熵 | 平方误差 |
| 问题 1 | 长尾分布对不常发生的事件过度加权 | 无 |
| 问题 2 | 要求模型分布 $Q$ **归一化**（softmax 分母遍历全词表，计算昂贵） | 无归一化需求 |

3. 所以把交叉熵**换成最小二乘**（式 14），并丢掉归一化因子：
   - 直接对 $\hat{P}_{ij} = X_{ij}$ 和 $\hat{Q}_{ij} = \exp(w_i^T \tilde{w}_j)$ 做平方误差
   - 但 $X_{ij}$ 数值太大（可能上亿），不好优化 → 改对**对数**做平方误差（式 15）：
     $$J = \sum_{i,j} X_i \left( w_i^T \tilde{w}_j - \log X_{ij} \right)^2$$
   - 再把固定的权重 $X_i$ 换成**可调的一般加权函数** $f(X_{ij})$（式 16）——这**就是**式 (8)！

**结论**：skip-gram 的交叉熵目标 → 去掉归一化 → 取对数 → 换成自由加权函数 = GloVe 的加权最小二乘。**两个模型家族在数学上是同一件事**，只是度量方式和加权方式不同。

---

第 5 步：3.2 节——为什么训练很快

- 式(8) 的复杂度取决于 $X$ 的**非零元素数**，不是 $V^2$（全词表平方）
- 假设共现服从幂律 $X_{ij} = k/r^\alpha$，可推出 $|X| = O(|C|^{1/\alpha})$，实测 $\alpha=1.25$ → $|X| = O(|C|^{0.8})$
- 比窗口方法的 $O(|C|)$ 还快

---



一句话总结全章

> 词义藏在**共现概率的比值**里 → 用 4 个对称性/线性约束把比值"翻译"成词向量方程 $w_i^T \tilde{w}_k + b_i + \tilde{b}_k = \log X_{ik}$ → 为处理零计数和噪声，转成**加权最小二乘** → 证明这个目标和 skip-gram 殊途同归 → 复杂度只依赖非零共现，所以快。

#### Q：展开细讲：式(4) 的"同态"到底在干什么

背景：为什么要提"对称性"？

在共现矩阵 $X$ 里，"词"和"上下文词"来自**同一个词汇表**。词 i 可以是词 j 的上下文词，同时词 j 也可以是词 i 的上下文词——角色完全对称。

比如："apple" 出现在 "juice" 的上下文里，同时 "juice" 也出现在 "apple" 的上下文里。模型不应该对"谁是目标词、谁是上下文词"敏感。

论文要求的对称性是：**交换角色（$w \leftrightarrow \tilde{w}$，同时 $X \leftrightarrow X^T$）后，模型形式必须不变**。



式(3) 为什么不满足对称性

式(3) 是 $F\left((w_i - w_j)^{\mathrm{T}} \tilde{w}_k\right) = \frac{P_{ik}}{P_{jk}}$

交换角色后变成：

$F\left((\tilde{w}_i - \tilde{w}_j)^{\mathrm{T}} w_k\right) = \frac{P'_{ik}}{P'_{jk}}$

其中 $P'$ 是基于 $X^T$ 的概率。因为 $X_{ik} = X_{ki}$（共现计数天然对称），但 $X_i = \sum_k X_{ik} \neq \sum_k X_{ki} = X'_i$（**归一化分母不对称**！），所以 $P'_{ik} \neq P_{ik}$。式(3) 在角色交换下**变了形**。

> 这就是为什么后面式(6) 里 $\log X_i$ 是"捣乱项"：$w_i^{\mathrm{T}} \tilde{w}_k = \log X_{ik} - \log X_i$，交换角色后变成 $\log X_{ki} - \log X_k$，两个 $\log X_i$ 和 $\log X_k$ 不相等，所以不对称。解法就是论文说的：把它吸收成偏置 $b_i$，再加 $\tilde{b}_k$ 配平。



#### Q：展开细讲："同态"是什么意思（初等代数版）

同态（homomorphism）= 保持运算结构的映射。

GloVe 里具体指：函数 $F$ 把**实数加法**映射到**正实数乘法**，且保持运算关系——

如果 $F(a - b) = \frac{F(a)}{F(b)}$ 对任意 $a, b$ 成立，就说 $F$ 是加法群 $(\mathbb{R}, +)$ 到乘法群 $(\mathbb{R}_{>0}, \times)$ 的同态。

它和更常见的 $F(x + y) = F(x) \cdot F(y)$ 是**同一件事**（令 $y = -b$ 即可互推）。

**直觉**：加法和减法是"线性世界"的运算，乘法和除法是"比值世界"的运算。同态要求 $F$ 把"向量的加减"翻译成"比值的乘除"。因为比值 $P_{ik}/P_{jk}$ 天然是除法形式，向量空间里天然是减法形式，$F$ 是连接这两个世界的翻译官。



为什么同态约束能"恢复"对称性

回到式(3)，如果 $F$ 是同态：

$$F\left((w_i - w_j)^{\mathrm{T}} \tilde{w}_k\right) \xlongequal{\text{同态性质}} \frac{F(w_i^{\mathrm{T}} \tilde{w}_k)}{F(w_j^{\mathrm{T}} \tilde{w}_k)} \qquad \text{（这就是式 4 的右边）}$$

原来 $F$ 的输入是**两个向量的差**（对角色交换敏感），现在被拆成**两个单参数项之比**（每个只依赖一个词向量和一个上下文词向量）。交换角色时，$w_i^{\mathrm{T}} \tilde{w}_k$ 变成 $w_k^{\mathrm{T}} \tilde{w}_i$，由于内积的对称性 $w_i^{\mathrm{T}} \tilde{w}_k = w_k^{\mathrm{T}} \tilde{w}_i$，**形式自动不变**——对称性就恢复了。



同态 + 式(3) 如何推出 $F = \exp$

把式(3) 代入同态形式：

$$\frac{F(w_i^{\mathrm{T}} \tilde{w}_k)}{F(w_j^{\mathrm{T}} \tilde{w}_k)} = \frac{P_{ik}}{P_{jk}}$$

交叉相乘后：

$$\frac{F(w_i^{\mathrm{T}} \tilde{w}_k)}{P_{ik}} = \frac{F(w_j^{\mathrm{T}} \tilde{w}_k)}{P_{jk}}$$

等式对**任意** $i, j$ 成立，而右边只依赖 $j, k$。这说明 $\frac{F(w_i^{\mathrm{T}} \tilde{w}_k)}{P_{ik}}$ 与 $i$ 无关——它只可能是某个依赖 $k$ 的常数 $c_k$：

$$F(w_i^{\mathrm{T}} \tilde{w}_k) = c_k P_{ik} \qquad \text{（式 5 再吸收掉常数} \ c_k \text{）}$$

即式(5)：$F(w_i^{\mathrm{T}} \tilde{w}_k) = P_{ik}$。

现在解函数方程。由同态 $F(a - b) = F(a)/F(b)$ 知 $F$ 满足：

$$F(x + y) = F(x) F(y)$$

这是经典柯西型函数方程。加上 $F$ 是连续的（神经网络的激活函数天然连续）这一温和条件，**唯一解是指数函数**：

$$F(x) = e^{cx}$$

（证明思路：先证对整数 $F(n) = F(1)^n$，再推广到有理数、实数，连续性保证取极限成立。）取 $c = 1$ 并吸收常数，$F = \exp$。代入式(5)：

$$\exp(w_i^{\mathrm{T}} \tilde{w}_k) = P_{ik} \quad\Longrightarrow\quad w_i^{\mathrm{T}} \tilde{w}_k = \log P_{ik} = \log X_{ik} - \log X_i \qquad \text{（式 6）}$$

**至此推导闭合**：两个约束（点积结构 + 同态）就把"任意函数 $F$"逼成了唯一的"内积 = 对数概率"。



#### Q：展开细讲：3.1 节——skip-gram 如何一步步变成 GloVe

起点：skip-gram 的 softmax 模型

skip-gram 假设词 $j$ 出现在词 $i$ 上下文中的概率是 softmax：

$$Q_{ij} = \frac{\exp(w_i^{\mathrm{T}} \tilde{w}_j)}{\sum_{k=1}^{V} \exp(w_i^{\mathrm{T}} \tilde{w}_k)} \qquad (10)$$

（$w_i$ 是目标词向量，$\tilde{w}_j$ 是上下文词向量，分母是对全词表的归一化。）

训练目标：扫描语料库时最大化 log 概率，即最小化负对数似然：

$$J = -\sum_{i \in \text{corpus}} \sum_{j \in \text{context}(i)} \log Q_{ij} \qquad (11)$$

注意这里是对**每个词 + 它的每个上下文词**单独累加——同一个 $(i,j)$ 对会在语料库中反复出现。



关键一步：按词对聚合

$X_{ij}$ 恰好就是"词 $i$ 和词 $j$ 共现的次数"。式(11) 里 $(i,j)$ 对出现 $X_{ij}$ 次，所以可以合并同类项：

$$J = -\sum_{i=1}^{V} \sum_{j=1}^{V} X_{ij} \log Q_{ij} \qquad (12)$$

这一步的妙处：**从"扫描上下文窗口"变成了"读共现矩阵"**——和 GloVe 的出发点完全一致了。

再利用 $X_{ij} = X_i \cdot P_{ij}$（$X_i$ 是行和，$P_{ij}$ 是条件概率）：

$$J = -\sum_{i=1}^{V} X_i \sum_{j=1}^{V} P_{ij} \log Q_{ij} = \sum_{i=1}^{V} X_i H(P_i, Q_i) \qquad (13)$$

其中 $H(P_i, Q_i) = -\sum_j P_{ij} \log Q_{ij}$ 就是**交叉熵**（真实分布 $P_i$ 和模型分布 $Q_i$ 之间）。$X_i$ 是权重——行出现总次数越多的词，它的分布拟合越重要。

> **这里的"交叉熵"具体是啥？** 概率论里两个分布 $P$、$Q$ 的交叉熵 = $-\sum P(x) \log Q(x)$。它衡量"用 $Q$ 编码来自 $P$ 的样本需要多少 bit"。$P = Q$ 时最小。这里每个词 i 有一个真实条件分布 $P_i$（从语料统计而来）和一个模型分布 $Q_i$（softmax 预测），把每个词的交叉熵按 $X_i$ 加权求和，就是整体目标。



交叉熵的两个毛病 → 换掉

**毛病 1：长尾分布建模差。** 交叉熵给"不太可能的事件"（稀有词对）过多权重，而真实语言分布是重尾的（绝大多数词对出现次数极少）。论文说交叉熵对长尾 "modeled poorly with too much weight given to the unlikely events"。

**毛病 2：要求归一化。** $H(P_i, Q_i)$ 要有界，$Q_i$ 必须是合法概率分布——softmax 分母 $\sum_{k=1}^V \exp(w_i^{\mathrm{T}} \tilde{w}_k)$ 每步都要对**全词表**求和，$O(V)$ 开销，词汇量几十万时完全不可行。

所以换一个**不需要归一化的距离度量**——最小二乘（式 14）：

$$\hat{J} = \sum_{i,j} X_i \left( \hat{P}_{ij} - \hat{Q}_{ij} \right)^2 \qquad (14)$$

其中 $\hat{P}_{ij} = X_{ij}$、$\hat{Q}_{ij} = \exp(w_i^{\mathrm{T}} \tilde{w}_j)$ 是**去掉归一化分母**的"未归一化分布"。

**为什么敢丢分母？** 优化目标是"让模型输出接近真实值"。softmax 的分母只是把所有分数拉成概率的缩放常数；丢掉后，$\exp(w_i^{\mathrm{T}} \tilde{w}_j)$ 本身仍然编码了词对的关联强度，**而且**省掉了每步 $O(V)$ 的归一化。$\hat{P}_{ij} = X_{ij}$ 同理（概率 $P_{ij}$ 去掉行归一化就是计数）。



再修一个毛病：$X_{ij}$ 数值范围太恐怖

$X_{ij}$ 从 1（罕见共现）到数亿（"the" 和 "and"）跨 8-9 个数量级。直接平方误差会被大数完全主导。对策：**对 log 做平方误差**（式 15）：

$$\hat{J} = \sum_{i,j} X_i \left( \log \hat{P}_{ij} - \log \hat{Q}_{ij} \right)^2 = \sum_{i,j} X_i \left( w_i^{\mathrm{T}} \tilde{w}_j - \log X_{ij} \right)^2 \qquad (15)$$

$\log$ 把数量级差异压缩成可比的尺度。注意这里 $\log \hat{Q}_{ij} = w_i^{\mathrm{T}} \tilde{w}_j$ 非常干净——**丢掉归一化和 log 之后，模型预测值恰好就是内积**。



最后一步：固定权重换成自由加权函数

式(15) 里的权重 $X_i$ 是**在线训练方法（skip-gram 的实现细节）预先决定的**，并没有理由认为它最优。事实上 Mikolov 等人观察到：**子采样频繁词**（降低高频词的有效权重）能提升性能——这正说明固定权重可以改进。

所以把 $X_i$ 换成一般的加权函数 $f(X_{ij})$（式 16）：

$$\hat{J} = \sum_{i,j} f(X_{ij}) \left( w_i^{\mathrm{T}} \tilde{w}_j - \log X_{ij} \right)^2 \qquad (16)$$

**这就是式(8)！**（脚注说明还可加偏置项。）



推导全景图

```
skip-gram/ivLBL 的 softmax 目标（式 10-11）
        │ 按词对聚合（同类项合并 X_ij 次）
        ▼
交叉熵目标 J = Σ X_i H(P_i, Q_i)（式 12-13）
        │ 毛病①长尾 ②需归一化
        ▼
最小二乘（未归一化分布）（式 14）
        │ X_ij 数值范围爆炸
        ▼
对 log 做平方误差（式 15）
        │ X_i 非最优 → 换成自由加权函数
        ▼
GloVe 的加权最小二乘（式 16 = 式 8）
```

**一句话结论**：3.1 节证明 skip-gram 的交叉熵目标，经过"聚合 → 去归一化 → 取对数 → 自由加权"四步改造，恰好落回 GloVe 的加权最小二乘。所以 GloVe 论文标题那句"结合两大模型家族优势"不是口号——**它和 skip-gram 在数学上本就是同一条推导链的两端**，GloVe 只是顺手修掉了交叉熵路径上的三个工程毛病。

#### Q：主题一：式(13) 的 $H(P_i, Q_i)$ 与 KL 散度的区别

## 先看三个容易混淆的量

对词 $i$ 的真实条件分布 $P_i$ 和模型分布 $Q_i$（都是 $V$ 维概率向量）：

**1. 交叉熵（论文用的 $H(P_i, Q_i)$）：**

$$H(P_i, Q_i) = -\sum_{j=1}^{V} P_{ij} \log Q_{ij}$$

**2. KL 散度（也叫相对熵）：**

$$D_{KL}(P_i \| Q_i) = \sum_{j=1}^{V} P_{ij} \log \frac{P_{ij}}{Q_{ij}} = \sum_j P_{ij} \log P_{ij} - \sum_j P_{ij} \log Q_{ij}$$

**3. 熵（真实分布自身的熵，与 $Q_i$ 无关）：**

$$H(P_i) = -\sum_{j=1}^{V} P_{ij} \log P_{ij}$$

## 三者关系：差一个与 $Q$ 无关的常数

$$D_{KL}(P_i \| Q_i) = \underbrace{-H(P_i)}_{\text{只依赖 } P_i，\text{与 } Q_i \text{ 无关}} + \underbrace{H(P_i, Q_i)}_{\text{依赖 } P_i \text{ 和 } Q_i}$$

把 $-H(P_i)$ 展开就是上面那个式子：$D_{KL} = \sum P_{ij}\log P_{ij} - \sum P_{ij}\log Q_{ij}$。

## 为什么论文可以用交叉熵代替 KL？

因为**优化目标里，$-H(P_i)$ 项不包含任何可学习的参数**（$P_i$ 完全由语料库统计决定，模型动不了它）。

$$J = \sum_i X_i H(P_i, Q_i) = \sum_i X_i \big[ D_{KL}(P_i \| Q_i) + H(P_i) \big] = \underbrace{\sum_i X_i D_{KL}(P_i \| Q_i)}_{\text{可变部分}} + \underbrace{\sum_i X_i H(P_i)}_{\text{常数}}$$

最小化 $J$ 和最小化加权 KL 散度，**得到完全相同的解**。常数项只是整体平移。

**通俗解释**：
- KL 散度 = "用 $Q$ 编码 $P$ 的样本所需 bit 数" − "用 $P$ 自己编码所需 bit 数"（即 $Q$ 相对 $P$ 的额外代价）
- 交叉熵 = "用 $Q$ 编码 $P$ 的样本所需 bit 总数"
- 两者之差是 $P$ 自身编码的 bit 数——它是"天地初开就定好的底价"，模型无法改变，所以优化时不在乎

**论文措辞的小心机**：论文脚注说"我们类比 $X_i$ 来定义" $H(P_i, Q_i)$——即它把交叉熵当作"加权的误差项"，没有纠结 KL 和交叉熵的区别，因为数学上等价。**两者在优化意义上没有区别**，区别只在绝对数值上（交叉熵多了一个不可优化的常数）。

## 注意：这里交叉熵的"归一化"毛病

回顾主题二讲的毛病②：交叉熵 $H(P_i,Q_i) = -\sum_j P_{ij}\log Q_{ij}$ 里，$\log Q_{ij}$ 中 $Q_{ij}$ 必须归一化（合法概率），否则对数里的值会失去意义、目标无下界。这正是论文说"为了使度量有界，它要求模型分布 $Q$ 被正确归一化"的原因——softmax 分母的 $O(V)$ 计算就是从这里来的。这也是为什么要换最小二乘。

# 主题二：式(6) → 式(7) 偏置吸收的具体代数操作

## 出发状态：式(6)

$$w_i^{\mathrm{T}} \tilde{w}_k = \log(P_{ik}) = \log(X_{ik}) - \log(X_i) \qquad (6)$$

即 $\log P_{ik} = \log(X_{ik}/X_i) = \log X_{ik} - \log X_i$（对数把除法变成减法，把 $X_{ik}/X_i$ 拆成两项之差）。

## 为什么 $\log X_i$ 是"捣乱项"——具体看交换对称性

**目标**：模型在 $w \leftrightarrow \tilde{w}$、$X \leftrightarrow X^T$ 下不变。

现在把式(6) 两端同时交换角色（目标词 $i$ 和上下文词 $k$ 互换）：

- 左边：$w_i^{\mathrm{T}} \tilde{w}_k \longrightarrow \tilde{w}_i^{\mathrm{T}} w_k = w_k^{\mathrm{T}} \tilde{w}_i$（内积对称）
- 右边第一项：$\log X_{ik} \longrightarrow \log X_{ki}$

而 $X_{ik} = X_{ki}$（**共现计数天然对称**——词 i 在词 k 上下文中的次数，和词 k 在词 i 上下文中的次数，统计的是同一种"相邻出现"事件，只是视角不同；用对称窗口时完全相等）。所以第一项交换后不变。✓

- 右边第二项：$\log X_i \longrightarrow \log X_k$

**问题来了**：$X_i = \sum_j X_{ij}$ 是词 i 行的和（词 i 作为目标词时它所有上下文词出现总次数），$X_k = \sum_j X_{kj}$ 是词 k 行的和。除非 i = k，**$X_i \neq X_k$**。例如高频词 the 和低频词 xylophone 的"行和"差几个数量级。

所以交换角色后，式(6) 从 $w_i^{\mathrm{T}}\tilde{w}_k = \log X_{ik} - \log X_i$ 变成了 $w_k^{\mathrm{T}}\tilde{w}_i = \log X_{ki} - \log X_k$，两端并不相同——**对称性被 $\log X_i$ 破坏**。这就是论文说的 "Eqn. (6) would exhibit the exchange symmetry if not for the log(Xi) on the right-hand side"。

## 第一步：把 $\log X_i$ 吸收成偏置 $b_i$

关键观察：$\log X_i$ **与 $k$ 无关**——它只依赖目标词 $i$，与"哪个上下文词"无关。这意味着它可以被"吸收"进一个只属于 $i$ 的量。

定义新量：

$$b_i \triangleq -\log X_i$$

代入式(6)：

$$w_i^{\mathrm{T}} \tilde{w}_k = \log X_{ik} + b_i$$

移项：

$$w_i^{\mathrm{T}} \tilde{w}_k - b_i = \log X_{ik}$$

再整理成论文的形式：

$$w_i^{\mathrm{T}} \tilde{w}_k + b_i = \log X_{ik} \qquad (6')$$

（符号方向无所谓，$b_i$ 只是可学习的自由参数，训练时会自动学出正确的符号。）

**为什么合法？** 原本 $\log X_i$ 是**从数据里固定算出来的**——一个不可优化的硬编码值。现在 $b_i$ 是**可学习的自由参数**，让优化器自己去找。模型表达能力不但没减弱，反而更强（$b_i$ 不再受限于 $\log X_i$ 的具体数值，它可以取任何使损失最小的值）。

## 第二步：再加 $\tilde{b}_k$ 恢复完整对称性

现在检查式(6') 的对称性。交换角色：

- 左边：$w_i^{\mathrm{T}} \tilde{w}_k \to w_k^{\mathrm{T}} \tilde{w}_i$（不变）
- 中间：$b_i \to b_k$（只属于目标词的偏置，跟着目标词角色走）——交换后目标词从 $i$ 变成 $k$，所以 $b_i$ 换成 $b_k$，**不对称**
- 右边：$\log X_{ik} \to \log X_{ki} = \log X_{ik}$（不变）

等等，这里 $b_i$ 交换后变成 $b_k$，还是不对称！所以论文说"为 $\tilde{w}_k$ 添加一个额外的偏置 $\tilde{b}_k$ 恢复对称性"——再给**上下文词**也配一个偏置：

$$w_i^{\mathrm{T}} \tilde{w}_k + b_i + \tilde{b}_k = \log X_{ik} \qquad (7)$$

**验证对称性**：交换 $w \leftrightarrow \tilde{w}$（同时 $b \leftrightarrow \tilde{b}$，$i \leftrightarrow k$ 角色互换）：

$$w_k^{\mathrm{T}} \tilde{w}_i + b_k + \tilde{b}_i = \log X_{ki}$$

由于 $w_k^{\mathrm{T}} \tilde{w}_i = w_i^{\mathrm{T}} \tilde{w}_k$、$b_k + \tilde{b}_i$ 与 $b_i + \tilde{b}_k$ 只是"两个可学习参数换了名字"、$\log X_{ki} = \log X_{ik}$——**形式完全一致，对称性恢复**。✓

## 这一步的深层含义

式(7) 的完整解读：**"词 i 与上下文词 k 的关联强度（共现对数）" = "两向量内积" + "目标词自身的流行度偏置" + "上下文词自身的流行度偏置"**。

偏置项吸收的是词的**独立频率信息**（一阶统计量），内积承载的是词对之间的**关联信息**（二阶统计量）。两者解耦后，向量本身只需编码"关系"，不必纠结"谁更常见"——这就是为什么 GloVe 向量做类比（king − man + woman ≈ queen）效果好的结构基础：频率差异被偏置项吸走了，向量里剩下的纯是语义结构。

## 偏置吸收的完整代数链条

```
式(6):  w_i^T w̃_k = log X_ik − log X_i          （−log X_i 与 k 无关，破坏对称）
                │ 令 b_i ≜ −log X_i（把硬编码常数变成自由参数）
式(6'): w_i^T w̃_k + b_i = log X_ik              （目标词偏置已吸收，但交换角色时 b_i→b_k 仍不对称）
                │ 加上下文词偏置 b̃_k
式(7):  w_i^T w̃_k + b_i + b̃_k = log X_ik       （交换角色后形式不变，对称性恢复）
```

至此，从"概率比值"出发的整条推导线闭合：式(1) 的任意函数 $F$ → 线性约束 → 点积 → 同态 → 唯一解 $\exp$ → 对数概率 → 偏置吸收 → **一个干净的线性方程 (7)**，最后变成式(8) 的加权最小二乘损失。
