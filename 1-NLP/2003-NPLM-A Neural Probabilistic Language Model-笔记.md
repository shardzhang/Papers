# NPLM: A Neural Probabilistic Language Model-笔记

> 神经概率语言模型
>
> Yoshua Bengio, Réjean Ducharme, Pascal Vincent, Christian Jauvin | Université de Montréal



#### Q：NPLM

NPLM = **Neural Probabilistic Language Model**（神经概率语言模型）



核心思想

用**前馈神经网络**学习语言模型——这是**第一个把"词嵌入"和"神经网络语言模型"结合起来的工作**，后来所有神经语言模型（RNNLM、word2vec、GPT 的远祖）都源于它。

具体做法（对应前面讨论的公式）：

1. **每个词**被映射为一个低维实值向量（embedding），参数存于查找表 $C$（$|V| \times d$）
2. **$g_i$ 的实现**：取目标词前 $n-1$ 个词的向量拼接起来，送入一个含隐藏层的前馈网络
3. **输出**：softmax 层给出下一个词 $w_t$ 在整个词表上的条件概率分布 $\hat{P}(w_t \mid w_{t-1}, \ldots, w_{t-n+1})$
4. **训练**：最大化训练集的对数似然（即最小化负对数似然），用梯度下降**同时更新网络权重和词向量**



为什么重要

- **解决了 n-gram 的稀疏问题**：词通过 embedding 共享统计强度——"见过"的词义相近的词会分到相似的向量，未见过的词组合也能得到合理概率
- **历史被 $g_i$ 压缩**：参数规模从 n-gram 的 $|V|^n$ 降到 $O(|V|d + |V|hd)$ 级别，第一次证明了用固定维度向量摘要历史是可行的
- 论文还指出主要缺点：softmax 输出层计算量随词表线性增长（$O(|V|)$），训练慢——这正是十年后 word2vec 负采样、以及更早 Morin & Bengio 分层 softmax 要解决的问题

所以前面两个问题（链式法则分解、$10^{100}$ 参数爆炸）正是这篇论文的立论背景。



#### Q：公式（1）含义

$$
\hat{P}(Z_1 = z_1, \ldots, Z_n = z_n) = \prod_i \hat{P}(Z_i = z_i \;|\; g_i(Z_{i-1} = z_{i-1}, \ldots, Z_1 = z_1))
$$

这是**链式法则（chain rule）在序列上的应用**：长度为 $n$ 的序列 $(z_1, \ldots, z_n)$ 的联合概率，被分解为 $n$ 个"给定全部历史、预测当前位置"的条件概率之积。这正是所有自回归语言模型（n-gram、NPLM、RNNLM、LSTM-LM、GPT）的统一框架——**语言建模的本质就是"根据前面的词预测下一个词"**。

符号逐项

| 符号 | 含义 |
| --- | --- |
| $Z_1, \ldots, Z_n$ | 序列中每个位置上的随机变量（如句子第 $i$ 个位置的词） |
| $z_i$ | 对应随机变量的具体取值（一个具体词） |
| $\hat{P}$ | **模型估计的**概率，区别于未知的真实分布 $P$ |
| $g_i(\cdot)$ | 一个**函数**（典型实现是神经网络），把完整历史 $z_1, \ldots, z_{i-1}$ 压缩成一个**固定长度的表示/摘要**，然后据此计算下一个词的分布 |
| $g_i$ 的下标 $i$ | 允许每个位置有不同函数；论文随后指出，由于每个 $Z_i$ 都是"同一种对象"（词），实际让 $g_i$ **跨时间共享参数**（同一个 $g$ 反复用） |

为什么必须这样分解

1. **直接参数化联合概率不可行**：若词表大小 $|V| = 10^5$、句长 $n = 20$，联合分布有 $|V|^n = 10^{100}$ 个参数。分解后每个因子只是"历史 → 下一个词"的条件分布，可独立用共享参数建模。
2. **$g_i$ 解决历史爆炸问题**：历史长度无限增长，无法显式存储。$g_i$ 的作用是把历史**摘要成固定维向量**。不同模型只是 $g_i$ 不同：
   - **n-gram**：$g_i$ = 截断到最近 $n-1$ 个词（信息损失大）
   - **NPLM（本文）**：$g_i$ = 前 $n-1$ 个词的 embedding **拼接后过神经网络**
   - **RNN/LSTM**：$g_i$ = 递归更新的隐状态（$h_i = f(h_{i-1}, z_{i-1})$），理论上能利用任意长历史

训练与生成

- **训练**：在语料上最小化负对数似然 $\sum_i -\log \hat{P}(z_i \;|\; g_i(\text{历史}))$，即让模型给"实际出现的下一个词"赋越高概率越好。
- **生成**：逐位置采样——先采 $z_1 \sim \hat{P}(Z_1)$，把 $z_1$ 送入 $g_2$ 得到下一个词的分布再采样 $z_2$，依此类推（GPT 的文本生成就是这么做的）。

与论文上下文的关系

论文介绍这个式子是为了承接 Bengio 和 Bengio (2000) 在 UCI 数据集上的工作（那里 $Z_i$ 可以是任意顺序的变量），然后指出语言建模的两点差异：① 序列长度可变；② 所有 $Z_i$ 是同质对象（都是词），所以引入**参数共享**——这才是 NPLM 的核心贡献之一。



#### Q：若词表大小 $|V| = 10^5$、句长 $n = 20$。为什么联合分布有 $|V|^n = 10^{100}$ 个参数？

因为**长度为 20 的"完整词序列"本身就是联合概率表要枚举的每一个结果**。

1. 先数结果：有多少种可能序列？

长度为 $n$ 的序列，每个位置从词表 $V$ 中任选一个词：

- 位置 1：$10^5$ 种选择
- 位置 2：$10^5$ 种选择
- ……
- 位置 20：$10^5$ 种选择

由于每个位置相互独立地任选，总的序列数是**连乘**：

$$
\underbrace{10^5 \times 10^5 \times \cdots \times 10^5}_{20 \text{ 次}} = (10^5)^{20} = 10^{5 \times 20} = 10^{100}
$$

这就是组合数学的乘法原理：第一个词有 $|V|$ 种取值，第二个词也有 $|V|$ 种取值（与第一个词组合成 $|V|^2$ 种"二元序列"），依此类推，$n$ 个位置就是 $|V|^n$。



2. 联合分布要"给每个结果一个概率"

离散联合分布是一个**查询表**：对每一种可能的完整序列 $(z_1, \ldots, z_n)$，都要指定一个概率值。有多少种序列，**就需要多少个表项**。所以参数数量 = 序列总数 = $|V|^n$。

严格说还要减 1（所有概率必须和为 1，最后一个表项由其余推出），即 $|V|^n - 1$ 个自由度，但数量级相同。



3. 一个重要补充：链式法则本身并不能减少参数

细想一下——分解成 $\prod_i \hat{P}(Z_i \mid \text{历史})$ 后，如果每个条件概率仍然按"历史 → 词"的完整查询表实现：

- 第 $i$ 个位置，历史有 $|V|^{i-1}$ 种，每种历史下要 $|V|$ 个概率
- 全部加起来 $\approx |V| + |V|^2 + \cdots + |V|^n \approx |V|^n$

参数数量并没有真正下降！**真正的削减来自 $g_i$**：用神经网络把任意长度的历史压缩成一个固定 $d$ 维向量，参数只随 $|V| \cdot d$（加共享的网络权重）增长，与 $n$ 无关。这正是上一个回答里"$g_i$ 解决历史爆炸问题"的精确含义——链式法则只是换了个记账方式，参数共享的 $g_i$ 才让 $10^{100}$ 变成几百万。



#### Q：这句话是什么意思 ？

>  其中 $g(\cdot)$ 是由一个**具有特殊从左到右架构的神经网络表示的函数**，第 $i$ 个输出块 $g_i()$ 计算参数以表示 $Z_i$ 在给定之前 $Z$ 值（按某种任意顺序）条件下的条件分布。

这句话是 Bengio 等人在引用其前期工作 **Bengio & Bengio (2000)**（在 UCI 数据集上用神经网络做概率分解的实验）时做的概括，本质上就是前面讨论过的**链式法则公式**

$$
\hat{P}(Z_1, \ldots, Z_n) = \prod_i \hat{P}(Z_i = z_i \mid g_i(Z_{i-1}, \ldots, Z_1))
$$

的**神经网络实现方案**。逐层拆解：

1. "从左到右架构的神经网络"

把 $n$ 个随机变量 $Z_1, \ldots, Z_n$ 排成一列，网络按这个顺序从左到右处理。关键约束是：**第 $i$ 个输出块只允许"看到"（连接来自）它左边的变量** $Z_1, \ldots, Z_{i-1}$，不允许看到右边或它自己。

这样做的目的是**把链式法则的结构"硬编码"进网络拓扑**——每个因子只依赖历史，网络天然就是一个有向无环图（DAG），不会"偷看未来"。

2. "第 $i$ 个输出块 $g_i()$ 计算参数"

注意用词：网络**不是直接输出 $Z_i$ 的值**，而是输出**条件分布的参数**。

- 若 $Z_i$ 是离散变量（如词）：$g_i$ 输出一个概率向量（通常经 softmax 归一化），每个分量对应 $Z_i$ 的一个可能取值
- 若 $Z_i$ 是连续变量：$g_i$ 可能输出**均值/方差等分布参数**

也就是说 $g_i$ = "输入一段历史 → 输出一个分布"，这个分布就是 $\hat{P}(Z_i \mid Z_{i-1}, \ldots, Z_1)$。

3. "按某种任意顺序"

链式法则对变量的排列顺序没有要求——**任何顺序都严格成立**：

$$
\hat{P}(a,b) = \hat{P}(a)\hat{P}(b|a) = \hat{P}(b)\hat{P}(a|b)
$$

所以在 Bengio & Bengio (2000) 的 UCI 实验里，变量可以按任意顺序排；而"从左到右"架构只需与所选顺序一致即可。

4. 与 NPLM 的区别（论文紧接着指出的两点）

原文下一段立刻说明语言建模不能直接套用这个通用框架：

1. **变量长度可变**：**句子长度不一，网络结构无法固定**；
2. **所有 $Z_i$ 是同质对象**（都是"词"），所以没必要每个位置配一个不同的 $g_i$——可以让**同一个 $g$ 跨位置共享参数**，这正是 NPLM 的循环使用同一个网络/embedding 表的核心设计。

一句话总结

这句话描述的是：**用"每个输出块只连历史变量"的左到右网络，把联合分布实现成链式法则的乘积**——$g_i$ 不是预测下一个符号，而是输出下一个符号的整个条件分布；而 NPLM 在此基础上**把"每位置独立参数"改成"跨位置共享参数"**，从而能处理变长词序列。





#### Q：详细解释

> $y = b + Wx + U \tanh(d + Hx)$

这是 NPLM 论文中输出层（softmax 层）之前"打分函数"的计算式。它输出的 $y$ 是长度为 $|V|$ 的**未归一化对数概率向量**（现代术语叫 logits），随后过 softmax 变成真正的概率分布：

$$
\hat{P}(w_t \mid w_{t-1}, \ldots, w_{t-n+1}) = \frac{e^{y_{w_t}}}{\sum_i e^{y_i}}
$$

逐项拆解
$$
y = \underbrace{b}_{\text{输出偏置}} + \underbrace{Wx}_{\text{直连路径（线性）}} + \underbrace{U \tanh(d + Hx)}_{\text{经隐藏层的路径（非线性）}}
$$

| 符号    | 形状                  | 含义                                                         |
| ------- | --------------------- | ------------------------------------------------------------ |
| $x$     | $(n-1)m$ 维           | 输入 = 前 $n-1$ 个上下文词的 embedding **拼接**：$x = (C(w_{t-1}), \ldots, C(w_{t-n+1}))$，$C$ 是词特征查找表（每词 $m$ 维） |
| $b$     | $\|V\|$ 维            | 输出层偏置——给每个词一个"先验基准分"（近似词频先验，与上下文无关） |
| $W$     | $\|V\| \times (n-1)m$ | **词特征 → 输出**的直连权重矩阵，可选（可置零）              |
| $d$     | $h$ 维                | 隐藏层偏置                                                   |
| $H$     | $h \times (n-1)m$     | **输入 → 隐藏层**权重                                        |
| $U$     | $\|V\| \times h$      | **隐藏层 → 输出**权重                                        |
| $\tanh$ | 逐元素                | 双曲正切非线性，把 $d + Hx$ 压到 $(-1, 1)$                   |



计算流程（维度变化）
$$
\underbrace{x}_{(n-1)m}
\xrightarrow{H} \underbrace{Hx}_{h}
\xrightarrow{+d,\ \tanh} \underbrace{\tanh(d+Hx)}_{h}
\xrightarrow{U} \underbrace{U\tanh(d+Hx)}_{\|V\|}
$$

同时另一条短路：$x \xrightarrow{W} Wx$（$\|V\|$ 维），两路相加再加 $b$，得到每个候选词的分数 $y$。



为什么要两条路径（$Wx$ 和 $U\tanh(\cdot)$）

- **$U \tanh(d+Hx)$ 非线性路径**：通过隐藏层学上下文组合（哪些词共现、句法搭配等），是模型的主体
- **$Wx$ 直连路径**：让输出层**直接看到原始词特征**，相当于一个"线性快捷方式/退避"——对高频词尤其有用，它们的概率靠词本身的 embedding 就能估得不错；论文说 $W$ 可选为零（去掉直连）
- **词特征层 $C$ 不加非线性**：论文特意说明加了没好处（原文："没有非线性——增加非线性不会带来任何好处"）



为什么参数规模是线性

$y$ 的每个分量 $y_i$ 需要的参数量都只涉及常数个向量/矩阵行，所以总自由参数随 $\|V\|$ 和 $n$ 都只**线性增长**（对比 n-gram 的 $\|V\|^n$ 爆炸）——这是上一轮"$g_i$ 压缩历史"的具体实现：**上下文被压进 $h$ 维隐藏表示**，输出层每个词只花 $h+1$ 左右个参数。



#### Q：这句话什么含义？
>  主要原因是，对于 n-gram 模型，获得特定的 $P(w_t \;|\; w_{t-1}, \ldots, w_{t-n+1})$ 不需要计算词汇表中所有词的概率，因为相对频率的线性组合提供了易于归一化的性质。

NPLM 论文 4.3 节（并行实现）开头，英文原句更精确：

> *"...because of the easy normalization (performed when training the model) enjoyed by the linear combinations of relative frequencies."*

它解释的是：**为什么 n-gram 每预测一个词只花 O(1) 查表，而神经语言模型必须花 O(|V|) 把全词表都算一遍**。分三层理解：

1. n-gram 的概率就是"相对频率"，归一化在训练时就做完了

n-gram 的估计式：

$$
P(w_t \mid w_{t-1}, \ldots, w_{t-n+1}) = \frac{\text{count}(w_{t-n+1}, \ldots, w_t)}{\text{count}(w_{t-n+1}, \ldots, w_{t-1})}
$$

想查**某一个特定词**的概率，只需两次计数查找（分子、分母）。关键是分母 $\text{count}(\text{历史}) = \sum_{w} \text{count}(\text{历史}, w)$ 对所有词是**同一个**——把所有词的相对频率加起来天然等于 1，归一化在**构建模型（计数阶段）时一次性完成**，查询时无需再做任何归一化计算。

2. "线性组合"指平滑 n-gram 的插值，归一化性质被继承

真实的 n-gram 模型都会平滑，典型形式是对不同阶相对频率做**加权线性组合**（如 Jelinek-Mercer 插值）：

$$
P(w_t \mid w_{t-1}) = \lambda \, f(w_t \mid w_{t-1}) + (1-\lambda) \, f(w_t)
$$

每个分量 $f(\cdot)$ 本身已是归一化的分布，且插值权重 $\lambda + (1-\lambda) = 1$，所以**组合结果自动仍是合法概率分布**——归一化性质在线性组合下被保持，权重在训练时调好、查询时同样零成本。

3. 神经模型做不到这一点——这就是瓶颈所在

神经模型的归一化是 softmax：

$$
\hat{P}(w_t \mid \text{上下文}) = \frac{e^{y_{w_t}}}{\sum_{i=1}^{|V|} e^{y_i}}
$$

分母取决于连续上下文 $x$ 的嵌入，每个上下文都不同，**无法在训练时预先算好**。所以哪怕你只想要一个词的概率，也必须把 $|V|$ 个词的分值 $y = b + Wx + U\tanh(d+Hx)$ 全部算出来再归一化——每次预测花 $O(|V|)$，这就是原文说的"主要计算瓶颈在于输出层激活值的计算"。



小结与延伸

- n-gram：查询 $O(1)$，归一化预计算 → 适合几十亿词的海量语料
- NPLM：查询 $O(|V|)$，每次都要重归一化 → 训练/测试都慢

这一矛盾正是后来一系列加速方案的动机：Morin & Bengio 的分层 softmax（$O(\log|V|)$）、Mnih & Hinton 的 NCE、以及 word2vec 的**负采样**（把归一化问题转化成二分类问题，彻底绕开全词表求和）。





#### Q：详细解释（没看懂）

> 相反，我们选择在参数上进行并行化，特别是输出单元的参数，因为这是在我们架构中占绝大多数计算量的地方。每个 CPU 负责计算一个输出子集的非归一化概率，并对相应的输出单元参数（进入该单元的权重）进行更新。这种策略使我们能够以可忽略的通信开销执行并行化随机梯度上升。

这段话出自 NPLM 论文 3.2 节"参数并行处理"，描述的是作者在 **CPU 集群**上的并行化方案。背景正是上一轮讨论的瓶颈：**输出层计算占了总计算量的 99.7%**（论文用 $|V|=17{,}964$、$h=60$、$n=6$、$m=100$ 的实例算出）。逐句拆解：

1. 为什么选"参数并行"而不是"数据并行"

3.1 节的教训：共享内存机器上的数据并行（每个处理器处理不同数据子集、共享同一份参数）在锁同步上卡死；而**CPU 集群**上如果频繁交换所有参数——最大网络接近 100 MB——本地网络传不动。

于是反过来：**把参数切开分给各个 CPU，各管各的**。模型参数中最大的一块是输出层（$b$、$W$、$U$ 共约 $|V| \times (1 + (n-1)m + h)$ 个），所以按**输出单元**切：

$$
\text{CPU } i \text{ 负责 } \left[ i \lceil |V|/M \rceil,\ \min(\lceil |V|/M \rceil, |V| - \text{start}_i) \right) \text{ 区间的词}
$$

2. "每个 CPU 计算一个输出子集的非归一化概率"

回忆输出打分式 $y = b + Wx + U \tanh(d + Hx)$：

- **共享部分** $x$（词特征）和 $\tanh(d+Hx)$（隐藏激活 $a$）只算一次，量很小（约 0.3% 计算量），**所有 CPU 各自重复算**（不通信，避免等锁）
- **切分部分**：CPU $i$ 只算自己那一段词的 logits $y_j = b_j + W_j x + U_j a$，$j \in \text{block}_i$

这样 $O(|V|)$ 的重头计算被 $M$ 个 CPU 平分，且**各自的输出权重就存在本 CPU 上，永远不需要搬运**。

3. "对进入该单元的权重进行更新"

CPU $i$ 拥有的参数正是**进入其输出单元的权重**：$b_j$、$W_j$（$|V|\times(n-1)m$ 的行）、$U_j$（$|V|\times h$ 的行）。反向传播时，这些权重的梯度只依赖本 CPU 已算出的 $y_j$ 与 softmax 分母，所以**更新也在本地完成**，无需任何参数通信。

4. "可忽略的通信开销"——每步只传两类信息

论文明确指出 CPU 只需交换两种东西：

1. **softmax 归一化因子**：softmax 分母 $\sum_j e^{y_j}$ 是全词表求和，各 CPU 先算自己块的局部和 $\sum_{j\in\text{block}_i} e^{y_j}$，再全局归约（all-reduce）成一个标量——通信量 $O(M)$ 个标量
2. **共享层上的梯度**：隐藏层 $a$ 和词特征 $x$ 是共享参数，其梯度 $\frac{\partial L}{\partial a}$、$\frac{\partial L}{\partial x}$ 依赖全部输出单元的误差，所以各 CPU 算出局部贡献后交换求和——通信量只有 $h + (n-1)m$ 维的小向量

每次训练样本交换的数据只有"一个标量 + 两个小向量"，相对 100 MB 的参数体，这就是"可忽略"的含义。

5. 代价与效果

- **代价**：每个 CPU 冗余重复前向部分（选词特征、算 $a$）——但那只占总计算量的极小比例
- **效果**：论文实测通信开销仅占总时间 **1/15**，在 Myrinet 快速网络上"几乎完美的加速"（32×2 个 1.2 GHz Athlon 的 MPI 集群）
- **慢网络变体**：每 $K$ 个样本（mini-batch）通信一次，$K$ 太大时收敛变慢，原因与批量梯度下降通常慢于随机梯度下降相同

一句话总结

把"每个样本都要扫一遍全词表"的 softmax 输出层按词切块分给各 CPU 常驻计算；只有归一化标量和小梯度向量需要通信，参数永不搬运——从而以几乎零通信成本线性摊薄了占 99.7% 的输出层计算。这也是现代大规模 softmax 并行（如 GPipe/Tensor 并行切 vocab 维）的早期雏形。
