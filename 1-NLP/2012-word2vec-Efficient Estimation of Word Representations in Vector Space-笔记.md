#### Q：CBOW样本？

一条样本输入多个词，输出一个词。一个滑动窗口对应一条样本。多个输入的emb通过平均池化再经过线性层

$T$：语料单词总数。

对于每个时刻 $t$，上下文单词集合：

\(\boldsymbol{Context}_t=\{w_{t-c},\dots,w_{t-1},w_{t+1},\dots,w_{t+c}\}\)

\(\frac1T\sum_{t=1}^T\log p(w_t\mid \boldsymbol{Context}_t)\)

或者 \(\frac1T\sum_{t=1}^T\log p(w_t\mid w_{{t-c}:{t+c}})\)，其中 $w_{{t-c}:{t+c}}$ 表示上下文 $(w_{t-c},\dots,w_{t-1},w_{t+1},\dots,w_{t+c})$

训练样本条数：$T$



CBOW 模型处理流程

```
句子: "The cat sat on the mat"
窗口 c=2

训练样本:
输入: [The, cat, _, on, the] → 输出: sat
      ↓       ↓    ↓   ↓   ↓
     emb    emb   emb emb emb
      ↓       ↓    ↓   ↓   ↓
      └───────┴────┴───┴───┘
              ↓ 平均池化
           平均向量
              ↓
           线性层
              ↓
           softmax → 预测 sat
```

关键点

| 特性                | 说明                              |
| ------------------- | --------------------------------- |
| 一个窗口 = 一条样本 | 窗口内的所有词构成一个训练样本    |
| 多输入              | 窗口内 $2c$ 个上下文词作为输入    |
| 单输出              | 中心词作为标签                    |
| 平均池化            | 所有输入词的 embedding 取平均     |
| **共享权重**        | 所有位置使用相同的 embedding 矩阵 |



#### Q：Skip-gram训练样本构造

样本不是1条 <1个中心词，C个上下文词>，而是拆成C 条<1个中心词，1个上下文词>。

公式 (1) 明确说明了这一点：

$$\frac{1}{T} \sum_{t=1}^{T} \sum_{-c \leq j \leq c, j \neq 0} \log p(w_{t+j}|w_t)$$

双重求和：外层遍历每个中心词 $w_t$，内层遍历每个上下文词 $w_{t+j}$，每个 $\log p(w_{t+j}|w_t)$ 是独立的一条训练样本。

训练样本条数：$T \cdot 2c$

简单说：Skip-gram 把"一个词预测周围多个词"拆成"一个词预测每一个上下文词"，每个都是独立的二分类任务。



#### Q：CBOW vs Skip-gram

与 Skip-gram 的对比

| 特性         | CBOW              | Skip-gram            |
| ------------ | ----------------- | -------------------- |
| 输入         | 多个上下文词      | 1个中心词            |
| 输出         | 1个中心词         | 1个上下文词          |
| 处理         | 平均池化后预测    | **不合并，拆开**     |
| 样本数       | 1个窗口 = 1条样本 | 1个窗口 = **$2c$条** |
| 训练样本条数 | $T$               | $T\cdot2c$           |

**简单说**：CBOW 是"多人投票选一个答案"，Skip-gram 是"一个人猜多人在哪"。
