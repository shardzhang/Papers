这篇论文是 **Bahdanau 等人 2015 年** 提出的经典注意力机制论文。我来逐个解释关键公式：

---

核心思想一句话

传统编码器-解码器把整个句子压成**一个固定长度向量**，长句子信息丢失严重。这篇论文的创新是：解码每个词时，**动态关注源句子的不同部分**，而不是只依赖一个固定向量。

---

公式 (1)：基础 RNN 编码器

$$h_t = f(x_t, h_{t-1})$$

- $x_t$：第 $t$ 个源词的嵌入向量
- $h_{t-1}$：上一步的隐藏状态
- $h_t$：当前隐藏状态（包含 $x_1$ 到 $x_t$ 的信息）
- $f$：RNN 的循环函数（这里用的是门控单元，类似 LSTM）

$c = q(\{h_1, \cdots, h_{T_x}\})$：把所有隐藏状态压缩成一个固定向量 $c$。论文里简单取 $c = h_{T_x}$（最后一个时间步的状态）。

---

公式 (2)-(3)：解码器生成翻译

$$p(y) = \prod_{t=1}^{T} p(y_t \mid y_1, \cdots, y_{t-1}, c)$$

翻译过程就是逐步预测每个目标词 $y_t$，条件是之前所有已生成的词和上下文向量 $c$。

$$p(y_t \mid \cdots, c) = g(y_{t-1}, s_t, c)$$

- $s_t$：解码器当前的隐藏状态
- $g$：输出层（softmax），给出每个词的概率

---

公式 (4)-(6)：**注意力机制 （核心创新）**

$$p(y_i \mid y_1, \ldots, y_{i-1}, x) = g(y_{i-1}, s_i, c_i)$$

**关键变化**：原来的 $c$ 是固定的，现在变成了 $c_i$——**每个目标词 $y_i$ 有自己专属的上下文向量**。

$$c_i = \sum_{j=1}^{T_x} \alpha_{ij} h_j$$

- $c_i$ 是所有源词注释 $h_j$ 的**加权和**
- $\alpha_{ij}$ 是权重，表示生成 $y_i$ 时，源词 $x_j$ 有多重要
- 这就是"注意力"：模型决定**看源句子的哪个位置**

$$\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_x} \exp(e_{ik})}$$

- 权重通过 softmax 归一化，所有 $\alpha_{ij}$ 加起来等于 1
- $e_{ij}$ 是"能量分数"，表示匹配程度

$$e_{ij} = a(s_{i-1}, h_j)$$

- 对齐模型 $a$ 是一个**前馈神经网络**
- 输入：解码器上一步状态 $s_{i-1}$ + 源词注释 $h_j$
- 输出：一个标量分数，衡量 $y_i$ 和 $x_j$ 的匹配度

**直觉理解**：生成第 $i$ 个法语词时，模型会"回头看"所有英语词，给每个英语词打一个注意力分数 $\alpha_{ij}$，然后按分数加权混合它们的信息，得到当前需要的上下文。

---

公式 (7)：双向 RNN 编码器

$$h_j = \begin{bmatrix} \overrightarrow{h}_j \\ \overleftarrow{h}_j \end{bmatrix}$$

- $\overrightarrow{h}_j$：正向 RNN 的状态（从左到右读，包含 $x_1$ 到 $x_j$ 的信息）
- $\overleftarrow{h}_j$：反向 RNN 的状态（从右到左读，包含 $x_j$ 到 $x_{T_x}$ 的信息）
- 拼接后，$h_j$ 同时包含**前文和后文**的信息

---

附录：门控单元的具体公式

$$s_i = (1 - z_i) \circ s_{i-1} + z_i \circ \tilde{s}_i$$

- $z_i$：**更新门**，控制"保留多少旧记忆"vs"接受多少新信息"
- $\tilde{s}_i$：候选新状态
- $\circ$：逐元素乘法（Hadamard 积）

$$\tilde{s}_i = \tanh(W e(y_{i-1}) + U [r_i \circ s_{i-1}] + C c_i)$$

- $e(y_{i-1})$：上一个目标词的嵌入
- $r_i$：**重置门**，控制"旧状态中多少信息参与计算新候选"
- $C c_i$：上下文向量也参与计算

$$z_i = \sigma(W_z e(y_{i-1}) + U_z s_{i-1} + C_z c_i)$$
$$r_i = \sigma(W_r e(y_{i-1}) + U_r s_{i-1} + C_r c_i)$$

- $\sigma$ 是 sigmoid 函数，输出 0-1 之间的值

---

对齐模型的具体形式

$$a(s_{i-1}, h_j) = v_a^\top \tanh(W_a s_{i-1} + U_a h_j)$$

就是一个简单的单层前馈网络，输入拼接 $s_{i-1}$ 和 $h_j$，输出一个标量分数。

---

总结：数据流

1. **编码**：双向 RNN 把源句子编码为注释序列 $(h_1, \ldots, h_{T_x})$
2. **注意力**：每步解码时，用 $s_{i-1}$ 和所有 $h_j$ 计算注意力权重 $\alpha_{ij}$
3. **加权求和**：$c_i = \sum_j \alpha_{ij} h_j$ 得到当前步的上下文
4. **解码**：用 $s_{i-1}$、$y_{i-1}$、$c_i$ 更新状态并预测 $y_i$

哪个部分还不清楚，可以继续问。

1. GRU（门控循环单元）公式

GRU是论文中使用的循环神经网络激活函数，用于编码器和解码器。

1.1 状态更新公式

$$s_i = (1 - z_i) \circ s_{i-1} + z_i \circ \tilde{s}_i$$

解释：

- $s_i$：当前时间步的隐藏状态
- $s_{i-1}$：前一时间步的隐藏状态
- $\tilde{s}_i$：候选新状态（下面会解释）
- $z_i$：更新门（0到1之间的值）
- $\circ$：逐元素乘法

直观理解：这个公式就像一个"滑动开关"：

- 当$z_i \approx 0$时，$s_i \approx s_{i-1}$，保持旧状态
- 当$z_i \approx 1$时，$s_i \approx \tilde{s}_i$，完全更新为新状态
- 通常$z_i$在0到1之间，所以新状态是旧状态和候选状态的加权平均

2.1.2 候选状态公式

 $$\tilde{s}_i = \tanh(W e(y_{i-1}) + U [r_i \circ s_{i-1}] + C c_i)$$

解释：

- $\tilde{s}_i$：候选新状态
- $e(y_{i-1})$：前一个输出词$y_{i-1}$的词嵌入向量
- $W$：词嵌入的权重矩阵
- $U$：隐藏状态的权重矩阵
- $r_i$：重置门（下面会解释）
- $c_i$：上下文向量（注意力机制提供）
- $C$：上下文向量的权重矩阵

直观理解：这个公式计算"可能的新状态"，它考虑了：

1. 当前输入（通过词嵌入$e(y_{i-1})$）
2. 前一状态中被重置门$r_i$选择保留的部分
3. 来自源句子的上下文信息$c_i$

1.3 更新门公式

$$z_i = \sigma(W_z e(y_{i-1}) + U_z s_{i-1} + C_z c_i)$$

解释：

$z_i$：更新门，值在0到1之间
$\sigma$：sigmoid函数，将输入映射到(0,1)
其他符号类似候选状态公式
直观理解：更新门决定"保留多少旧状态，接受多少新状态"：

$z_i$接近0：保留更多旧状态（长期记忆）
$z_i$接近1：接受更多新状态（短期更新）

1.4 重置门公式

$$r_i = \sigma(W_r e(y_{i-1}) + U_r s_{i-1} + C_r c_i)$$

解释：

$r_i$：重置门，值在0到1之间
其他符号类似更新门
直观理解：重置门决定"在计算候选状态时，忽略多少旧状态"：

$r_i$接近0：忽略大部分旧状态（类似于从头开始）
$r_i$接近1：保留大部分旧状态（继承历史信息）
重置门的作用：在计算候选状态$\tilde{s}i$时，我们使用$r_i \circ s{i-1}$，这意味着：

如果$r_i \approx 0$，候选状态几乎不依赖旧状态
如果$r_i \approx 1$，候选状态很大程度上依赖旧状态

这使得模型能够"重置"历史信息，当需要关注新信息时。

2. 对齐模型公式
对齐模型是注意力机制的核心，用于计算源句子中每个位置与当前解码位置的相关性。
2.1 对齐能量公式
$$e_{ij} = v_a^\top \tanh(W_a s_{i-1} + U_a h_j)$$
解释：
- $e_{ij}$：对齐能量，表示源位置$j$与解码位置$i$的相关性分数
- $s_{i-1}$：解码器的前一个隐藏状态
- $h_j$：编码器在源位置$j$的隐藏状态（注释）
- $v_a$：权重向量
- $W_a$：解码器状态的权重矩阵
- $U_a$：编码器状态的权重矩阵
直观理解：这个公式计算一个"相关性分数"：
1. 将解码器状态$s_{i-1}$和编码器状态$h_j$分别通过线性变换
2. 将它们相加，通过tanh激活函数
3. 通过权重向量$v_a$计算一个标量分数
为什么用tanh？ tanh将输入映射到(-1,1)范围，增加非线性，使得模型能够学习复杂的对齐模式。
2.2 注意力权重公式
$$\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_x} \exp(e_{ik})}$$
解释：
- $\alpha_{ij}$：注意力权重，表示源位置$j$对解码位置$i$的重要性
- 这是一个softmax操作，将所有位置的对齐能量转换为概率分布
直观理解：
1. 对所有源位置$j$的对齐能量$e_{ij}$取指数
2. 除以所有位置的指数和，得到归一化的权重
3. 所有权重之和为1：$\sum_j \alpha_{ij} = 1$
重要特性：
- 权重大的位置表示模型认为这个源词对当前翻译更重要
- 权重小的位置表示这个源词不太相关
- 这使得模型能够"关注"源句子的不同部分

3. 编码器公式
编码器使用双向循环神经网络（BiRNN）来处理源句子，生成每个位置的注释（annotation）。
3.1 正向状态计算
$$\overrightarrow{h}_i = \begin{cases} (1 - \overrightarrow{z}_i) \circ \overrightarrow{h}_{i-1} + \overrightarrow{z}_i \circ \overrightarrow{\tilde{h}}_i, & \text{if } i > 0 \\ 0, & \text{if } i = 0 \end{cases}$$
解释：
- $\overrightarrow{h}_i$：正向隐藏状态，从左到右处理源句子
- 这本质上是GRU的状态更新公式，只是方向是正向的
- 初始状态$\overrightarrow{h}_0 = 0$（全零向量）
3.2 正向状态的细节
$$\begin{aligned}
\overrightarrow{\tilde{h}}_i &= \tanh(\overrightarrow{W} E x_i + \overrightarrow{U} [\overrightarrow{r}_i \circ \overrightarrow{h}_{i-1}]) \\
\overrightarrow{z}_i &= \sigma(\overrightarrow{W}_z E x_i + \overrightarrow{U}_z \overrightarrow{h}_{i-1}) \\
\overrightarrow{r}_i &= \sigma(\overrightarrow{W}_r E x_i + \overrightarrow{U}_r \overrightarrow{h}_{i-1})
\end{aligned}$$
解释：
- $E$：词嵌入矩阵，将one-hot向量转换为稠密向量
- $x_i$：源句子第$i$个位置的输入（one-hot编码）
- 其他符号与GRU公式类似
直观理解：正向RNN从句子开头处理到结尾，每个位置的状态都包含前面所有词的信息。
3.3 反向状态计算
反向状态的计算类似，但方向是从右到左：
- 从句子结尾开始，向句子开头处理
- 每个位置的状态包含后面所有词的信息
3.4 拼接公式
$$h_i = \begin{bmatrix} \overrightarrow{h}_i \\ \overleftarrow{h}_i \end{bmatrix}$$
解释：
- $h_i$：最终的注释向量，是正向和反向状态的拼接
- 如果正向状态维度是$n$，反向状态维度也是$n$，则$h_i$的维度是$2n$
为什么需要双向？
1. 正向RNN只看到前面的词，不知道后面的词
2. 反向RNN只看到后面的词，不知道前面的词
3. 拼接后，每个位置的注释都包含整个句子的信息
重要特性：
- 每个源位置都有一个注释向量$h_i$
- 这些注释向量被用于注意力机制，计算上下文向量$c_i$

4. 解码器公式
解码器负责生成翻译，它使用注意力机制动态关注源句子的不同部分。
4.1 上下文向量计算
$$c_i = \sum_{j=1}^{T_x} \alpha_{ij} h_j$$
解释：
- $c_i$：上下文向量，为解码位置$i$提供源句子信息
- $\alpha_{ij}$：注意力权重（前面已解释）
- $h_j$：源位置$j$的注释向量（编码器输出）
- $T_x$：源句子的长度
直观理解：上下文向量是源句子所有位置注释向量的加权平均：
- 权重大的位置对上下文向量贡献大
- 权重小的位置对上下文向量贡献小
- 这使得解码器能够"聚焦"于源句子的相关部分
重要特性：
- 每个解码位置$i$都有自己的上下文向量$c_i$
- 不同位置可能关注源句子的不同部分
- 这实现了动态对齐，不同于传统的固定对齐
4.2 注意力权重计算（再次强调）
$$\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_x} \exp(e_{ik})}$$
关键点：
- 注意力权重在每一步都重新计算
- 权重分布随解码过程动态变化
- 这使得模型能够处理长距离依赖
4.3 输出概率公式
$$p(y_i \mid s_i, y_{i-1}, c_i) \propto \exp \left( y_i^\top W_o t_i \right)$$
解释：
- $p(y_i \mid s_i, y_{i-1}, c_i)$：给定当前状态$s_i$、前一个输出$y_{i-1}$和上下文$c_i$，输出词$y_i$的概率
- $y_i$：目标词的one-hot向量（在概率计算中作为索引）
- $W_o$：输出权重矩阵
- $t_i$：深度输出层的隐藏表示（下面会解释）
直观理解：这个公式计算每个可能目标词的分数，然后通过softmax转换为概率分布。
为什么用$\propto$？ 表示"正比于"，实际计算时需要归一化，使得所有词的概率之和为1。


5. Maxout隐藏层和输出层公式
论文使用了一个单层maxout网络作为深度输出层，提高模型的表达能力。
5.1 Maxout隐藏层计算
$$t_i = \left[ \max \{ \tilde{t}_{i,2j-1}, \tilde{t}_{i,2j} \} \right]_{j=1, \ldots, l}^\top$$
解释：
- $t_i$：深度输出层的最终表示，维度为$l$
- $\tilde{t}_i$：中间表示，维度为$2l$
- $\tilde{t}_{i,k}$：$\tilde{t}_i$的第$k$个元素
- $l$：maxout隐藏层的大小（论文中$l=500$）
Maxout操作：
- 将$\tilde{t}_i$的元素两两分组：$(\tilde{t}_{i,1}, \tilde{t}_{i,2}), (\tilde{t}_{i,3}, \tilde{t}_{i,4}), \ldots$
- 每组取最大值：$\max(\tilde{t}_{i,1}, \tilde{t}_{i,2}), \max(\tilde{t}_{i,3}, \tilde{t}_{i,4}), \ldots$
- 得到$l$个值，组成向量$t_i$
为什么用Maxout？
1. Maxout是一种可学习的激活函数
2. 它可以近似任意凸函数
3. 比ReLU等固定激活函数更灵活
4. 能够学习更复杂的输出分布
5.2 中间表示计算
$$\tilde{t}_i = U_o s_{i-1} + V_o E y_{i-1} + C_o c_i$$
解释：
- $U_o$：解码器状态的权重矩阵
- $V_o$：词嵌入的权重矩阵
- $C_o$：上下文向量的权重矩阵
- 其他符号与之前相同
直观理解：这个公式综合了三个信息源：
1. 解码器状态$s_{i-1}$：当前翻译的上下文
2. 前一个输出词$y_{i-1}$的嵌入：已生成的部分翻译
3. 上下文向量$c_i$：源句子的相关信息
5.3 完整的输出概率计算
结合所有公式，输出概率的完整计算流程是：
1. 计算中间表示：$\tilde{t}_i = U_o s_{i-1} + V_o E y_{i-1} + C_o c_i$
2. 应用maxout：$t_i = \text{maxout}(\tilde{t}_i)$
3. 计算分数：$\text{score}(y_i) = y_i^\top W_o t_i$
4. softmax归一化：$p(y_i) = \frac{\exp(\text{score}(y_i))}{\sum_{y'} \exp(\text{score}(y'))}$



6. 总结：各公式之间的逻辑关系和整体架构
6.1 整体数据流
源句子 x → [编码器] → 注释向量 h_1, ..., h_Tx
                        ↓
解码器 s_{i-1} → [对齐模型] → 注意力权重 α_{i1}, ..., α_{iTx}
                        ↓
              [上下文向量] c_i = Σ α_{ij} * h_j
                        ↓
解码器状态 s_{i-1} + 前一输出 y_{i-1} + 上下文 c_i → [GRU] → 新状态 s_i
                        ↓
              [深度输出层] → 概率分布 p(y_i)
                        ↓
              [采样/贪心/束搜索] → 输出词 y_i
6.2 各组件的作用
组件	公式
编码器	双向GRU
对齐模型	$e_{ij} = v_a^\top \tanh(W_a s_{i-1} + U_a h_j)$
注意力权重	$\alpha_{ij} = \text{softmax}(e_{ij})$
上下文向量	$c_i = \sum_j \alpha_{ij} h_j$
解码器GRU	$s_i = (1-z_i) \circ s_{i-1} + z_i \circ \tilde{s}_i$
深度输出层	$t_i = \text{maxout}(\tilde{t}_i)$
输出概率	$p(y_i) \propto \exp(y_i^\top W_o t_i)$
6.3 关键创新点
1. 动态对齐：传统NMT使用固定对齐，而RNNsearch在每一步都重新计算注意力权重，实现动态对齐。
2. 端到端训练：整个模型（编码器、解码器、对齐模型）联合训练，无需人工设计对齐规则。
3. 长距离依赖：GRU的门控机制和注意力机制共同解决了长句子的依赖问题。
4. 深度输出：使用maxout网络作为输出层，比简单的线性投影更能捕捉复杂模式。
6.4 与传统方法的区别
特性	传统NMT (如RNNencdec)
对齐方式	固定上下文向量
源句子表示	单向RNN
输出层	简单线性投影
长句子处理	性能下降明显
6.5 公式间的依赖关系
编码器公式 → 注释向量 h_j
    ↓
对齐模型公式 → 对齐能量 e_{ij}
    ↓
注意力权重公式 → 权重 α_{ij}
    ↓
上下文向量公式 → 上下文 c_i
    ↓
解码器GRU公式 → 状态 s_i
    ↓
深度输出层公式 → 表示 t_i
    ↓
输出概率公式 → 概率 p(y_i)
