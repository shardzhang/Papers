个人收获：

- 负采样NEG：训练样本中只有正样本，计算标准softmax计算量太大。因为让问题转换为在1个正样本 + 随机K个负样本的多分类问题。将softmax分母变为1+K。注意：负采样不会体现在训练样本中（不会直接操作样本），而是体现在损失计算中
- 子采样：训练样本中大量无效的<输入词，输出词>对，很多共现样本对 对学习没有贡献，全部训练反而拉低训练效率。子采样后不仅加速训练，才能提高低频词表示准确性



## FQA

#### Q1：

**负采样与NCE的主要区别在于，NCE需要样本和噪声分布的数值概率，而负采样仅使用样本**。此外，虽然NCE近似最大化softmax的对数概率，但这一属性对我们的应用并不重要。



这句话解释了负采样（NEG） 和 噪声对比估计（NCE） 之间的两个关键区别：
1. 概率要求不同
- NCE：需要知道样本分布 $P_n(w)$  和 噪声分布的具体数值概率
- 负采样：只需要从噪声分布中采样，不需要知道精确的概率值

这意味着负采样的实现更简单，因为我们不需要维护和计算复杂的概率分布。

2. 目标函数不同
- NCE：近似最大化 softmax 的对数概率（即 $\log p(w_O|w_I)$）
- 负采样：直接定义自己的目标函数，不追求近似 softmax

为什么这个属性不重要？

Skip-gram 模型的**唯一目标是学习高质量的词向量表示**，并**不是要得到精确的概率分布**。因此，NCE 那个"近似 softmax"的特性对词向量学习没有实际帮助。

结论：既然只需要好的词向量，负采样更简单、计算更快，**效果也相当**，所以作者选择了负采样作为 NCE 的简化版本。



#### Q2：

NCE和NEG都将噪声分布 $P_n(w)$ 作为自由参数。我们研究了 $P_n(w)$ 的若干选择，发现将unigram分布 $U(w)$ 提升到 $3/4$ 次幂（即 $U(w)^{3/4}/Z$ ）在每项任务上显**著优于unigram和均匀分布，包括语言建模**（此处未报告）。



这句话讲的是**噪声分布 $P_n(w)$ 的选择问题**。

核心内容

NCE 和 NEG 都需要一个**噪声分布** $P_n(w)$ 来生成负样本。这个分布是可以自由选择的参数。

实验发现

作者测试了几种噪声分布的选择：

| 分布类型    | 公式                   | 特点                     |
| ----------- | ---------------------- | ------------------------ |
| 均匀分布    | $U_{uniform}(w) = 1/V$ | 所有词等概率             |
| Unigram分布 | $U(w)$                 | 按词频分布，高频词概率大 |
| 3/4次幂     | $U(w)^{3/4}/Z$         | 对Unigram做"软化"        |

**结论**：$U(w)^{3/4}$ 在所有任务上都**显著优于**另外两种。

为什么3/4次幂效果最好？

- **均匀分布**：太扁平，**忽略了词频信息**，所有词都一样对待
- **原始Unigram**：太陡峭，高频词（如 "the"、"a"）主导，低频词几乎采不到
- **3/4次幂**：折中方案，既**保留了词频信息**，又让**低频词有更多被采为负样本的机会**

直觉上，$3/4$ 次幂相当于**"压缩"了频率分布**，使得采样更均衡但又不完全忽略词频。



#### Q3：子采样公式

公式详解

$$P(w_i) = 1 - \sqrt{\frac{t}{f(w_i)}}$$

这个公式计算的是**每个词被丢弃（跳过）的概率**。

变量解释

| 变量     | 含义                                           |
| -------- | ---------------------------------------------- |
| $P(w_i)$ | 词 $w_i$ 被丢弃的概率                          |
| $f(w_i)$ | 词 $w_i$ 在语料库中的频率（出现次数 / 总词数） |
| $t$      | 阈值，通常 $t \approx 10^{-5}$                 |

公式行为分析

**情况1：高频词（$f(w_i) \gg t$）**

假设 $f(w_i) = 10^{-2}$（如 "the"），$t = 10^{-5}$：

$$P = 1 - \sqrt{\frac{10^{-5}}{10^{-2}}} = 1 - \sqrt{10^{-3}} = 1 - 0.0316 \approx 0.97$$

→ **97% 的概率被丢弃**，几乎每次都跳过

**情况2：低频词（$f(w_i) \ll t$）**

假设 $f(w_i) = 10^{-8}$（如 "algorithm"），$t = 10^{-5}$：

$$P = 1 - \sqrt{\frac{10^{-5}}{10^{-8}}} = 1 - \sqrt{1000} = 1 - 31.6$$

概率不能为负数，所以当 $f(w_i) < t$ 时，$P = 0$（不丢弃）

**情况3：中频词（$f(w_i) \approx t$）**

$$P = 1 - \sqrt{\frac{t}{t}} = 1 - 1 = 0$$

→ 不丢弃，100% 保留

核心思想 

| 频率范围     | 丢弃概率 | 效果       |
| ------------ | -------- | ---------- |
| $f(w_i) > t$ | 接近 1   | 激进子采样 |
| $f(w_i) = t$ | 0        | 完全保留   |
| $f(w_i) < t$ | 0        | 完全保留   |

**$t$ 就是一个分界线**：
- 频率 > $t$ 的词（高频词）：被激进子采样
- 频率 ≤ $t$ 的词（低频词）：完全保留

为什么用 $\sqrt{}$？

平方根的作用是**平滑采样率**，避免：
- 频率稍高于 $t$ 的词被过度采样
- 频率稍低于 $t$ 的词完全不被采样

相比直接用 $1 - t/f(w_i)$，$\sqrt{}$ **使得采样率变化更温和**。

实际效果

假设语料库有 10 亿词：
- "the"（频率 $10^{-2}$）：出现 1000 万次 → 子采样后保留约 30 万次
- "Paris"（频率 $10^{-6}$）：出现 1000 次 → 完全保留

**高频词被大幅削减，低频词完整保留**，训练效率和质量都提升。



#### Q4：样本如何生成? 训练样本是词对么? <输入词, 输出词> 这样?

是的，训练样本就是**词对** <输入词, 输出词>。让我详细解释：

Skip-gram 样本生成机制

核心思想

给定一个句子，用**中心词**预测**上下文词**。

具体例子

假设句子：`"The cat sits on the mat"`

窗口大小 $c = 2$（左右各看2个词）

| 中心词（输入） | 上下文词（输出） |
| -------------- | ---------------- |
| cat            | the              |
| cat            | sits             |
| cat            | on               |
| sits           | The              |
| sits           | cat              |
| sits           | on               |
| sits           | The              |
| ...            | ...              |

数学表达

公式 (1)：

$$\frac{1}{T} \sum_{t=1}^{T} \sum_{-c \leq j \leq c, j \neq 0} \log p(w_{t+j}|w_t)$$

- $w_t$：中心词（输入）
- $w_{t+j}$：上下文词（输出）
- $j \neq 0$：**排除中心词自己**

每个样本的结构

```
输入：中心词的 one-hot 向量
输出：上下文词的 one-hot 向量
```

举例说明关键点

1. **一个中心词生成多个样本**：窗口内的每个上下文词都构成一个独立样本
2. **有向的**：从中心词→上下文词，不是双向的
3. **样本数量**：$T \times (2c)$，其中 $T$ 是句子长度，$c$ 是窗口大小
4. **负采样时**：对每个正样本（中心词, 上下文词），随机采样 $k$ 个负样本（中心词, 噪声词）

**简单说**：Skip-gram 把"语境中哪些词会一起出现"转换成多分类问题——区分真正的上下文词和随机噪声词。
