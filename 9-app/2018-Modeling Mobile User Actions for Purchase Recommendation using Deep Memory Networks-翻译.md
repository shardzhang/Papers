# 使用深度记忆网络建模移动用户行为进行购买推荐

> Djordje Gligorijevic, Jelena Gligorijevic, Aravindan Raghuveer, Mihajlo Grbovic, Zoran Obradovic | Temple University; Facebook Inc.; Airbnb

本文提出一种基于深度记忆网络（Deep Memory Networks, DMN）的方法，从移动应用使用会话和购买记录中学习用户行为表示，用于移动购买推荐。**DMN模型在召回率上显著优于所有基线，加入用户个性化后召回率提升4.5-10倍**。

核心内容：

- 利用深度记忆网络（DMN）建模移动应用事件序列，结合外部记忆捕获用户长期和短期行为模式
- 数据来自两个来源：Flurry SDK采集的移动应用事件日志和应用商店购买记录，共超过250万条购买记录
- 引入用户个性化嵌入，将用户历史会话作为外部记忆，为每个用户构建个性化预测模型
- 使用采样Softmax（sampled softmax）解决大规模词汇表（约14万商品）的计算效率问题

关键发现：

- DMN模型在购买预测任务上Recall@5达到**0.003315**，是word2vec基线（0.001576）的**2.1倍**
- 加入用户嵌入后（DMN-user），Recall@5飙升至**0.028720**，比非个性化DMN提升**8.7倍**
- 嵌入空间分析显示DMN能够语义消歧不同应用的事件名称（如"open"和"close"事件的近邻学习正确）
- 约50%的购买行为发生前1小时内有超过10次应用事件信号，验证了事件序列作为购买意图信号的有效性

## 摘要

移动设备的迅速扩张为移动运营商和内容发布商带来了前所未有的机遇，可以在任何时间触达大量用户。理解移动应用（App）的使用模式是为用户提供相关推荐的前置任务。然而，由于应用数据的非结构化特性和可用信息的稀疏性，这一任务可能非常困难。本研究提出一种使用深度记忆网络（Deep Memory Networks）学习移动用户行为表示的新方法。我们在从大规模移动应用事件流和移动购买记录中构建的数百万个应用使用会话上验证了所提出的方法。实证研究表明，所提出的方法在推荐精度质量方面优于几个竞争基线。据我们所知，这是第一个分析应用使用模式以进行购买推荐的研究。

## 1 引言

近年来我们见证了智能移动设备数量的快速增长，随之而来的是2015年移动数据流量增长74%，2016年增长63%，并且据估计在不久的将来，大部分互联网消费将来自移动端。这种无处不在的移动使用环境为移动广告提供了比传统在线广告更大的市场机会[1]。

为了持续改进广告效果，需要更好地理解移动使用模式，特别是那些导致移动购买的使用行为。挖掘用户的移动应用使用行为和购买习惯是实现更优质上下文感知广告设计和推荐的基本任务。

在这一背景下，监控用户的移动活动并从选择匿名广告研究的用户中生成应用事件日志，作为丰富的数据来源。另一条相关信息来自用户的购买习惯，可以在应用商店购买记录中找到。在我们的研究中，数据最终由在移动应用商店进行购买并使用一个或多个注册在专有广告SDK上的应用的注册用户组成。应用事件信号对预测移动购买的有用性体现在：约50%的购买行为发生前1小时内有超过10次来自注册在专有SDK上的应用的信号。将两个数据源耦合将产生如图1所示的会话。应用事件日志因此被视为购买商品的上下文。在我们的示例中，我们观察到用户在一个特定时间窗口内，花时间与朋友交流和听音乐，然后玩一个移动游戏（我们的示例中是Angry Birds），之后他购买了游戏中的金币。示例会话描绘了一个主要意图是娱乐的用户，这经常导致购买应用内商品以获得完整体验。

预测用户的购买意图是一个困难的问题，主要原因是用户可以购买的产品和服务（item）数量庞大。此外，应用事件传统上由应用开发者定义，他们提供自由形式的文本描述，因此在应用宇宙中缺乏统一性，这构成了使用这些信息的挑战。

本研究的目标是提出一个能够应对上述挑战的模型，从应用事件序列中捕获有用的模式，用于预测用户的购买意图，提升广告定向和应用推荐能力。将用户行为建模为会话并学习序列中事件的低维分布式表示，相比于协同过滤或聚类等传统方法，近年来带来了显著收益。然而，这些方法主要是无监督的，或者更准确地说，它们没有显式地建模监督信息。我们旨在使用一类能够利用神经嵌入模型能力的模型，同时保留显式建模给定序列的监督信息的能力。具体来说，我们利用最近提出的深度记忆网络（DMN）模型[5]，该模型能够显式建模与预测当前事件相关的记忆。例如，在移动游戏内购买或在移动商店购买歌曲的用户很可能会再次这样做。我们的结果表明，所提出的方法在移动购买预测上优于其他方法，同时学习到有意义的噪声事件表示。

## 2 相关工作

大多数挖掘移动应用数据的研究集中在使用从用户会话日志和其他可用应用元数据收集的数据，将移动应用分类到不同应用市场使用的类别集合中。方法包括各种主题建模技术[8]、协同过滤[7]和神经嵌入[3]。除了[3]之外，上述方法主要在有限数量的用户（<500）和相对较少的应用上进行实验，这留下了可扩展性作为开放问题。此外，考虑到不同用户可能有不同的偏好，在大多数情况下用户上下文被忽略，这仍然是一个开放的研究问题。这些问题在本研究中得到了解决。实证证据表明，使用我们的方法优于反映上述研究的基线。

## 3 数据

如引言所述，我们的数据来自两个数据源：移动购买记录数据和应用事件流。

**购买记录数据**：在保护隐私的前提下匿名化用户ID，构建了用户购买记录数据集，并由自动系统进行分析。使用内部提取工具从记录中提取产品信息。我们在三个月内收集了超过250万条应用商店购买记录，来自用户子集。用户绝大多数（约70%）偏好购买单个item，这表明用户有直接购买特定感兴趣item的意图，而非捆绑购买。由于移动广告努力因屏幕大小而允许的广告数量有限（如果应用没有可滚动屏幕，通常最多5个广告），在给定时间点向用户投放相关item的广告非常重要，而非投放更通用的广告。移动item的购买预测将使用从专有移动广告SDK收集的移动行为信号来解决。

**Flurry SDK应用事件数据**：移动事件数据来自移动分析、变现和广告平台Flurry，该平台允许用户注册其智能设备应用并在其中进行广告投放时获得丰富的洞察。数据主要由用户应用事件活动流组成，每天记录数百亿条。出于本研究的目的，仅对自愿选择参加此类研究的移动用户进行活动采样，他们的匿名ID与购买记录数据连接。在此数据集中，我们观察到约75%的购买行为发生前有超过一次应用事件，50%有超过十次事件，10%有超过20次事件。我们将这些事件流用作移动购买的上下文，假设使用活动揭示了用户的购买意图。

**预测任务**：我们的目标是根据用户的移动应用事件会话估计用户最可能购买的item，以便广告/推荐系统能够通过提供用户感兴趣item的及时推荐来做出响应。

## 4 方法论

我们首先给出预测任务的公式化，然后提出解决所公式化问题的方法论。

### 4.1 问题设置

假设我们有一组来自应用宇宙$A$的移动应用事件，以及一组来自item宇宙$T$的应用商店购买item。进一步，我们考虑一组应用事件$X_n \subset A$，与时间戳相关联，在任意选择的时间窗口内（我们的实验中为一小时）发生，位于包含item集合$Y_n \subset T$的应用商店记录之前，代表每个独立会话$x_n$中用户的购买，其中$x_n = \{X_n, Y_n\} = \{\{a_1, a_2, a_3, \ldots\}, \{t_1, t_2, \ldots\}\}$。我们考虑应用商店item推荐任务，即给定用户在时间窗口内采取的所有应用事件$X_n$，我们希望预测用户最可能购买的item。通过检索最可能的或$K$个最可能的item，我们向用户提供推荐。

### 4.2 提出的方法

在这里，我们提出使用并扩展深度记忆网络（DMN）模型[5]用于移动购买推荐任务。DMN基于先前提出的分布式嵌入方法[6]，我们与之进行实验比较。与这些只建模给定动作序列的分布式嵌入方法相比，DMN能够建模提供的外部动作集（外部记忆）作为当前动作的上下文，并将这些信息与当前动作序列一起用于目标预测。DMN对于先前动作很重要且可以存储为外部记忆的应用特别有意义（即DMN模型已成功应用于多个任务，如问答任务[5]）。

我们调整并开发这些模型用于挖掘上下文丰富的移动会话。它们的目的是学习先前应用事件和已购买应用商店item的表示作为外部记忆（用于建模用户偏好），以及学习当前应用事件的表示，最终目标是预测下一个购买的item。

#### 4.2.1 用于移动设备购买预测的深度记忆网络。外部记忆被公式化为第$i$个会话$x_i$之前的会话集合$S_i$，按购买时间排序，对于个性化推荐，按用户分组然后按购买时间排序。这样，DMN模型保留了历史用户行为会话和随后的购买的记忆。因此，DMN的任务是捕获移动用户在移动商店购买之前进行的长期和短期行为模式，并将学习到的规则应用于当前观察到的应用事件动作，以预测最可能被购买的item。为了进行预测，DMN接受两个不同的输入，第一个输入是作为"记忆"存储的历史观察会话集合（记忆大小$J$由用户选择），第二个输入是当前观察到的移动应用事件会话。模型最终输出从宇宙$T$中最可能被购买的item。

DMN模型前向传播步骤的图形表示如图2所示。第一步是将观察到的应用事件会话（嵌入矩阵$\mathbf{A}$）和先前会话嵌入到连续向量表示中（嵌入矩阵$\mathbf{B}$和$\mathbf{C}$）。观察到的应用事件被嵌入到向量$\mathbf{a}_i$中。然后$\mathbf{a}_i$用于通过注意力机制（嵌入$\mathbf{B}$与Softmax层）学习记忆中每个事件的相关性分数。获得的相关性分数（$\mathbf{p}_i$）用于通过加权求和将整个记忆汇总为单个向量。两个向量使用点积组合，产生向量$\mathbf{o}_i$。该过程可以在多个层（$H \geq 1$）中重复。最终，组合作为记忆和观察到的应用事件的摘要，馈送到最终全连接层以检索潜在的购买item。

**学习DMN**。DMN模型的优化目标可以定义为交叉熵损失。损失函数的目标是优化嵌入矩阵$\mathbf{A}$、$\mathbf{B}$、$\mathbf{C}$和权重矩阵$\mathbf{W}$：$\hat{\mathbf{A}}, \hat{\mathbf{B}}, \hat{\mathbf{C}}, \hat{\mathbf{W}} = \arg\min \mathcal{H}$。为了优化DMN模型，我们使用Adam优化器来控制学习率。

#### 4.2.2 移动用户嵌入。通过DMN学习用户特定行为通过两个步骤实现。第一步是为用户建模嵌入，这可以通过学习用户$n$在会话$x_i^{(n)} = \{u_n, \{a_1, a_2, a_3, \ldots\}, \{t_1, t_2, \ldots\}\}$中的表示$\mathbf{u}_n$来实现。第二步，观察到的用户动作的记忆上下文仅为其先前的活动和购买。因此，模型被迫考虑用户特殊性，提供个性化的item预测。

#### 4.2.3 大规模优化。移动应用事件$A$和应用商店item $T$的基数可能非常大，这给建模带来了问题，特别是在大规模情况下。在这种基数下，在Memory Networks模型中对所有item运行最终Softmax层可能不可行。然而，在本研究中，我们采用了一种称为采样Softmax（sampled softmax）[4]的重要采样技术，以使模型能够扩展到我们数据中发现的大规模应用商店item词汇表。我们选择采样Softmax是因为我们只需要在训练时加速，并希望在推理时保留所有item的logits。

## 5 实验

应用嵌入使用大规模应用事件日志与移动应用商店记录相结合学习。移动应用会话构建为在应用商店购买前观察到的应用事件。训练集从80天的会话生成，共1,517,830个会话，测试集由15天数据组成，共37,476个会话。

实验的基线选择为要么代表先前发表的研究，要么是预期适合给定设置的模型，包括：朴素分布采样购买item、LDA [8]、word2vec [2]和RNN [6]。

作为评估指标，我们使用Recall@K，衡量猜测相关（已购买）item的成功率。Recall@K为每个移动会话计算为$K$个检索item中真正预测的已购买item的比例，报告平均召回率。对于基线模型比较，我们使用Recall@5度量，因为大多数移动屏幕最多允许5个广告。

### 5.1 预测应用商店item购买

此任务的目标是预测用户在应用事件会话后实际购买的item。由于目标宇宙庞大（约140,000个在我们的数据集中被购买超过10次的独特item），预测问题非常困难。如果我们均匀建模目标，Recall@5将为$3.6 \times 10^{-5}$，证明了任务的难度。

当检查最可能购买item的预测（表1中的Recall@5）时，我们观察到DMN模型优于所有基线。基线中第二好的模型是在嵌入空间中进行最近邻搜索的word2vec模型，其次是RNN方法，而LDA和朴素模型未能提供与其他基线相当的准确度。这表明DMN模型比基线更好地处理数据中的噪声和类别不平衡。

### 5.2 将用户嵌入添加到上下文中

我们最后讨论在用户特定会话日志数据集上获得的结果，与先前实验中使用的简单时间排序会话日志数据集进行比较。使用了504,383个用户特定会话，最低购买次数为3次。应用事件和应用商店item的数量被降采样到约50,000个最频繁的，以补偿此设置可以使用的较小内存大小。

图3显示了用户DMN模型（红色）相对于普通DMN模型（蓝色）在Recall@K上的改进。我们可以看到，当考虑用户嵌入并将记忆集中在用户的活动上进行item预测时，我们在$K=1$和$K=10$时分别获得了4.5倍和约10倍的Recall@K改进。令人信服的改进表明，个性化移动广告在可能的情况下或在用户被观察到的历史会话中是可取的。我们还观察到DMN-user模型在$K=10$时的召回率比$K=1$时提高了7倍，为广告商在购买推荐中提供了更大的变异潜力。

## 6 结论与未来工作

在本研究中，我们提出了一种基于神经语言模型和深度记忆网络的方法，用于使用应用会话事件建模移动设备上的购买。为了解决可扩展性问题，我们提出在深度模型的最终层使用采样Softmax，并进一步表明将模型扩展到个性化推荐是可能的，并且优于非个性化方法。本研究的结果表明，DMN似乎适合解决此问题，因为它们优于所有基线。
